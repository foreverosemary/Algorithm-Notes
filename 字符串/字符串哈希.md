多项式字符串哈希函数 $H$ 将字符串看作 $p$ 进制数字，即：
$$
\begin{aligned}
H(s)=s_0\times{p^{n-1}}+s_1\times{p^{n-2}}+\dots+s_{n-1}\times{p^{0}}=\sum\limits_{i=0}^{n-1}s_i\times{p^{n-i-1}}
\end{aligned}
$$
其中 $s_i$ 表示字符串 $s$ 的第 $i$ 个字符的编码（**ASCII** 编码或自定义编码），$n$ 为字符串的长度。其中哈希值通常用 `unsigned long long` 存储，并用其溢出特性进行自动取模预算（模数为 $2^{64}$）。

## 子串哈希

对于一个字符串 $s$，在计算其哈希值时用 $h(i)$ 记录字符串前 $i$ 个字符的哈希值。

```cpp
using ull = unsigned long long;

ull h[N], p[N], P;

void hash(string s) {
    int n = s.size();
    s = " " + s;
    for(int i = 1; i <= n; i++) {
	    h[i] = h[i - 1] * P + s[i];
	    p[i] = p[i - 1] * P;
    }
}
```

对于子串 $[l,r]$ 的哈希值，其计算代码如下：

```cpp
ull get(int l, int r) {
	return h[r] - h[l - 1] * p[r - l + 1];
}
```

## 双值哈希

多值哈希即多个哈希函数，每个哈希函数的进制数不一样，这样能够解决哈希碰撞的问题。判断时只要其中一个哈希值不同，就认为两个字符串不同，如果哈希值都相同，则认为两个字符串相同。双值哈希即两个哈希函数。
