# 中介并查集

在标准的并查集中，如果要将一个元素从集合 $A$ 移动到集合 $B$，或者删除某个元素，就会遇到一个问题：该元素可能不仅是一个叶子节点，它还可能是其它节点的父节点，如果直接修改或删除它，会破坏整颗树的结构。

中介并查集也被称作 **带虚点的并查集** 或 **支持删除/移动操作的并查集**，核心作用是解决动态加点/删除、延迟合并、带时间维度的连通性等普通并查集无法处理的问题。

## 设计原理

**核心思想**：为每个原始元素简历一个映射，指向一个实际的物理节点。

- 初始状态：有 $n$ 个元素，但不直接操作 $1\sim n$，而是建立一个映射数组 $\text{id}[1...n]$，初始时有 $\text{id}[i]=i$。
- 合并操作：合并 $\text{id}[i],\text{id}[y]$。
- 删除/移动操作：
	- 如果把元素 $x$ 从当前集合中剔除，不改动原本的物理节点 $\text{id}[x]$，而是给 $x$ 分配一个新的、从未用过的物理编号 $ptr_{new}$，取 $\text{id}[x] =++ptr_{new}$。
	- 这样，原来的物理节点作为 **中介** 或者 **虚点** 继续留在原来的树里，保证了树结构的完整性，而 $x$ 已经指向了一个全新的、独立的空间。

```cpp
const int N;
int parent[2 * N]; // 两倍空间
int id[N];         // id[i] = 节点 i 当前绑定的中介节点
int cnt;

int find(int x) {
	return parent[x] == x ? x : (parent[x] = find(parent[x]));
}

void unite(int x, int y) {
	int px = find(id[x]), py = find(id[y]);
	if(px != py) parent[px] = py;
}

void init(int n) {
	iota(parent + 1, parent + 1 + n, 1);
	iota(id + 1, id + 1 + n, 1);
	cnt = n;
}

// 将元素 x 移动到 y 所在的集合
void move(int x, int y) {
	int px = find(id[x]), py = find(id[y]);
	if(px == py) return;
	id[x] = ++cnt;
	parent[id[x]] = py;
}

// 将元素 x 从当前集合中剔除
void remove(int x) {
	id[x] = ++cnt;
	parent[id[x]] = id[x];
}
```
