# 网络流

## 一、网络流初步

&emsp;&emsp;**网络** 指一个有向图 $G=(V,E)$，有两个特殊节点 **源点** $s$ 和 **汇点** $t$。每条有向边 $\langle x,y\rangle\in E$ 都有一个权值 $c\langle x,y\rangle$，为边的 **容量** 。当 $\langle x,y\rangle\notin E$ ，有 $c\langle x,y\rangle=0$。

&emsp;&emsp;&emsp;&emsp;对于每一条有向边上的流量 $f\langle x,y\rangle$ ，应该满足：
1.   **容量限制**：$f\langle x,y\rangle\le c\langle x,y\rangle$；
2.   **流量守恒**：除开源点与汇点外，$\sum_{\langle u,x\rangle\in{E}}f\langle u,x\rangle=\sum_{\langle x,v\rangle\in{E}}f\langle x,v\rangle$ ，即一个点的入流总和等于出流总和。$|f|=\sum_{\langle s,v\rangle\in{E}}f\langle s,v\rangle-\sum_{\langle u,s\rangle\in{E}}f\langle u,s\rangle$ 称为整个网络的流量，由于源点通常没有入边，可以简化为 $|f|=\sum_{\langle s,v\rangle\in{E}}f\langle s,v\rangle$ 。

**基础概念**

- **残留网**：对每条原边 $\langle x,y\rangle$ ，其 **残留容量** 为 $c_f\langle x,y\rangle=c\langle x,y\rangle-f\langle x,y\rangle$ ，并添加方向边 $\langle y,x\rangle$ ，其残留容量为 $f\langle x,y\rangle$ 。残留网络由所有残留容量 $\gt0$ 的边（包括反向边）构成，记为 $G_f$。 

- **增广路**：$G_f$ 上一条从源点到汇点的所有边的剩余容量都 $\gt0$ 的路径。对于一条增广路，给每一条边 $\langle u,v\rangle$ 都加上等量流量，以令整个网络的流量增加的过程，称为 **增广** 。

- **退流管道**：初始建图时，每一条有向边 $\langle x,y\rangle$ 都构建一条对应的反向边 $\langle y,x\rangle$ ，初始化容量 $c\langle y,x\rangle=0$ 。构建反向边的目的是提供后悔机制，一旦前面的增广路堵死可行流，可以通过管道进行退流。

- **割**：对于一个网络 $G=(V,E)$ ，将所有的点划分为两个集合 $S$ 和 $T$ ，称为割 $(S,T)$ ，其中源点 $s\in S$ ，汇点 $t\in{T}$ 。对于任意一个割 $(S,T)$ 都会使得网络断流。割的容量 $c\langle S,T\rangle=\sum_{u\in{S},v\in{T}}c\langle u,v\rangle$ 表示所有从 $S$ 到 $T$ 的出边的容量和。

-  **割集**：割集是割 $(S,T)$ 中所有从 $S$ 到 $T$ 的有向边的集合，满足 $\langle u,v\rangle\in{E}$ 且 $u\in{S},v\in{T}$ ，当在网络中移除这个边集合中的所有边后，网络会被划分为两个集合 $S$ 和 $T$ ，其余同上。此时割的容量就是割集中所有边的容量之和。

## 二、最大流

### 最大流求解

#### Ford–Fulkerson 增广

- 对于一条增广路，给每一条边 $\langle u,v\rangle$ 都加上等量的流量，以令整个网络的流量增加，这一过程被称为增广。因此，最大流的求解可以被视为若干次增广分别得到的流的叠加。在增广过程中，对于每条边 $\langle u,v\rangle$ ，新建对应的反向边 $\langle v,u\rangle$ ，初始化其便边权为 $0$ ，并约定 $f\langle u,v\rangle=-f\langle v,u\rangle$ ，那么反向边流量的减少视为反向边剩余容量 $c_f\langle v,u\rangle$ 的增加，接下来可能通过走反向边和原先正向的增广抵消，代表 **反悔** 操作。

&emsp;&emsp;容易发现，只要残留网 $G_f$ 上存在增广路，那么对其增广就可以使得总流量 $|f|$ 增加；否则说明总流量已经达到最大可能值，最大流求解完毕。那么求最大流本质就是不断增广的过程。

---

#### EK 算法

&emsp;&emsp;采用 **BFS** 寻找增广路，具体求解思路如下：
- 如果在 $G_f$ 上可以寻得从 $s$ 出发 **BFS** 到 $t$ ，则我们找到了一条新的增广路。
- 对于增广路 $p$ ，计算出 $p$ 经过的边的剩余流量的最小值 $\Delta=min\{c_f\langle u,v\rangle|\langle u,v\rangle\in{p}\}$ 。给路径上每一条边都加上 $\Delta$ 流量，并给它们的反向边都退掉 $\Delta$ 流量，最大流增加了 $\Delta$ 流量。
- 修改了一些边的流量后，得到新的残留网 $G_f'$ ，在新的 $G_f'$ 上重复上述过程，直到 $BFS$ 再也不能找到一条增广路为止。
该算法复杂度为 $O(VE^2)$ 。

```cpp
// O(VE^2)
using ll = long long;
const ll INF = 0x3f3f3f3f3f3f3f3f;

struct edge {
	ll v, c, nxt;
} edges[M];

int tot = 1, head[N], pre[N], S, T;
ll mf[N];

void add(int u, int v, ll c) {
	edges[++tot] = {v, c, head[u]};
	head[u] = tot;
	edges[++tot] = {u, 0, head[v]};
	head[v] = tot;
}

// bfs 寻找增广路
bool bfs() {
	memset(mf, 0, sizeof(mf));
	queue<int> q;
	q.push(S); mf[S] = INF;
	while(q.size()) {
		int u = q.front(); q.pop();
		for(int i = head[u]; i; i = edges[i].nxt) {
			ll v = edges[i].v;
			if(!mf[v] && edges[i].c) {
				mf[v] = min(edges[i].c, mf[u]);
				pre[v] = i;
				q.push(v);
				if(v == T) return true;
			}
		}
	}
	return false;
}

ll EK() {
	ll flow = 0;
	while(bfs()) {
		int v = T;
		while(v != S) {
			int i = pre[v];
			edges[i].cap -= mf[T];
			edges[i ^ 1].cap += mf[T];
			v = edges[i ^ 1].v;
		}
		flow += mf[T];
	}
	return flow;
}
```

#### Dinic 算法

&emsp;&emsp;同样采用 $BFS$ 寻找最短路，但在寻找过程中按照节点 $u$ 到源点 $s$ 的距离 $d(u)$ ，对 $G_f$ 进行分层。令经过 $u$ 的流量只能流向下一层的节点 $v$ ，即忽略 $u$ 指向层数标号相等或更小的节点的出边，此时 $G_f$ 剩下的部分为分层图 $G_L=(V,E_L)$ ，其中
$$\begin{aligned}
E_L=\{\langle u,v\rangle|\langle u,v\rangle\in{E_f},d(v)=d(u)+1\}
\end{aligned}.$$

&emsp;&emsp;如果在分层图 $G_L$ 上找到一个最大的增广流 $f_b$ ，使得仅在 $G_L$ 上不可能找出更大的增广流，则我们称 $f_b$ 是 $G_L$ 的阻塞流。

&emsp;&emsp;具体求解思路如下：
- 在 $G_f$ 上 **BFS** 出层次图 $G_L$ 。
- 在 $G_L$ 上 **DFS** 出阻塞流 $f_b$ 。
- 将 $f_b$ 合并到原先的流 $f$ 中，即 $f\leftarrow{f+f_b}$ 。
- 重复以上过程直到找不到增广路，此时的 $f$ 即为最大流。
某一时刻，当某条边 $\langle u,v\rangle$ 已经没有剩余流量或者 $v$ 的后侧已经增广至堵塞，则 $u$ 的流量没有必要再尝试流向出边 $\langle u,v\rangle$ 。因此，维护 $u$ 的出边表中第一条还有必要尝试的出边，称为 **当前弧** ，这个做法为 **当前弧优化** 。一般图的复杂度为 $O(n^2m)$，但对于二分图这样的特殊图可以达到 $O(\sqrt{n}m)$。

```cpp
using ll = long long;
const ll INF = 0x3f3f3f3f3f3f3f3f;

// O(V^2E)
struct edge {
	ll v, c, nxt;
} edges[M];

int tot = 1, head[N], cur[N], d[N], S, T, n, m;
bool vis[N];

void add(int u, int v, ll c) {
	edges[++tot] = {v, c, head[u]};
	head[u] = tot;
	edges[++tot] = {u, 0, head[v]};
	head[v] = tot;
}

bool bfs() {
	memset(d, 0, sizeof(d));
	queue<int> q;
	q.push(S); d[S] = 1;
	while(q.size()) {
		int u = q.front(); q.pop();
		for(int i = head[u]; i; i = edges[i].nxt) {
			int v = edges[i].v;
			if(!d[v] && edges[i].c > 0) {
				d[v] = d[u] + 1;
				q.push(v);
				if(v == T) return true; 
			}
		}
	}
	return false;
}

ll dfs(int u, ll mf) {
	if(u == T) return mf;
	ll sum = 0;
	for(int &i = cur[u]; i; i = edges[i].nxt) {
		int v = edges[i].v;
		if(d[v] == d[u] + 1 && edges[i].c > 0) {
			ll res = dfs(v, min(edges[i].c, mf - sum));
			edges[i].cap -= res;
			edges[i ^ 1].cap += res;
			sum += res;
			if(sum == mf) break;
		}
	}
	if(!sum) d[u] = 0; // 当前点没有增广路
	return sum;
}

ll dinic() {
	ll flow = 0;
	while(bfs()) {
		memcpy(cur, head, sizeof(head));
		flow += dfs(S, INF);
	}
	return flow;
}
```

### 关键边

&emsp;&emsp;关键边是满足如下条件的边：
1. 在当前最大流中，该边的流量等于其容量，即该边满流。
2. 删除该边后，网络的最大流值会严格减小。
换句话说，关键边是最大流中 **不可或缺** 的饱和边。

&emsp;&emsp;在运行完 **Dinic** 算法后，分别以 $S$ 和 $T$ 为起点，在残留网上遍历并对所有可达点打上标记。再遍历所有的边，如果该边的两个端点都被打上了标记，则该边为关键边。

```cpp
struct edge {
    ll u, v, c, nxt;
} edges[M];

int tot = 1, head[N], S, T, n, m;
bool vs[N], vt[N];

void add(int u, int v, ll c) {
    edges[++tot] = {u, v, c, head[u]};
    head[u] = tot;
    edges[++tot] = {v, u, 0, head[v]};
    head[v] = tot;
}

void clr(int u, bool vis[], int rev) {
	vis[u] = true;
	for(int i = head[u]; i; i = edges[i].nxt) {
		int v = edges[i].v;
		if(!vis[v] && edges[i ^ rev].c) clr(v, vis, rev);
	}
}

int main() {
	cin >> n >> m;
	S = 0, T = n - 1;
	for(int i = 1; i <= m; i++) {
		int u, v, c; cin >> u >> v >> c;
		add(u, v, c);
	}
	ll ans = 0;
	dinic();
	clr(S, vs, 0); clr(T, vt, 1);
	for(int i = 2; i <= tot; i += 2) {
		if(!edges[i].c && vs[edges[i ^ 1].v] && vt[edges[i].v]) ans++;
	}
	cout << ans << endl;
	return 0;
}
```

## 三、上下界网络流

- 在寻常流量网络的基础上给每一条边多添加了一个下限 $b\langle u,v\rangle$ ，即一条边上的流量应当满足 $b\langle u,v\rangle\le f\langle u,v\rangle\le c\langle u,v\rangle$ 。同时必须满足除了源点和汇点之外的其余点流量平衡。

### 无源汇上下界可行流

- 给定无源汇网络 $G$ ，询问是否存在一种标定每条边流量的方式，使得每条边流量满足容量限制，并且每一个点都满足流量守恒。

&emsp;&emsp;假设每条边已经有 $b\langle u,v\rangle$ 的流量，设为初始流。将每条边调整为 $c\langle u,v\rangle-b\langle u,v\rangle$ 建图，此时每条边的容量表示为：在满足下界后，该边还能承载的最大额外流量。这样再跑最大流算法，虽然满足了容量限制，但是不一定满足流量守恒，对于每个节点 $u$，其净需求为：$$d(u)=\sum_{e_{in}}b(e)-\sum_{e_{out}}b(e)$$
- 若 $d(u)\gt0$：节点 $u$ 的流入下界总和超出流出下界总和，则表明该节点缺少流量，需要补充 $d(u)$ 的流量才能满足流量守恒。
- 若 $d(u)\lt0$：节点 $u$ 的流出下界总和超出流入下界总和，则表明该节点流量多余，需要释放 $|d(u)|$ 的流量才能满足流量守恒。
- 若 $d(u)=0$：此时显然流量平衡。

**引入虚拟源汇平衡节点需求**：
- 虚拟源点 $S'$：向所有 $d(u)\gt0$ 的节点 $u$ 连一条容量为 $d(u)$ 的边，代表补充流量。
- 虚拟汇点 $T'$：所有 $d(u)\lt0$ 的节点 $u$ 向 $T'$ 连一条容量为 $|d(u)|$ 的边，代表吸收多余流量。

&emsp;&emsp;虚拟源汇平衡了节点因边下界产生的净需求，确保了循环流的流量守恒。在建图完毕后跑 $S'$ 到 $T'$ 的最大流，**若 $S'$ 连出去的边全部满流，则存在可行流，反之不存在**。

&emsp;&emsp;对于一般的 **Dinic** 算法，修改建图过程即可。

```cpp
using ll = long long;

struct edge {
	ll v, c, b, nxt;
} edges[M];

int tot = 1, S, T, n, m;
ll net[N];

void add(int u, int v, ll c, ll b) {
	edges[++tot] = {v, c - b, b, head[u]};
    head[u] = tot;
    edges[++tot] = {u, 0, 0, head[v]};
    head[v] = tot;
}

int main() {
	ios::sync_with_stdio(false); cin.tie(0); cout.tie(0);
	cin >> n >> m;
	for(int i = 0; i < m; i++) {
		int u, v, c, b; cin >> u >> v >> b >> c;
		add(u, v, c, b);
		net[u] -= b, net[v] += b;
	}
	ll sum = 0;
	for(int i = 1; i <= n; i++) {
		if(net[i] > 0) add(S, i, net[i], 0), sum += net[i];
		else if(net[i] < 0) add(i, T, -net[i], 0);
	}
	if(sum != dinic()) cout << "NO\n"; // 不存在可行流
	else {
		cout << "YES\n";
		// 输出方案
		for(int i = 2; i <= m * 2; i += 2) {
			cout << edges[i ^ 1].c + edges[i].b << endl;
		}
	}
}
```

### 有源汇上下界可行流

- 给定无源汇网络 $G$ ，询问是否存在一种标定每条边流量的方式，使得每条边流量满足容量限制，并且除了源汇点外都满足流量守恒。
对于源汇点 $S,T$ ，加入一条 $T$ 到 $S$ 的边，上界 $c\langle S,T\rangle=+\infty$ ，下界 $b\langle S,T\rangle=0$ ，该问题即转化为无源汇上下界可行流问题，若有解，则 $S$ 到 $T$ 的可行流流量等于 $T$ 到 $S$ 的附加边的流量。

#### 有源汇上下界最大流

&emsp;&emsp;首先找到网络上任意一个可行流，如果找不到解直接结束。否则考虑删除所有附加边（即 $\langle S',T'\rangle$ ）之后的残留网并在网络上调整。在残留网上再跑一次 $S$ 到 $T$ 的最大流，将可行流流量与最大流流量相加即为最大流。

```cpp
using ll = long long;

struct edge {
    ll v, c, nxt;
} edges[M];

int tot = 1, head[N], S, T, n, m, s, t;
ll net[N];

void add(int u, int v, ll c) {
    edges[++tot] = {v, c, head[u]};
    head[u] = tot;
    edges[++tot] = {u, 0, head[v]};
    head[v] = tot;
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0); cout.tie(0);
    cin >> n >> m >> s >> t;
    S = 0, T = n + 1; // 虚拟源汇
    for(int i = 0; i < m; i++) {
        int u, v, c, b; cin >> u >> v >> b >> c;
        add(u, v, c - b);
        net[u] -= b, net[v] += b;
    }
    ll sum = 0;
    for(int i = 1; i <= n; i++) {
        if(net[i] > 0) add(S, i, net[i]), sum += net[i];
        else if(net[i] < 0) add(i, T, -net[i]);
    }
    add(t, s, INF); // 实际源汇填边变为无源汇模型
    if(dinic() < sum) cout << "No Solution" << endl; // 不存在可行流
    else {
        ll res = edges[tot].c;
        S = s, T = t;
        // 删除源汇附加边
        edges[tot].c = edges[tot - 1].c = 0;
        cout << res + dinic() << endl;
    }
    return 0;
}
```

#### 有源汇上下界最小流

&emsp;&emsp;首先找到网络上任意一个可行流，如果找不到解直接结束。否则考虑删去所有附加边（即 $\langle S',T'\rangle$ ）之后的残留网，在残留网上再跑一次 $T$ 到 $S$ 的最大流，将可行流流量减去最大流流量即为最小流。

&emsp;&emsp;只需要将上述代码末尾处的 `S = s, T = t` 以及 `res + dinic()` 改为 `S = t, T = s` 和 `res - dinic()` 即可。

## 四、最小割

### 最小割求解

&emsp;&emsp;最小割即最小化 $S$ 到 $T$ 的容量和，即最小化一个 **割集** 中所有有向边的容量和，但割集中的边本身不一定是极简的。**可以理解为将点集划分为包含源点和汇点的两个互补子集的最小代价** 。

-   **最大流最小割定理**：$|f|\le c\langle S,T\rangle\Rightarrow |f|_{max}=c\langle S,T\rangle_{min}$ 

&emsp;&emsp;**一个最小割的割集中的边都是满流边，但满流边不一定都是一个最小割中的边**。<br>
&emsp;&emsp;如果一条边同时满足 **满流** 和 **去掉该边后网络的最大流减小的量等于该边的容量** 这两个条件，这条边一定属于一个最小割的割集。<br>
​&emsp;&emsp;因此，从 $S$ 开始在残留网中 $BFS$ 出一个源集合，这个集合中的所有点与源点连通，那么如果一条边 $\langle u,v\rangle$ 满流并且 $u$ 属于源集合而 $v$ 不属于，则这条边一定属于一个最小割。

**最小割的方案求解**

&emsp;&emsp;由于满流的边不一定都是一个最小割中的边，但最小割中的边一定满流。可以从源点 $s$ 开始 $DFS$ ，每次走 $G_f$ 中残量大于 0 的边，即可找全 $S$ 点集内的点，而其余的点即为 $T$ 点集内的点，则 $\{\langle u,v\rangle|u\in{S},v\in{T}\}$ 即为一个最小割。

```cpp
struct edge {
	ll v, c, nxt;
} edges[M];
int head[N]; bool vis[N];

void dfs(int u) {
    vis[u] = true;
    for(int i = head[u]; i; i = edges[i].nxt) {
	    int v = edges[i].v;
	    if(!vis[v] && edges[i].c) dfs(v);
    }
}
```

**割边数量求解**

- 在最小割前提下最小化割边数量，有以下两种方法，本质基本一样：
	1. 在输入边权时将正向边权改为 $c*Mod+1$ ，其中 $Mod$ 为一个足够大的常数，这样跑一遍最小割算法得到的值为 $f'$ ，那么最小割就等于 $\frac{f'}{Mod}$ ，最小割边数为 $f'\mod{Mod}$ 。
	2. 先求出最小割，再将没有满流的边容量改为 $+\infty$ ，满流的边容量改为 $1$ ，重新跑一遍最小割就可以得到最小割边数。
- 若没有最小割的前提，直接将所有边的容量设为 $1$ ，再求一遍最小割即可。

### 最大权闭合图

- 定义一个有向图 $G=(V,E)$ 的闭合子图 $V_c$ 为有向图的一个点集，且点集中所有出边都还指向该点集，即对于 $\forall{u}\in{V_c}$ ，若满足 $\langle u,v\rangle\in{E}$ ，则一定有 $v\in{V_c}$ 成立。
- 给每个点 $v$ 分配一个点权 $w(v)$ ，**最大权闭合图** 是一个点权之和最大的闭合图，即最大化 $\sum\limits_{v\in{V_c}}w(v)$ 。

**转化为最小割模型**

&emsp;&emsp;在原图点集上增加超级源点 $s$ 和超级汇点 $t$ ，对于每个正权点，增加源点到该点的有向边，容量为 $c\langle s,v\rangle=w(v)$ ；对于每个负权点，增加该点到汇点的有向边，容量为 $c\langle v,t\rangle=-w(v)$ ；而对于原图中的有向边 $\langle u,v\rangle\in{E}$ ，边权替换为 $c\langle u,v\rangle=+\infty$ 。定义这样构建的网络为 $N=(V_N,E_N)$ ，有如下三个定理：

1. **在网络 $N$ 中，最小割为简单割** 。<br>
&emsp;&emsp;若一个割 $(S,T)$ 中的每条边都只与 $s$ 或 $t$ 关联，则称该割为 **简单割** 。由于割中的边一定满流，由于原图中的边在网络中容量为无穷大，所以一定不会满流，故该网络 $N$ 最小割中的边一定与 $s$ 或 $t$ 关联 。

2. **一个闭合子图 $V_c$ 与网络 $N$ 中的一个简单割 $(S,T)$ 一一对应**，即
   $$\begin{aligned}
   V_c\cup\{s\}=S,\overline{V_c}\cup\{t\}=T.
   \end{aligned}$$ 
- **充分性**：对于一个闭合子图 $V_c$ ，定义 $S=V_c\cup\{s\},T=\overline{V_c}\cup\{t\}$ ，证明 $(S,T)$ 为一个简单割 。假设存在 $\langle u,v\rangle\in{E}$ ， 其中 $u\in{V_c},v\in{\overline{V_c}}$ ，则不满足 $V_c$ 为一个闭合子图的前提，故不存在边 $V_c\rightarrow\overline{V_c}$ ，即不存在边 $S\rightarrow{T}$ 。故 $(S,T)$ 为一个简单割，充分性得证。
- **必要性**：对于网络中的一个简单割 $(S,T)$ ，证明 $V_c=S-\{s\}$ 为一个闭合子图。$\forall{u}\in{V_c}$ ，考虑其出边 $\langle u,v\rangle\in{E}$ ，根据定理 $1$ 可知简单割中不含 $E$ 中任何边，故 $\forall{v}\notin T-{t}=\overline{V_c}$ ，满足闭合图的定义。故 $V_c$ 为一个闭合图，必要性得证。
3. **最大权值和=所有正权值和-最小割/最大流** 。<br>
&emsp;&emsp;定义闭合图 $V_c$ 的权值和为 $W(V_c)=\sum\limits_{v\in{V_c}}w(v)$ ，所有正权值之和为
$$\begin{aligned}Sum^+=\sum\limits_{w(v)\gt0,v\in{V}}w(v)\end{aligned}.$$
将 $W(V_c)$ 拆分成正权节点和负权节点两部分
$$
\begin{aligned}  W(V_c)=\sum\limits_{w(v)\gt0,v\in{V_c}}w(v)+\sum\limits_{w(v)\lt0,v\in{V_c}}w(v)
\end{aligned}.
$$
而正权节点的总和可以拆分为
$$
\begin{aligned}  Sum^+=\sum\limits_{w(v)\gt0,v\in{V}}=\sum\limits_{w(v)\gt0,v\in{V_c}}w(v)+\sum\limits_{w(v)\gt0,v\notin{V_c}}w(v)
\end{aligned}.
$$
因此，闭合图中的正权部分可以表示为
$$
\begin{aligned}
\sum\limits_{w(v)\gt0,v\in{V_c}}w(v)=Sum^+-\sum\limits_{w(v)\gt0,v\notin{V_c}}w(v)
\end{aligned}.
$$
将正权部分表达式代入 $W(V_c)$
$$
\begin{aligned}
W(V_c)=(Sum^+-\sum\limits_{w(v)\gt0,v\notin{V_c}}w(v))+\sum\limits_{w(v)\lt0,v\in{V_c}}w(v)
\end{aligned}.
$$
对于负权节点，令 $w(v)=-c(v)$ ，则
$$
\begin{aligned}
W(V_c)=Sum^+-\sum\limits_{w(v)\gt0,v\notin{V_c}}w(v)-\sum\limits_{w(v)\lt0,v\in{V_c}}c(v)
\end{aligned}.
$$
根据割容量的定义有
$$
\begin{aligned}
c\langle S,T\rangle=\sum\limits_{w(v)\gt0,v\notin{S}}w(v)+\sum\limits_{w[v]<0,v\in{S}}c(u)
\end{aligned}.
$$
故有 $W(V_c)=Sum^+-c\langle S,T\rangle$ 。由于 $Sum^+$ 为定值，故当前仅当 $c\langle S,T\rangle$ 为最小割的容量时，$W(V_c)$ 有最大值。

### 最大密度子图

&emsp;&emsp;定义一个无向图 $G=(V,E)$ 的密度 $D=\frac{|E|}{|V|}$ ，其具有最大密度的子图 $G'=(V',E')$ 称为最大密度子图。

- 该问题需要最大化如下式子：
$$
\begin{aligned}
D=\frac{\sum\limits_{e\in{E}}x_e}{\sum\limits_{v\in{V}}x_{v}}=\frac{|E'|}{|V'|}
\end{aligned}
$$

&emsp;&emsp;其中，$x_v,x_e\in\{0,1\}$ ，表示每个点或边是否在该子图中，很明显该模型为 $0-1$ 分数规划。通过二分搜索猜测密度阈值 $\lambda$ ，构造辅助函数判断是否存在密度至少为 $\lambda$ 的子图：$g(\lambda)=\max_x[\sum_{e\in{E}}x_e-\lambda\sum_{v\in{V}}x_v]=\max(|E'|-\lambda|V'|)$ ，若 $g(\lambda)\ge0$ ，说明存在密度不小于 $\lambda$ 的子图，反之则不存在。

&emsp;&emsp;对于二分查找，先确定范围为 $\left[\frac{1}{n},\frac{m}{1}\right]$ 。对于查找精度：无向图 $G$ 中，任意两个具有不同密度的子图 $G_1,G_2$ ，它们的密度之差不小于 $\frac{1}{n^2}$ ，证明如下：
$$
\begin{aligned}
D_{G_1}-D_{G_2}&=\frac{m_1}{n_1}-\frac{m_2}{n_2}=\frac{m_1n_2-m_2n_1}{n_1n_{2}} \ge \frac{1}{n_1n_{2}} \ge \frac{1}{n^2}
\end{aligned}
$$
- 接下来探讨如何求解 $g(\lambda)$ ：

 &emsp;&emsp;对于子图 $G'$ ，若 $(u,v)\in{E'}$ ，则必存在  $u,v\in{V'}$ ，这复合闭合图的约束条件。如果将边 $e$ 视为点权为 $1$ 的点 $v_e$ ，而原本的点带上点权 $-\lambda$ 。那么对于所有的边 $(u,v)\in{E}$ ，在新图中视作 $\langle v_e,u\rangle,\langle v_e,v\rangle$ 这两条边，这样所有原来的点在新图中不再有出边，而新增的点必然指向原来的点，问题转换为求解最大权闭合图。

&emsp;&emsp;贪心考虑，对于一个给定的 $V'$ ，凡是符合 $u,v\in{V'}$ 的，都应该将 $(u,v)\in{E}$ 选进 $E'$ 中， 此时对于这个这个给定的 $V'$ ，其对应的导出子图 $G'=(V',E')$ 就是密度最大的子图。故直接将 $E'$ 重新定义为 $V'$ 的导出子图的边集。

&emsp;&emsp;将原函数 $g(\lambda)=max(|E'|-\lambda|V'|)$ 转换为求解 $min(\lambda|V'|-|E'|)$ ：
$$
\begin{aligned}
\lambda|V'|-|E'|&=\sum\limits_{v\in{V'}}\lambda-\sum\limits_{e\in{E'}}1\\
\end{aligned}.
$$
而对于 $u\in{V'}$ 且存在 $(u,v)\in{E}$ ，但 $v\notin{V'}$ ，即 $v\in{\overline{V'}}$ 。由度数守恒有：
$$
\begin{aligned}
\frac{1}{2}\sum\limits_{u\in{V'}}d(u)&=\sum\limits_{e\in{E'}}1+\sum\limits_{\substack{(u,v)\in{E}\\u\in{V'},v\in{\overline{V'}}}}1\\
&=\sum\limits_{e\in{E'}}1+c(V',\overline{V'})
\end{aligned}.
$$
其中 $d(u)$ 表示点 $u$ 的度数，$c(V,V')$ 代表割 $(V',\overline{V'})$ 的容量，则对于原式：
$$
\begin{aligned}
\lambda|V'|-|E'|&=\sum\limits_{v\in{V'}}\lambda-\sum\limits_{e\in{E'}}1\\
&=\sum\limits_{v\in{V'}}\lambda-\left( \frac{1}{2}\sum\limits_{v\in{V'}}d(v)-c(V',\overline{V'}) \right)\\
&=\sum\limits_{v\in{V'}}\left( \lambda-\frac{d(v)}{2} \right)+c(V',\overline{V'})
\end{aligned}.
$$
&emsp;&emsp;网络模型建图：
1. 新增源点 $s$ 和汇点 $t$ ，每条边 $(u,v)$ 转化为双向边 $\langle u,v\rangle,\langle v,u\rangle$ ，容量都为 $1$ ，表示选择了 $u,v$ 两点且存在 $(u,v)\in{E'}$ 的边权贡献 $1$ ；
2. 源点 $s$ 向所有点 $v$ 连边，容量为 $U$（足够大的常数，如 $m$，确保后面的边权非负，防止影响最小割的求解）；
3. 所有点 $v$ 向汇点 $t$ 连边，容量为 $U+2\lambda-d(v)$ ，表示选择点 $v$ 带来的点权贡献 $\lambda-\frac{d(v)}{2}$（乘以 $2$ 方便处理，加上了一个足够大的常数确保非负）。

&emsp;&emsp;此时 **最小割的容量就对应 $g(\lambda)$ 的最大值** ，通过调整 $\lambda$ 不断逼近最优解。

```cpp
#define endl '\n'
#define eb emplace_back

using namespace std;
using ll = long long;
using pii = pair<int, int>;

const ll INF = 0x3f3f3f3f3f3f3f3fll;
const double eps = 1e-8;

struct edge {
    ll v, nxt; double c;
} edges[M];

int tot = 1, S, T, n, m, ans;
int d[N], cur[N], deg[N], head[N];
bool vis[N];
vector<pii> ed;

void add(int u, int v, double c1, double c2) {
    edges[++tot] = {v, head[u], c1};
    head[u] = tot;
    edges[++tot] = {u, head[v], c2};
    head[v] = tot;
}

void build(double x) {
	memset(head, 0, sizeof(head));
	tot = 1;
	for(auto [u, v] : ed) {
		add(u, v, 1, 1);
	}
	for(int i = 1; i <= n; i++) {
		add(S, i, m, 0);
		add(i, T, m + 2 * x - deg[i], 0);
	}
}

bool bfs() {
    memset(d, 0, sizeof(d));
    queue<int> q;
    q.push(S); d[S] = 1;
    while(q.size()) {
        int u = q.front(); q.pop();
        for(int i = head[u]; i; i = edges[i].nxt) {
            int v = edges[i].v;
            if(!d[v] && edges[i].c > eps) {
                d[v] = d[u] + 1;
                q.push(v);
                if(v == T) return true;
            }
        }
    }
    return false;
}

double dfs(int u, double mf) {
    if(u == T) return mf;
    double sum = 0;
    for(int &i = cur[u]; i; i = edges[i].nxt) {
        int v = edges[i].v;
        if(d[v] == d[u] + 1 && edges[i].c > eps) {
            double res = dfs(v, min(edges[i].c, mf - sum));
            edges[i].c -= res;
            edges[i ^ 1].c += res;
            sum += res;
            if(abs(sum - mf) <= eps) break;
        }
    }
    if(sum <= eps) d[u] = 0; // 当前点没有增广路
    return sum;
}

double dinic(double x) {
	build(x);
    double flow = 0;
    while(bfs()) {
        memcpy(cur, head, sizeof(head));
        flow += dfs(S, INF);
    }
    return flow;
}

void clr(int u) {
	vis[u] = true;
	if(u != S) ans++;
	for(int i = head[u]; i; i = edges[i].nxt) {
		int v = edges[i].v;
		if(!vis[v] && edges[i].c > 0) clr(v);
	}
}

int main() {
	ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
	cin >> n >> m;
	S = 0, T = n + 1;
	for(int i = 1; i <= m; i++) {
		int u, v; cin >> u >> v;
		deg[u]++, deg[v]++;
		ed.eb(u, v);
	}
	
	auto check = [&](double x) -> bool {
		double flow = dinic(x);
		return m * n - flow > 0;	
	};
	
	double l = 0, r = m;
	while(r - l > eps) {
		double mid = (r + l) / 2;
		(check(mid) ? l : r) = mid;
	}
    // l 为最大密度
	dinic(l); clr(S);
    if(!ans) cout << "1\n1\n";
    else {
        // 输出方案
        cout << ans << endl;
        for(int i = 1; i <= n; i++) {
            if(vis[i]) cout << i << endl;
        }
    }
	return 0;
}
```

## 五、费用流
 
&emsp;&emsp;给定一个网络 $G=(V,E)$ ，每条边除了有容量限制外，新增了一个单位流量的费用 $w\langle u,v\rangle$ ，当 $\langle u,v\rangle$ 的流量为 $f\langle u,v\rangle$ 时，需要花费 $f\langle u,v\rangle\times w\langle u,v\rangle$ 的费用。$w$ 满足斜对称性，即 $w\langle u,v\rangle=-w\langle v,u\rangle$ 。则该网络中总花费最小的最大流称为 **最小费用最大流** ，即在最大化 $|f|$ 的情况下最小化 $\sum\limits_{\langle u,v\rangle\in{E}}f\langle u,v\rangle\times w\langle u,v\rangle$ 。
### Dinic 算法

&emsp;&emsp;将原 **Dinic** 算法求解最大流中的 **BFS** 替换为 **SPFA** ，用最短路的思路在增广过程中求解最小花费即可。

```cpp
using ll = long long;
const ll INF = 0x3f3f3f3f3f3f3f3f;

struct edge {
	ll v, c, nxt, w;
} edges[M];

int tot = 1, S, T, n, m;
int cur[N], head[N]; bool vis[N];
ll d[N], mic; // mic 为最小花费

void add(int u, int v, ll c) {
	edges[++tot] = {v, c, head[u]};
	head[u] = tot;
	edges[++tot] = {u, 0, head[v]};
	head[v] = tot;
}

bool spfa() {
	memset(d, 0x3f, sizeof(d));
	memcpy(cur, head, sizeof(head));
	queue<int> q;
	d[S] = 0, vis[S] = true;
	q.push(S);
	while(q.size()) {
		int u = q.front(); q.pop();
		vis[u] = false;
		for(int i = head[u]; i; i = edges[i].nxt) {
			int v = edges[i].v;
			if(edges[i].c && d[v] > d[u] + edges[i].w) {
				d[v] = d[u] + edges[i].w;
				if(!vis[v]) {
					vis[v] = true;
					q.push(v);
				}
			}
		}
	}
	return d[T] < INF;
}

ll dfs(int u, ll mf) {
	if(u == T) return mf;
	ll sum = 0;
	vis[u] = true;
	for(int &i = cur[u]; i; i = edges[i].nxt) {
		int v = edges[i].v;
		if(!vis[v] && edges[i].c && d[v] == d[u] + edges[i].w) {
			ll res = dfs(v, min(edges[i].c, mf - sum));
			edges[i].c -= res;
			edges[i ^ 1].c += res;
			sum += res;
			minc += res * edges[i].w;
			if(mf == sum) break;
		}
	}
	vis[u] = false;
	if(!sum) d[u] = 0; // 当前点没有增广路
	return sum;
}

ll dinic() {
	ll flow = 0;
	while(spfa) {
		ll x;
		while((x = dfs(S, INF))) {
			flow += x;
		}
	}
	return flow;
}
```

## 六、网络流建模

- 对于一般无向图，在网络流建模时，对于容量为 $c$ 的边 $(u,v)$，只需连 $u\to v$ 和 $v\to u$，且容量都设置为 $c$。无需另外设置容量为 $0$ 的反向边，两条边互为反向边。

### 平面图与网络流

- 对于一个图 $G=(V,E)$，如果其本身不存在两条边相交，那么称该图为平面图。根据欧拉公式，如果一个连通的平面图有 $|V|=n$ 个点，$|E|=m$ 条边和 $f$ 个面。那么：
$$
f=m-n+2
$$

&emsp;&emsp;定义 $G'=(V',E')$ 为平面图 $G$ 的对偶图，其根据如下映射关系建立而成：
1. 将原图 $G$ 中的每个面（包括外部无限面）映射为 $G'$ 中的一个顶点，即 $G$ 的每个面 $f$ 对应 $G'$ 中的一个点 $v'_f\in V'$。
2. 对于原图中的每条边 $e\in E$，若 $e$ 是两个不同面 $f_1,f_2$ 的公共边界，则在 $G'$ 中添加一条连接 $v'_{f_1},v'_{f_2}$ 的边 $e'$，且 $e$ 与 $e'$ 相互对应。若 $e$ 只属于一个面 $f$，那么有自环 $(v'_f,v'_f)$。

&emsp;&emsp;平面图 $G$ 与对偶图 $G'$ 存在关系：
- $G'$ 的点数等于 $G$ 的面数，即 $n'=f$；$G'$ 的边数等于 $G$ 的边数，即 $m'=m$；$G'$ 的面数等于 $G$ 的点数，即 $f'=n$。
- $G'$ 同样为平面图，且 $(G')'$ 与 $G$ 同构。
- $G'$ 中的每一个自环，都对应 $G$ 中的一条为桥的边；$G'$ 中的每一条为桥的边，都对应 $G$ 中的一个自环。

&emsp;&emsp;如果存在两个特殊顶点，记为源点 $s$ 和汇点 $t$，且将平面图 $G$ 嵌入平面后，使得 $s,t$ 都位于同一个外部面的边界上，定义流的流向为从 $s$ 到 $t$，称该平面图为 $s-t$ 平面图。由于对于 $G,G'$ 之间存在桥和自环的对应关系，推广到 $s-t$ 平面图中时，有如下对应关系：
- **$G$ 中的一个 $s-t$ 割 $C$，对应对偶图 $G'$ 中一个包含外部面顶点的环 $L'$，反之亦然。**

证明过程：
- 由于 $s-t$ 平面图中 $s$ 和 $t$ 共属外部面，原图的面可分为包含 $s$ 侧和包含 $t$ 侧两类（但本质上这两侧的面共属于外部面），$s-t$ 割 $C$ 正是分割这两类面的边集。
- 对偶图 $G'$ 中，每个顶点对应原图的一个面。对于边 $e\in C$，在对偶图中对应一条连接 $s$ 侧面顶点和 $t$ 侧面顶点的边 $e'$。这些边 $e'$ 相当于一条闭合的分割线，从 $s$ 侧的面开始，经过所有的 $e\in C$，最终到达 $t$ 侧的面，又由于 $s,t$ 共属于外部面，等价于从外部面出发又重新回到了外部面，共同构成对偶图中一个闭合路径，也就是环 $L'$，且该环必定经过外部面对应的顶点。

&emsp;&emsp;在上述基础上，将外部面在 $G'$ 中对应的点拆分为两个顶点 $s',t'$，根据上述结论，$G$ 中的一个 $s-t$ 割 $C$ 可被视作从 $s'$ 到 $t'$ 的一条路径。如果将原图 $G$ 上的每条边 $e$ 的边权赋值到其在 $G'$ 中对应的 $e'$ 上，那么：
- **$G$ 中的一个最小割，对应对偶图 $G'$ 中的最短路，反之亦然。**

```cpp
// S 为源点, T 为汇点
int up(int idx) {return idx <= m ? S : idx - m;}
int down(int idx) {return idx > n * m ? T : idx;}
int left(int idx) {return (idx % (m + 1)) == 1 ? T : idx - (idx - 1) / (m + 1) - 1;}
int right(int idx) {return (idx % (m + 1)) == 0 ? S : idx - idx / (m + 1);}
```

&emsp;&emsp;其中 `up` 和 `down` 用于找横边，`left` 和 `right` 用于找竖边。

### 分层图与网络流

&emsp;&emsp;当网络流问题中的流具有某种 **不可逆性的状态值** 时，常常用分层图来进行建模，此时每一层代表一个特定的状态（即分层图本质为状态空间上的拓展），而层间的单项边（底层 $\to$ 高层）则严格控制了状态的单调推进，完美匹配了这些具有 **单调性、不可逆性或严格次数限制** 的复杂约束。也就是说分层图建模的核心精髓在于利用 **层间转移的不可逆性**，去模拟 **现实世界中资源消耗、时间流逝（即状态转变）的不可逆性质**。

建模示例：
- 资源消耗建模：初始时带有资源总量为 $k$，每进行一次行动消耗一次资源，资源为 $0$ 时停止行动。取分层图层数为 $0\sim k$ 共 $k+1$ 层，位于第 $i$ 层代表消耗了 $i$ 份资源。从每一层的 $(i,u)$ 向下一层的可转移节点 $(i+1,v)$ 连有向边，代表从 $u$ 转移到 $v$ 需要消耗一次资源；从该层的 $(i,u)$ 向同一层的可转移节点 $(i,v)$ 或者非下一层可转移节点则可以表示某种特权边。
- 时间流逝建模：初始时带有资源总量为 $k$，在每一天上都只能在一些特定的路线上行动，求解将所有资源从起点运往终点的最小调度时间。取分层图层数为 $0\sim t$，其中 $t$ 为调度任务结束时间，即最小调度时间，位于第 $i$ 层代表处于第 $i$ 天。由于每一天的可行路线都不相同，从每一层的 $(i,u)$ 向下一层的 $(i+1,u)$ 连有向边，代表在状态 $u$ 停滞行动一天，从而能够在下一天做出对应的决策；从该层的 $(i,u)$ 向下一层的可转移节点 $(i+1,v)$ 连有向边代表消耗一个单位时间运输物资，用网络流的流动来表示资源的调度；每到达新的一层就代表经过一个单位时间，结合该层与上层的残余网络，若累计流量大于等于 $k$，则代表得到了最小调度时间。

### 二元关系下的最小割问题

#### 最小化组合损失

- 将若干元素 $e_1,e_2,\dots,e_n$ 划分到两个集合 $A,B$ 中。对于元素 $e_i$，它被划分到 $A$ 或 $B$ 中分别能够获得 $a_{e_i}$ 或 $b_{e_i}$ 的权值。此外，给出若干组合 $(e_i,e_j)$（保证 $i\neq j$），若组合中的元素被同时划分到 $A$ 或 $B$ 中，可获得额外的权值 $a'_{ij}$ 或 $b'_{ij}$，求将所有元素划分完全后的最大权值。

&emsp;&emsp;由于每一个元素要么被划分到集合 $A$，要么被划分到集合 $B$，自然联系到网络流中的割，一个点要么被划分到 $S$ 集合，要么被划分到 $T$ 集合，如果不考虑组合收益，可建立以下的流网络图：

![[例图1.png]]

&emsp;&emsp;在这张图上求解最小割，对于每一条 $S\to u\to T$ 的有向路径，要么割去 $S\to u$，要么割去 $u\to T$。若一个点保留与 $S$ 相连的边，则代表被划分到集合 $S$，等价于集合 $A$；若一个点保留与 $T$ 相连的边，则代表被划分到集合 $T$，等价于集合 $B$。用 $W_S,W_{S'}$ 分别表示与 $S$ 相连的边中没有被割去的权值和以及被割去的权值和，即
$$W_S+W_{S'}=\sum a_i.$$
&emsp;&emsp;对于集合 $W_T,W_{T'}$ 同样有 $$W_T+W_{T'}=\sum b_i.$$
&emsp;&emsp;那么由于此时最小割求解的是最小割边权值和，用 $W_{\text{Cut}}$ 表示未被选择的元素基础权值和，即被割去的边权值和，有 $$\min W_{\text{Cut}}=\min(W_{S'}+W_{T'})$$
&emsp;&emsp;而我们要求解的是 $\max(W_S+W_T)$，故作以下转换 $$\max(W_S+W_T)=\sum(a_i+b_i)-\min(W_{S'}+W_{T'}).$$
&emsp;&emsp;那么最大权值和就等价于总权值和减去最小割，即 $$\max W_{\text{sel}}=W_{\text{all}}-\min W_{\text{Cut}}.$$&emsp;&emsp;其中 $W_{\text{sel}}$ 表示被选择的基础权值和，$W_{\text{all}}$ 表示所有选择的基础权值和。接下来加入组合权值进行分析，组合收益当且仅当一对组合中的两个元素被划分到同一集合 $S$ 或 $T$ 时才会产生，由于之前的模型分析建立在最小割上，故尝试将组合权值加入到最小割体系里。对于一对组合 $(u,v)$，若组合权值不存在，那么仅需分别割去 $S\to u\to T$ 和 $S\to v\to T$ 这两条路径上任意一条边，即可保证 $S,T$ 在这两条路径上断开。<br>
&emsp;&emsp;当引入组合权值时，以 $S$ 举例，若 $u,v$ 都选择了 $S$，也就是 $u\to T$ 和 $v\to T$ 被割去，但仍然需要一条边代表组合权值 $b'_{uv}$ 使得 $S\to T$ 的路径依然存在，让其不得不被割去。

&emsp;&emsp;由于此时路径表示为 $S\to u,v\to T$ 存在，而组合权值 $b'_{uv}$ 被割去当且仅当 $S\to u$ 和 $S\to v$ 同时存在，故新建虚拟点 $Y$ 不表示任何元素，连接有向边 $u\to Y,v\to Y$，容量为 $\infty$，再连接 $Y\to T$ 容量为 $b'_{uv}$（对于 $a'_{uv}$ 同理）。

![[例图2.png]]

&emsp;&emsp;这样建图后，若 $S\to u$ 和 $S\to v$ 被选择，由于必定不能割去容量为 $\infty$ 的边，故 $Y\to T$ 这条边必须被割去。$W_S$ 与 $W_{S'}$ 的定义保持不变，那么有 $$\begin{aligned}W_S+W_{S'}=&\sum a_i+\sum a'_{ij}\\W_T+W_{T'}=&\sum b_i+\sum b'_{ij}\end{aligned}.$$
&emsp;&emsp;此时最大权值和仍然为
$$\max W_{\text{sel}}=W_{\text{all}}-\min W_{\text{Cut}}$$

&emsp;&emsp;现在换一种视角建模，考虑以下流网络图：

![[例图4.png]]

&emsp;&emsp;同样与 $S$ 相连代表选择 $A$ 集合，与 $T$ 相连代表选择 $B$ 集合，其最小割如图有这四种情况表示其损失权值总和：
$$W_{\text{Cut}}=\begin{cases}y+t=b_1+b_2+b'_{12}\\x+k=a_1+a_2+a'_{12}\\x+e+t=a_1+b_2+a'_{12}+b'_{12}\\k+e+y=a_2+b_1+a'_{12}+b'_{12}\end{cases}$$
&emsp;&emsp;根据线性代数的知识容易得到当且仅当 $e=\frac{a'_{12}+b'_{12}}{2}$ 时，该方程组才有解，为了便于建模，给出一组特定解为：

$$\begin{cases}x=k=\frac{a_1+a_2+a'_{12}}{2}\\y=t=\frac{b_1+b_2+b'_{12}}{2}\\e=\frac{a'_{12}+b'_{12}}{2}\end{cases}$$
&emsp;&emsp;拓展到更一般的形式，当有多个点 $v$ 与当前点 $u$ 建立了二元关系时，用 $\deg(u)$ 表示与 $u$ 建立了二元关系的元素总数，那么有
$$\begin{aligned}S\to u:&\frac{a_u+\sum (a_v+a'_{uv})}{2}\\u\to T:&\frac{b_u+\sum(b_v+b'_{uv})}{2}\\u\to v:&\frac{\sum(a'_{uv}+b'_{uv})}{\deg(u)}\end{aligned}$$
&emsp;&emsp;此时，最大权值和就等于所有权值和减去该流网络图上的最小割，然而，由于该建模方法涉及到浮点数精度问题，故第一种建模方法通常优于第二种。

#### 最小化组合代价

&emsp;&emsp;若此时改变组合权值的定义，对于一个组合 $(u,v)$，当 $(u,v)$ 不被分到同一个集合 $A$ 或者 $B$ 时，另有额外权值 $c_{uv}$，问题也转变为求解最小权值和。

&emsp;&emsp;同样考虑最小割，此时 $e_i\to T$ 上的权值 $a_i$ 就是将元素 $e_i$ 划分到 $A$ 集合而割去 $e_i\to T$ 所需要的代价（$S\to e_i$ 上的容量同理为 $b_i$），在不考虑组合权值的流网络图中，此时最小割就等价于最小基础权值和。<br>
&emsp;&emsp;在引入组合权值后，以 $S\to u\to T$ 割去 $u\to T$ 和 $S\to v\to T$ 割去 $S\to v$ 为例，此时 $S\to T$ 仍然存在路径，由于前提是 $S\to u$ 和 $v\to T$ 存在，故添加一条 $u\to v$ 的有向边，容量为 $c_{uv}$，这样在割去 $u\to T$ 和 $S\to v$ 后还得考虑割去 $u\to v$ 的代价，同样的，考虑割边为 $S\to u$ 和 $v\to T$ 时需要添加一条 $v\to u$ 的有向边。

![[例图3 1.png]]

&emsp;&emsp;这样建图后，当 $u,v$ 被划分到一个集合中时，不会产生任何影响，只有当两者被划分到不同集合时，才会考虑割去 $c_{uv}$ 带来的代价，此时最小权值和等价于求解最小割。

### 流量平衡建模（线性规划建模）

&emsp;&emsp;对于一个约束等式方程组，每个变量 $x_i$ 恰好在两个等式中出现，一次带正号，一次带负号
$$\begin{cases}\dots+x_i\dots=c_j\\\dots-x_i+\dots=c_k\end{cases}.$$
求目标函数 $\min\sum w_i\cdot x_i$（其中 $x_i\ge0$）。

&emsp;&emsp;在流网络图中，除源点和汇点外，其它顶点都满足流量平衡，即对于每个顶点都有
$$\sum_{\langle u,x\rangle\in{E}}f\langle u,x\rangle=\sum_{\langle x,v\rangle\in{E}}f\langle x,v\rangle.$$
根据流量平衡的思想，可以通过以下步骤处理方程组：
1. 构建原始约束：按照题意列出所有线性不等式 $\sum\limits(\pm x_i)\ge c_i$ 和/或等式约束；
2. 转化为等式：引入非负松弛变量 $d_j\ge 0$ 将不等式转化为等式 $\sum\limits(\pm x_i)-d_j=c_j$；
3. 构造差分约束：将任意等式做差，使得所有核心变量 $x_i$ 恰好在两个等式中分别带有 $+1$ 和 $-1$ 出现，代表 $x_i$ 所表示的状态入流和出流。
考虑以下建图方式：
    - 将每一个约束等式 $j$ 视作图中的一个非源汇节点 $V_j$，用于强制流量平衡；建立 $S$ 和 $T$ 用于处理等式右侧的非零常数项 $c_j$。
    - 如果变量 $x_i$ 在等式 $j$ 中为 $+x_i$，在等式 $k$ 中为 $-x_i$，且该变量在目标函数中对应的系数为 $w_i$，那么由节点 $V_j$ 向节点 $V_k$ 连接有向边 $V_j\to V_k$，容量设置为 $\infty$，费用为 $w_i$。该边代表了变量 $x_i$ 的取值，$+x_i$ 在等式 $j$ 中，意味着 $V_j$ 节点有一个净流出项；$-x_i$ 在等式 $k$ 中，意味着 $V_k$ 节点有一个 $x_i$ 的净流入项。因此，$V_j\to V_k$ 上的流量恰好同时满足了两个等式的要求。此时，边上的费用 $w_i$ 对应目标函数中的成本，最小费用流即最小化 $\sum w_ix_i$。
    - 若变量 $y_i$ 在等式 $j$ 中为 $+y_i$，在等式 $k$ 中为 $-y_i$，且该变量对目标函数没有贡献（比如 $d_i$），那么连接有向边 $V_j\to V_k$，容量设置为 $\infty$，费用为 $0$，起到传递流的作用。
    - 由于整个流网络中，只有源点与汇点不满足流量守恒，故用这两个点充当流量补充和流量消耗，平衡所有等式右边的非零系数。由于等式 $j$ 必须满足 $$\sum\limits_{\langle j,k\rangle}f\langle j,k\rangle-\sum\limits_{\langle i,j\rangle\in E}f\langle i,j\rangle=c_j.$$
      如果等式 $j$ 的常数项 $c_j\gt0$，连边 $S\to V_j$ 容量为 $c_j$，代表净流入增加 $c_j$；如果等式 $c_j$ 为负数，连边 $V_j\to T$ 容量为 $|c_j|$，代表净流出 $-c_j$ 。

&emsp;&emsp;最后求解最小费用最大流，当且仅当最大流等于 $\sum_{c_j\gt0}c_j$ 时（所有 $S\to V_j$ 边的容量和），该线性规划问题才有解，否则无解，若有解则求得的最小费用即为目标函数最优解，且图上边 $V_j\to V_k$ 的流量即为变量 $x_i$ 的最优取值。

### 拆点建模

&emsp;&emsp;拆点即将一个点拆分为两个或多个点进行建模，通常具有以下两种作用：

1. 将点约束转化为边约束
   - 拆点目的：将点上的限制（容量/权值）转化为边上的限制（容量/费用）。
   - 具体方法：将原图中的 $u$ 拆分为两个节点 $u_{in}$ 和 $u_{out}$，并从 $u_{in}$ 向 $u_{out}$ 连一条有向边，边的容量设置为原点 $u$ 的容量或边的费用设置为原点 $u$ 的点权。原来指向 $u$ 的边现在指向 $u_{in}$；原来从 $u$ 出发的边现在从 $u_{out}$ 出发。

2. 状态空间的显性化
   - 拆点目的：将一个对象/位置在不同状态、时间、顺序或资源消耗下的情况显性表示为网络中的不同节点。
   - 具体方法：将原图中的一个对象 $O$ 根据状态定义拆分为多个节点 $O_1,O_2,O_3,\dots$，并根据状态转换来连边从而决定流的流向。若对于所有点都有这种多状态拆分时，即可视为分层图建模。

# 二分图

&emsp;&emsp;二分图的节点由两个不相交的集合 $X，Y$ 组成，且两个集合内部没有边。 

-   **二分图的判定**：由于 **二分图中不存在长度为奇数的环** ，对于一个给定的无向图，从任意一个点开始进行 $dfs$ 染色，相邻两个节点的颜色相异，如果两个顶点处于一个集合内但颜色不同，则该图不是二分图。

## 一、二分图初步

### 基础概念

1.   **匹配（独立边集）**：一张图中不具有公共端点的边的集合 $M$ ，在二分图中求匹配等价于网络流问题，匹配的大小定义为其中边的数量 $|M|$ 。匹配中的边称为 **匹配边**，反之称为 **未匹配边**。一个点属于 $M$ 中一条且至多一条边的端点，称为 **匹配点**，反之称为 **未匹配边** ，另有其它类型匹配：

-   **极大匹配**：无法再增加匹配边的匹配，不一定是最大匹配，类比于极大值与最大值的关系。
-   **最大匹配**：匹配边数 $|M|$ 最大的匹配，记为 $\alpha'(G)$ 。最大匹配可能不止一个，但 $|M|$ 的大小的确定的，并且满足 **小于等于图中顶点数的一半** 。
-   **最大权匹配**：加权图中，权值和最大的匹配。
-   **最大权最大匹配**：匹配数最多的前提下，边权和最大的匹配。即最大匹配中边权和最大的匹配。
-   **完美匹配**：所有点都属于匹配的情况，同时也是最大匹配。**顶点数为偶数的完全图必然存在完美匹配** 。当二分图的两个集合的点数相等时，其完美匹配又称为 **完备匹配** 。
-   **近完美匹配**：图的点数为奇数且恰好只有一个点不在匹配中。

2.   **增广路（交错路）**：始于非匹配边且路径由匹配边与非匹配边交错而成的，称为 **交错路** 。如果交错路的两端连接两个非匹配点，称为 **增广路** 。

&emsp;&emsp;增广路有以下两点性质：

1.   其长度 $len$ ，即路径所含边数为 **奇数** 。
2.   路径上第 $1,3,5,\dots,len$ 条边为非匹配边，第 $2,4,6,\dots,len-1$ 条边是匹配边。

&emsp;&emsp;如果将一条增广路上的所有边的状态取反，那么得到的新的边集 $M'$ 仍然是一组匹配，且 $|M'|=|M|+1$ ，那么可以得到结论：**二分图的一组匹配 $M$ 是最大匹配，当且仅当图中不存在 $M$ 的增广路**。故求最大匹配的过程本质就是不断进行增广的过程。

### 二分图与矩阵行列式

&emsp;&emsp;对于均衡二分图 $G=(U,V,E)$（左右集合元素个数相等），定义 $n\times n$ 的 $01$ 矩阵 $A$ 为其邻接矩阵：$A_{i,j}=1$ 若存在边 $(u_i,v_j)$，否则 $A_{i,j}=0$。容易发现，二分图完美匹配对应了其邻接矩阵中行列各不相同的位置且元素为 $1$ 的情况，此时，二分图的完美匹配表现为，存在一组边 $\{(u_{i_1},v_{j_1}),(u_{i_2},v_{j_2}),\dots,(u_{i_n},v_{j_n})\}$，使得 $i_1,\dots,i_n$ 和 $j_1,\dots,j_n$ 都为 $1\sim n$ 的排列。

&emsp;&emsp;回顾行列式的代数定义：
$$
\begin{aligned}
\det(A)=\sum\limits_{\sigma\in{S_n}}sign(\sigma)\cdot\prod_{i=1}^{n}A_{i,\sigma(i)}
\end{aligned}.
$$
其中：
- $S_n$ 是 $1\sim n$ 的所有排列构成的集合（共 $n!$ 个排列）。
- $\sigma$ 是一个排列，即将 $U$ 中的第 $i$ 个顶点匹配到 $V$ 中第 $\sigma(i)$ 个顶点。
- $sign(\sigma)$ 是排列的符号，偶排列为 $1$（排列存在偶数个逆序对），奇排列为 $-1$（排列存在奇数个逆序对）。
- $\prod_{i=1}^{n}A_{i,\sigma(i)}$ 是排列 $\sigma$ 对应的 **边乘积**：若所有 $A_{i,\sigma(i)}=1$（即排列 $\sigma$ 对应一组边 $(u_1,v_{\sigma(1)}),\dots,(u_n,v_{\sigma(n)})$），则乘积为 $1$；否则为 $0$（只要有一个 $A_{i,\sigma(i)}=0$，即 $i$ 没有对应的匹配，乘积为 $0$）。

对每个排列 $\sigma\in S_n$：
- 若 $\prod_{i=1}^{n}A_{i,\sigma(i)}=1$，则排列 $\sigma$ 恰好对应二分图的一个完美匹配（每个 $u_i$ 匹配到唯一的 $v_{\sigma(i)}$，且所有 $v$ 不重复）。
- 若 $\prod_{i=1}^{n}A_{i,\sigma(i)}=0$，则排列 $\sigma$ 不对应任何完美匹配（存在某个 $u_i$ 与 $v_{\sigma(i)}$ 无边）。

&emsp;&emsp;因此，行列式的定义重新解读为：$\det(A)=\sum_{完美匹配M}sign(\sigma_M)$，其中 $\sigma_M$ 是完美匹配 $M$ 对应的排列，求和仅遍历所有完美匹配。

&emsp;&emsp;在整数域 $\mathbb{Z}$ 中，单个完美匹配对应的排列的边乘积可能为 $1$ 或 $-1$，所以只能用于判断该二分图是否存在完美匹配。当矩阵行列式不为 $0$ 时，一定存在完美匹配，即邻接矩阵行列式为 $0$ 是二分图存在完美匹配的充分条件。但在模 $2$ 域 $\mathbb{F}_2$ 中，$-1\equiv1\mod{2}$，此时行列式的符号失去意义，简化为
$$\begin{aligned}\det_{\mathbb{F}_2}(A)=\sum_{\text{完美匹配}M}1\mod2\end{aligned}.$$
即 **行列式的值为完美匹配数量的奇偶性**：
- 若 $\det_{\mathbb{F}_2}(A)=1$，完美匹配数量为奇数。
- 若 $\det_{\mathbb{F}_2}(A)=0$，完美匹配数量为偶数（或 $0$)。

&emsp;&emsp;故可用高斯消元在 $O(n^3)$ 时间内解决二分图匹配的 parity 问题（判定完美匹配的奇偶性）。但在 $\mathbb{F}_2$ 域下，如果二分图的边以一种特殊形式给出，即对于每一个 $u_i$，其都与一组对应的 $[v_{l_i},v_{r_i}]$ 连边，那么邻接矩阵 $A_{i,l_{i}}\sim A_{i,r_i}$ 上都为 $1$，倘若另有 $j,k$ 分别满足 $A_{j,l_{j}}\sim A_{j,r_j}$ 和 $A_{k,l_{k}}\sim A_{k,r_k}$，且
$$\begin{aligned}l_i=l_j\le{r_j},r_j+1=l_k,l_k\le{r_k}=r_i\end{aligned}.$$
则 $(i,j,k)$ 对应的行向量是线性相关的（当存在两个行向量完全相等时，可以退化为二元组），即 $A_i=A_j+A_k$，得到的行列式也就一定为 $0$ 了，倘若并查集来维护，对于每个关系将 $l_i-1$ 与 $r_i$ 合并，如果两者合并之前已经在同一集合里，代表邻接矩阵中存在线性相关的行向量，复杂度为 $O(n)$。

## 二、二分图最大匹配（边独立集）

### 匈牙利算法（增广路算法）

&emsp;&emsp;该算法一开始将所有边设为非匹配边，然后不断重复寻找增广路，直到图中不存在增广路为止，其复杂度为 $O(VE)$。匈牙利算法依次尝试给每一个左部的节点 $x$ 找到一个匹配的右部的节点 $y$，该节点 $y$ 能与 $x$ 匹配需要满足：

1.   $y$ 本身为非匹配点，则无向边 $(x,y)$ 为一条非匹配边，自身构成一条长度为 $1$ 的增广路。
2.   $y$ 已经与一个左部点 $x'$ 匹配，但从 $x'$ 出发能够找到另外一个右部点 $y'$ 与之匹配，按照贪心策略，$x'$ 撤销与 $y$ 的匹配转而与 $y'$ 匹配，使得 $x$ 能够与 $y$ 匹配。此时路径 $P(x,y)$ 与 $P(x',y')$ 相连为新的一条增广路。

**Dfs 版**

```cpp
bool vis[N]; int match[N];
vector<vector<int>> g(N);

bool dfs(int u) {
    for(int v : g[u]) {
        if(vis[v]) continue;
        vis[v] = true; // 避免重复访问
        if(match[v] == -1 || dfs(match[v])) {
            match[v] = u;
            return true; // 找到增广路
        }
    }
    return false; // 未找到增广路
}

int hungarian(int n) {
    memset(match, -1, sizeof(match));
    int res = 0;
    for(int u = 0; u < n; u++) {
        memset(vis, false, sizeof(vis));
        if(dfs(u)) res++; // 找到增广路则最大匹配值增加
    }
    return res;
}
```

**Bfs 版**

```cpp
int px[N], py[N], pre[N], n, m;
bool g[N][N], vx[N], vy[N];

bool bfs(int s) {
    memset(pre, 0, sizeof(pre));
    memset(vx, false, sizeof(vx));
    memset(vy, false, sizeof(vy));
    queue<int> q;
    q.push(s);
    while(q.size()) {
        int u = q.front(); q.pop();
        vx[u] = true;
        for(int v = 1; v <= m; v++) {
            if(g[u][v] && !vy[v]) {
                vy[v] = true;
                pre[v] = u; // 记录路径
                if(py[v] == -1) {
                    while(v != -1) {
                        int t = px[pre[v]];
                        px[pre[v]] = v;
                        py[v] = pre[v];
                        v = t;
                    }
                    return true;
               } else q.push(py[v]);
            }
        }
    }
    return false;
}

int hungarian() {
    int res = 0;
    memset(px, -1, sizeof(px));
    memset(py, -1, sizeof(py));
    for(int i = 1; i <= n; i++) {
        if(bfs(i)) res++;
    }
    return res;
}
```

### Dinic 算法

&emsp;&emsp;将二分图转化为网络流模型：添加一个源点 $s$，连接上左边集合所有的点，每条边的容量设为 $1$；再添加一个汇点 $t$，连接上右边集合所有的点，容量同样设为 $1$；最后将原图中所有边改为从左到右的有向边，容量也设为 $1$。最后使用 **Dinic** 算法求网络最大流即可。算法复杂度为 $O(VE^2)$。

## 三、二分图完美匹配与 Hall 定理

&emsp;&emsp;Hall 定理给出了二分图 $G=(U\cup Y,E)$ 存在一个 $U-$ 完美匹配（即 $U$ 部的所有点都被匹配）的充要条件。
- **Hall 定理**：考虑一个二分图 $G=(U\cup V,E)$，$G$ 存在从 $U$ 到 $V$ 的匹配，当且仅当对于 $U$ 的任意子集 $A\subseteq U$，都有：$$|N(A)|\ge|A|$$
  其中 $N(A)$ 是 $A$ 中所有顶点的邻居集合（即与 $A$ 中顶点相连的 $V$ 中顶点的集合）。

&emsp;&emsp;倘若最多允许存在 $x(x\lt|U|)$ 个左部点得不到匹配，得到加强后的 Hall 定理。
- **亏缺 Hall 定理**：考虑一个二分图 $G=(U\cup V,E)$，$G$ 存在一个大小至少为 $|U|-x$ 的匹配（即 $U$ 部中最多有 $x$ 个点未被匹配），当且仅当对于 $U$ 的任意子集 $A\subseteq U$，都有：$$|N(A)|\ge|A|-x$$
  倘若左部 $U$ 中的第 $i$ 个点希望匹配 $r(i)$ 个右部 $V$ 中的点，即匹配带有容量约束，则被称为多重匹配，该匹配下有 Hall 定理的推广版本（在图论中称为因子理论或 $(r_1,r_2,\dots,r_n)-$ 因子的存在性条件）。
- **带容量的 Hall 定理推广**：考虑一个二分图 $G=(U\cup V,E)$，其中 $U=\{u_1,u_2,\dots,u_n\}$。若对于每位 $u_i\in U$ 都需要与 $r(u_i)$ 个不同且未被匹配过的右部点匹配，当且仅当对于 $U$ 的任意子集 $A\subseteq U$，都有：$$|N(A)|\ge\sum\limits_{u_i\in A}r(u_i)$$

## 四、二分图最大权完美匹配

### KM（Kuhn–Munkres）算法——匈牙利算法变种

1.   **可行顶标**<br>
给每个节点 $i$ 分配一个权值 $l(i)$，对于所有边 $\langle u,v\rangle$ 满足 $w\langle u,v\rangle\le l(u)+l(v)$ 。
2. **相等子图**<br>
在一组可行顶标下原图的生成子图，包含所有点但只包含满足 $w\langle u,v\rangle=l(u)+l(v)$ 的边 $\langle u,v\rangle$。

 &emsp;&emsp;**对于某组可行顶标，如果其相等子图存在完美匹配，那么该匹配就是原图的最大全完美匹配** 。

证明：

**Dfs 版**：对于随机数据，复杂度为 $O(n^3)$ ，但实际复杂度为 $O(n^4)$

```cpp
using ll = long long;

const ll INF = 0x3f3f3f3f3f3f3f3fll;
int match[N];
bool va[N], vb[N]; // 标记是否在交替路中
ll w[N][N], d[N], la[N], lb[N];
int n;

bool dfs(int x) {
    va[x] = 1;
    for(int y = 1; y <= n; y++) {
        if(vb[y] || la[x] + lb[y] != w[x][y]) continue; // 不在交替路中或不可行
        vb[y] = 1;
        if(!match[y] || dfs(match[y])) {
            match[y] = x;
            return true;
        } else {
            d[y] = min(d[y], la[x] + lb[y] - w[x][y]);
        }
    }
    return false;
}

ll KM() {
    memset(lb, 0, sizeof(lb));
    for(int i = 1; i <= n; i++) {
        la[i] = -INF;
        for(int j = 1; j <= n; j++) {
            // 初始化左部顶标为最大权值
            la[i] = max(la[i], w[i][j]);
        }
    }
    for(int i = 1; i <= n; i++) {
        // 直到找到一组匹配
        while(true) {
            fill(va + 1, va + 1 + n, 0);
            fill(vb + 1, vb + 1 + n, 0);
            fill(d + 1, d + 1 + n, INF);
            if(dfs(i)) break; // 找到增广路
            // 否则修改顶标
            ll delta = INF;
            for(int j = 1; j <= n; j++)
                if(!vb[j]) delta = min(delta, d[j]);
            for(int j = 1; j <= n; j++) {
                if(va[j]) la[j] -= delta;
                if(vb[j]) lb[j] += delta;
            }
        }
    }
    ll res = 0;
    for(int i = 1; i <= n; i++) {
        res += w[match[i]][i];
    }
    return res;
}
```

**Bfs 版**：复杂度为 $O(n^3)$

```cpp
using ll = long long;
const ll INF = 0x3f3f3f3f3f3f3f3fll;

ll px[N], py[N], slack[N];
bool vx[N], vy[N]; // 标记是否在交替路中
ll w[N][N], pre[N], lx[N], ly[N];
int n, m;

// 需要保证 n >= m
void augment(int v) {
    while(v != -1) {
        int t = px[pre[v]];
        px[pre[v]] = v;
        py[v] = pre[v];
        v = t;
    }
}

void bfs(int s) {
	memset(slack, 0x3f, sizeof(slack));
    memset(pre, -1, sizeof(pre));
    memset(vx, false, sizeof(vx));
    memset(vy, false, sizeof(vy));
    queue<int> q; q.push(s);
    while(true) {
        while(q.size()) {
            int u = q.front(); q.pop();
            vx[u] = true;
            for(int v = 1; v <= m; v++) {
                if(vy[v] || lx[u] + ly[v] - w[u][v] >= slack[v]) continue; // 不在交替路中或不可行
                slack[v] = lx[u] + ly[v] - w[u][v]; // 更新slack
                pre[v] = u; // 记录前驱
                if(!slack[v]) {
                    vy[v] = true; // 找到增广路
                    if(py[v] == -1) {
                        augment(v);
                        return;
                    } else q.push(py[v]);
                }
            }
        }
        ll delta = INF;
        for(int i = 1; i <= m; i++) {
            if(!vy[i]) delta = min(delta, slack[i]); // 找到最小的 slack
        }
        if(delta == INF) return; // 找不到增广路
        // 更新顶标
        for(int i = 1; i <= n; i++) if(vx[i]) lx[i] -= delta;
        for(int i = 1; i <= m; i++) {
            if(vy[i]) ly[i] += delta;
            else slack[i] -= delta;
        }
        for(int i = 1; i <= m; i++) {
            if(!vy[i] && !slack[i]) {
                vy[i] = true;
                if(py[i] == -1) {
                    augment(i);
                    return;
                } else q.push(py[i]);
            }
        }
    };
}

ll km() {
    memset(px, -1, sizeof(px));
    memset(py, -1, sizeof(py));
    for(int u = 1; u <= n; u++) {
    	lx[u] = -INF;
        for(int v = 1; v <= m; v++) lx[u] = max(lx[u], w[u][v]);
    }
    for(int i = 1; i <= n; i++) bfs(i);
    ll ans = 0;
    for(int i = 1; i <= n; i++) {
    	if(px[i] != -1) ans += w[i][px[i]];
    }
    return ans;
}

int main() {
	ll k;
	cin >> n >> m >> k;
	for(int i = 1; i <= n; i++) {
		for(int j = 1; j <= m; j++) w[i][j] = -INF;
	}
	while(k--) {
		ll x, y, wit; cin >> x >> y >> wit;
		w[x][y] = wit;
	}
	cout << km() << endl;
    // 输出匹配
	for(int i = 1; i <= n; i++) {
		cout << i << " " << px[i] << " \n"[i == n];
	}
    return 0;
}
```

### Dinic 算法

&emsp;&emsp;在图中新增一个源点一个汇点，从源点向二分图的每个左部点连一条流量为 $1$ ，费用为 $0$ 的边；从二分图的每个右部点向汇点连一条流量为 $1$，费用为 $0$ 的边；对于原图中每一条边 $\langle u,v\rangle$，边权为 $w$，连接一条从 $u$ 到 $v$，流量为 $1$，费用为 $w$ 的边。<br>
&emsp;&emsp;另外在最大权匹配下，匹配边的数量不一定与最大匹配的匹配边数量相等，因此对于每个左部点，还需向汇点连一条流量为 $1$，费用为 $0$ 的边。
此时转化为了网络流模型，即等价于求解 **最大费用最大流** ，将边权置为相反数，再跑一遍最小费用最大流即可。

## 五、二分图最小点覆盖

- **点覆盖**：点覆盖是顶点集 $V$ 的一个子集 $V'\subseteq{V}$，使得图中每一条边都至少有一个端点在 $V'$ 中。也就是说，点覆盖中的顶点能够 **覆盖** 住所有的边。在图 $G$ 的所有点覆盖中，顶点个数 $|V'|$ 最少点覆盖称为 **最小点覆盖** ，最小点覆盖的顶点个数被称为 **点覆盖数** ，记为 $\beta(G)$ 。 

### König 定理

**$\text{K\"onig}$ 定理**：在二分图中，**最大匹配的边数等于最小点覆盖的点数** ，这个定理揭示了二分图中覆盖与匹配的对偶性。

- **证明**：对于一个二分图 $G=(V,E)$，最大匹配 $M$ 的边数为 $m$，最小点覆盖 $C$ 的点数为 $n$ ，且 $m\neq{n}$ 。由于最大匹配是原二分图图集的一个子集，该集合中所有边都不相交，那么每一条匹配边都至少需要一个点覆盖，则最大匹配的边数一定小于等于最小点覆盖的点数。
  
  设 $M=\{e_1,e_2,\dots,e_m\}$ 为图 $G$ 的一个最大匹配，因为 $C$ 是点覆盖，所以 $C$ 要覆盖 $M$ 中的所有边，即 $M$ 中的每一条边 $e_i$ 的两个端点至少有一个在 $C$ 中。
  
  现在从 $C$ 中去掉一个点 $v$ ，由于 $C$ 是最小点覆盖，去掉 $v$ 后，必然存在一条匹配边 $e_j$ ，其两个端点都不在 $C-\{v\}$ 中，这意味着 $C-\{v\}$ 不能覆盖所有的匹配边，进而不能覆盖图 $G$ 的所有边，所以 $C-\{v\}$ 不是点覆盖。
  
  此时考虑边集 $M$ ，其有 $m$ 条边，而 $C-\{v\}$ 有 $n-1$ 个点，且 $m\lt{n}$ ，那么 $m\le{n}-1$ 。这就意味着存在一种方式可以用 $n-1$ 个点来覆盖 $m$ 条匹配边，即存在一个比 $C$ 更小的点集可以覆盖所有匹配边，与 $C$ 为最小点覆盖矛盾。
  
  所以假设 $m\lt{n}$ 不成立，只能 $m=n$，即最大匹配的边数等于最小覆盖的点数。

### 二分图最小点权覆盖集

&emsp;&emsp;给定一个带点权二分图 $G=(V,E)$ ，其中 $V=X\cup{Y}$ ，即 $Y=\overline{X}$ ，另有 $\forall{v}\in{V}$ ，都被分配了一个非负点权 $w(v)$ 。记该图的一个覆盖集的点权为 $w(V')=\sum_{v\in{V'}}w(v)$ ，其中，
$w(V')$ 最小的即为最小点权覆盖集。

&emsp;&emsp;根据 $\text{K\"onig}$ 定理的带权推广 ，考虑到最大边权独立集（匹配）和最小点权覆盖集之间的对偶性，二分图的最小点权覆盖集可以通过构造流网络的最小割求解。其核心逻辑如下：
- 将点覆盖的 **选点** 决策转化为流网络中 **割边** 的选择。
- 利用流网络中割的性质（源汇不流通）对应点覆盖的约束（每条边至少选择一个端点）。

&emsp;&emsp;构造流网络 $N=(V_N,E_N)$ ，其中 $V_n=X\cup{Y}\cup\{s,t\}$ 。对于边集 $E_N$ ，，从源点 $s$ 向 $X$ 中每个顶点 $u$ 连边 $\langle s,u\rangle$ ，容量大小为 $w(u)$（表示选择 $u$ 的代价）；从 $Y$ 中每个顶点 $v$ 向汇点 $t$ 连边，容量大小为 $w(v)$（表示选择 $v$ 的代价）；对于原图中每条边 $\langle u,v\rangle\in{E}$ ，从 $u$ 向 $v$ 连一条容量为 $+\infty$ 的边。

- **无穷大容量的边确保其不会被包含在最小割中，从而将割的选择限制在与源汇相连的边上，即简单割**。

&emsp;&emsp;此时求解最小割，对于网络中的一条路径 $s\rightarrow{u}\rightarrow{v}\rightarrow{t}$ ，不可能为 $u\rightarrow{v}$ （容量无穷大），只能是 $s\rightarrow{u}$ 和 $v\rightarrow{t}$ 二选一，对应最小点覆盖集的约束中每条边只能二选一一个端点。那么 **最小割的容量即为最小点权覆盖集的权值** 。

## 六、Gallai 定理

### 概念与定义

- **独立集**：对于一个图 $G=(V,E)$ ，如果有一个顶点子集 $S\subseteq{V}$ ，使得 $S$ 中任意两个顶点之间都没有边相连，那么称 $S$ 是图 $G$ 的一个独立集。在所有独立集中，包含顶点数量最多的独立集被称为 **最大独立集** ，$|S|$ 表示独立集 $S$ 中的顶点个数。最大独立集的顶点个数称为图 $G$ 的 **独立数** ，记为 $\alpha(G)$ 。
- **边覆盖集**：对于一个图 $G=(V,E)$ ，如果有一个边子集 $E'\subseteq E$ ，使得 $V$ 中的每个顶点至少与 $E'$ 中的一条边关联。即，$\forall v\in V$ ，都 $\exists e\in E'$ ，使得 $e$ 包含顶点 $v$ ，称 $E'$ 为一个边覆盖集。在所有边覆盖集中，边数 $|E'|$ 最少的边覆盖集被称为 **最小边覆盖集** 。最小边覆盖集的边数被称为图 $G$ 的 **边覆盖数** ，记为 $\beta'(G)$ 。

**$Gallai$ 定理**：
- 对于任意图 $G$，有 $\alpha(G)+\beta(G)=n$。
- 对于无孤立点的图 $G$，有 $\alpha'(G)+\beta'(G)=n$

&emsp;&emsp;即：**独立数=点数-点覆盖数** ，**边独立数=点数-边覆盖数** ，两对集合之间两两互为补集。<br>
&emsp;&emsp;在二分图中：由 $\text{K\"onig}$ 定理有 $\alpha'(G)=\beta(G)$ ，结合 $Gallai$ 定理可得 $\alpha(G)=\beta'(G)$ 。

- **证明** ：
	  1. $\alpha(G)\le n-\beta(G)$ ：设 $K$ 为 $G$ 的一个最小点覆盖，即 $|K|=\beta(G)$ 。考虑 $V-K$ 这个顶点集合，假设 $\exists u,v\in V-K$ ，使得 $(u,v)\in E$ ，那么 $K$ 就不是点覆盖，因为存在一条边，其两个端点都不在 $K$ 中，与假设矛盾。则 $\forall u,v\in V-K$ ，都满足 $(u,v)\notin E$ ，那么 $V-K$ 是一个独立集。由于 $|V-K|=n-|K|=n-\beta(G)$ ，那么可得 $\alpha(G)\le|V-K|=n-\beta(G)$ 。
	  2. $\alpha(G)\ge n-\beta(G)$ ：设 $I$ 为 $G$ 的一个最大独立集，即 $|I|=\alpha(G)$ 。考虑 $V-I$ 这个顶点集合，$\forall u,v\in V$ ，不可能使得 $\exists u,v\in I$ ，因为 $I$ 是独立集，任意两个顶点不相邻，所以两个顶点至少有一个在 $V-I$ 中。这说明 $V-I$ 是一个点覆盖。由于 $|V-I|=n-|I|=n-\alpha(G)$ ，那么可得 $\beta(G)\le|V-I|=n-\alpha(G)$ ，即 $\alpha(G)\ge n-\beta(G)$ 。
	  3. 由上述两点得证，对于一般图 $G$ ，有 $\alpha(G)=n-\beta(G)$ 。
	  4. 同理可用反证法证得 $\alpha'(G)=n-\beta'(G)$ 。

&emsp;&emsp;同样的，对于带权扩展有：
$$
\begin{aligned}
最大点权独立集权值和+最小点权覆盖集权值和=\sum_{v\in{V}}w(v)
\end{aligned}.
$$
而最大边权匹配与最小边权覆盖没有类似的结论。

---

### 二分图最小权边覆盖

&emsp;&emsp;对于原图，新建源点 $s$ 和汇点 $t$ ，从源点 $s$ 向左部 $X$ 中所有顶点连边，容量 $c\langle s,u\rangle=1$ ，费用 $w\langle s,u\rangle=0$（确保每个 $u\in{X}$ 最多被匹配一次）；从右部 $Y$ 中所有顶点向汇点 $t$ 连边，容量与费用与前者相同（确保每个 $v\in{V}$ 只被匹配一次）；最后保留原二分图的所有边 $\langle u,v\rangle\in{E}$，容量无穷大且权重不变。<br>
&emsp;&emsp;现在在该网络上跑一遍最小费用最大流，在确保尽可能多的顶点被覆盖（最大流）的同时，保证总费用最小（优先选权值更小的边）。

## 七、二分图与最小路径覆盖

### 最小路径覆盖

&emsp;&emsp;**路径覆盖**：在有向无环图 $G=(V,E)$ 中路径覆盖是指一个路径集合 $P$ ，使得图中每个顶点恰好属于 $P$ 中的一条路径。这里的路径可以是单个顶点，也可以是多条连续的边连接的多个顶点序列。在所有可能的路径覆盖中，路径数量最少 $|P|$ 的路径覆盖，被称为 **最小路径覆盖** 。

&emsp;&emsp;**DAG 最小路径覆盖定理**：对于任意有向无环图（DAG）$G=(V,E)$ ，定义 $G'=(V_{l}\cup V_{r},E')$ 为原图 $G$ 的 **拆点二分图** （也称二分图模型），其构造方法如下：
1. 将原图 $G$ 的每个顶点拷贝出两个副本 $V_{l},V_{r}$ 。
2. 对于原图中每一条有向边 $\langle u,v\rangle$ ，在 $G'$ 中建立对应的有向边 $\langle u_l,v_r\rangle$ 。 
在二分图 $G'$ 中，每次找到一条匹配边 $\langle u_l,v_r\rangle$ ，相当于在原图 $G$ 中合并两条路径（如：对于一条匹配边 $\langle u_l,k_r\rangle$ ，如果另有一条匹配边 $\langle k_l,v_r\rangle$ ，则可以合并路径为 $u\rightarrow v$ ），从而减少一条路径。那么有：
$$
\begin{aligned}
|P|_{\min}=n-\alpha'(G')
\end{aligned}
$$
即：**最小路径覆盖数=原图节点数-拆点二分图的边独立数** 。

### 最小可相交路径覆盖（可重复点路径覆盖）

&emsp;&emsp;在可重复点最小路径覆盖中，若有两条路径 $\dots\rightarrow{u}\rightarrow{p}\rightarrow{v}\rightarrow\dots$ 和 $\dots\rightarrow{x}\rightarrow{p}\rightarrow{y}\rightarrow\dots$ 在 $p$ 点相交，可以直接在原图中添加边 $\langle x,y\rangle$ ，让第二条路线变换为 $x\rightarrow{y}$ ，避免了重复覆盖点 $p$ 。因此，如果将原图中所有间接连通点对 $u, v$ 连上有向边 $\langle u,v\rangle$ ，那么**可重复点路径覆盖就转化为了无重复点路径覆盖** 。<br>
&emsp;&emsp;故先对有向图做传递闭包（即 Floyd 算法），得到有向无环图 $G'$ 后，再在 $G'$ 上求一般最小路径点覆盖。

### 最多不相交路径问题

&emsp;&emsp;这个是在固定起点和终点情况下最大化路径数量问题，通常是寻找在满足特定约束下（如节点/边限制）和长度限制（如最短路）的最大路径集合，一般采用最大流解决，建模方法如下：
- 拆点：将每个节点 $u$ 拆分为 $u_{in}$ 和 $u_{out}$，并在两者之间连边，容量设为该节点最多可经过次数（即路径条数）。
- 连边：图中边的容量设为该边最多可经过的次数。

### 最小路径边覆盖

&emsp;&emsp;与最小路径覆盖不同的是，这里是要找到最小的路径数量 $|P|$，使得所有的边被覆盖。通常的做法是建立对应的线图 $L(G)$：
- 将每一条边视作一个点，对于原 DAG 中的任意 $e_1=\langle u,v\rangle,e_2=\langle v,w\rangle\in E$，连边 $e_1\to e_2$。需要注意的是线图的边数是
  $$\begin{aligned}
  |E(L(G))|=\sum\limits_{v\in V}\deg^-(v)\deg^+(v).
  \end{aligned}$$

&emsp;&emsp;这样原图的边覆盖就转换为了点覆盖模型，根据是否可重（注意边覆盖中的不可重复指边不重复，点可以重复）选择对应的模型即可。<br>
&emsp;&emsp;但在这里需要探讨的是基于平面图与 DAG 偏序、对偶图更深的联系，以下面这道题为例：[滑雪者](https://qoj.ac/problem/11492/statement/zh_cn)。

- 题目大意：给定一个平面图，图中有 $n(2\le n\le 5000)$ 个点，有一个最高点 $S$ 和一个最低点 $T$，$m$ 条有向边，且保证每条边都是从高到低，即形成一个 DAG。对于图中任意一点 $u$，保证存在路径 $S\leadsto T$ 经过 $u$。如下图所示：
  ![[最小路径边覆盖题目大意图.png|532]]

&emsp;&emsp;转化为线图，根据可重复点路径覆盖，需要先做传递闭包，如果采用一般 Floyd 则会 TLE。考虑 DAG 的线图也是 DAG，用 bitset 记录每个点的可达情况，对线图 DAG 进行拓扑排序，逆序遍历拓扑序列：
$$\begin{aligned}
\text{Reach}(u)={u}\cup\bigcup_{u\to v}\text{Reach}(v).
\end{aligned}$$
&emsp;&emsp;这样确实解决了传递闭包的复杂度问题，但同样导致了 MLE。而且后续显式构造二分图的 $O(n^2)$ 条边是根本性瓶颈，无论怎么优化都无法通过大数据，所以在模型层面上该问题无法应用可重复点路径覆盖。

```cpp
#include <bits/stdc++.h>
#define endl '\n'
#define pb push_back

using namespace std;

using ll = long long;
using vi = vector<int>;
using vvi = vector<vector<int>>;
using pii = pair<int, int>;

const int INF = 0x3f3f3f3f;
const int N = 1e5 + 10;

vvi g(N), lg(N);

struct Edge {
    int v, c, nxt;
} edges[10 * N];

int tot = 1;
int head[N], dep[N], cur[N];
int S, T;

void add(int u, int v, int c) {
    edges[++tot] = {v, c, head[u]};
    head[u] = tot;
    edges[++tot] = {u, 0, head[v]};
    head[v] = tot;
}

bool bfs() {
    memset(dep, 0, sizeof(dep));
    queue<int> q;
    q.push(S);
    dep[S] = 1;
    while(!q.empty()) {
        int u = q.front();
        q.pop();

        for(int i = head[u]; i; i = edges[i].nxt) {
            int v = edges[i].v;
            if(!dep[v] && edges[i].c > 0) {
                dep[v] = dep[u] + 1;
                q.push(v);
            }
        }
    }

    return dep[T] != 0;
}

int dfs(int u, int mf) {
    if(u == T) return mf;
    int sum = 0;
    for(int &i = cur[u]; i; i = edges[i].nxt) {
        int v = edges[i].v;

        if(dep[v] != dep[u] + 1 || edges[i].c <= 0)
            continue;

        int res = dfs(v, min(edges[i].c, mf - sum));

        edges[i].c -= res;
        edges[i ^ 1].c += res;
        sum += res;

        if(sum == mf)
            break;
    }

    if(!sum)
        dep[u] = 0;

    return sum;
}

ll dinic() {
    ll flow = 0;
    while(bfs()) {
        memcpy(cur, head, sizeof(head));
        flow += dfs(S, INF);
    }
    return flow;
}

void solve() {
    int n; cin >> n;
    for(int u = 1; u < n; u++) {
        int k;
        cin >> k;

        while(k--) {
            int v;
            cin >> v;
            g[u].pb(v);
        }
    }

    int m = 0;
    map<pii, int> id;
    vi in(N);

    for(int u = 1; u < n; u++) {
        for(int v : g[u]) {
            if(!id[{u, v}])
                id[{u, v}] = ++m;
            int e1 = id[{u, v}];
            for(int w : g[v]) {
                if(!id[{v, w}])
                    id[{v, w}] = ++m;
                int e2 = id[{v, w}];
                lg[e1].pb(e2);
                in[e2]++;
            }
        }
    }

	// topo
    vi topo;
    topo.reserve(m);

    queue<int> q;

    for(int i = 1; i <= m; i++) {
        if(!in[i])
            q.push(i);
    }

    while(!q.empty()) {
        int u = q.front(); q.pop();
        topo.pb(u);
        for(int v : lg[u]) {
            if(--in[v] == 0)
                q.push(v);
        }
    }
    
    // 闭包
    vector<bitset<N>> reach(m + 1);
    for(int i = (int)topo.size() - 1; i >= 0; i--) {
        int u = topo[i];
        reach[u].set(u);
        for(int v : lg[u])
            reach[u] |= reach[v];
    }

	// dinic
    S = 0;
    T = 2 * m + 1;

    for(int i = 1; i <= m; i++) {
        add(S, i, 1);
        add(i + m, T, 1);
    }

    for(int i = 1; i <= m; i++) {
        for(int j = 1; j <= m; j++) {
            if(i != j && reach[i][j])
                add(i, j + m, 1);
        }
    }

    cout << m - dinic() << endl;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    solve();
    return 0;
}
```

#### 上下界最小流

&emsp;&emsp;考虑一般网络流模型，边覆盖代表着对于每条边，都要有下界为 $1$ 的流量。因此该题目可以转换为上下界最小流求解，但在求解可行流的时候，对于每条边 $\langle u,v\rangle$，可以直接遍历增加 $1$ 点流量到 $S\leadsto u,u\to v,v\leadsto T$，无需额外跑网络流求解，但需要注意的是建边时反向边流量要设置为 $-1$，保证退流时至少有 $1$ 点流量，之后再求最大反向流并减去即可（也可以用一般的最小可行流求法）。复杂度为 $O(n^2)$。

```cpp
#include<bits/stdc++.h>
#define endl '\n'
#define pb push_back

using namespace std;
using ll = long long;
using pii = pair<int, int>;

const ll LLINF = 0x3f3f3f3f3f3f3f3fll;
const int N = 5e3 + 10;

struct edge {
	ll v, c, nxt;
} edges[20 * N];

int tot = 1, head[N], S, T, n, m;
int d[N], cur[N];
vector<pii> in(N), out(N);
ll FLOW;

void add(int u, int v, ll c) {
	edges[++tot] = {v, c, head[u]};
	head[u] = tot;
	edges[++tot] = {u, -1, head[v]};
	head[v] = tot;
}

bool bfs() {
	memset(d, 0, sizeof(d));
	queue<int> q;
	q.push(S); d[S] = 1;
	while(q.size()) {
		int u = q.front(); q.pop();
		for(int i = head[u]; i; i = edges[i].nxt) {
			int v = edges[i].v;
			if(!d[v] && edges[i].c > 0) {
				d[v] = d[u] + 1;
				q.push(v);
				if(v == T) return true;
			}
		}
	}
	return false;
}

ll dfs(int u, ll mf) {
	if(u == T) return mf;
	ll sum = 0;
	for(int &i = cur[u]; i; i = edges[i].nxt) {
		int v = edges[i].v;
		if(d[v] == d[u] + 1 && edges[i].c > 0) {
			ll res = dfs(v, min(edges[i].c, mf - sum));
			edges[i].c -= res;
			edges[i ^ 1].c += res;
			sum += res;
			if(sum == mf) break;
		}
	}
	if(!sum) d[u] = 0;
	return sum;
}

ll dinic() {
	ll flow = 0;
	while(bfs()) {
		memcpy(cur, head, sizeof(head));
		flow += dfs(S, LLINF);
	}
	return flow;
}

void dfs_path(int u, int forward) {
	if(forward) {
		if(u == S) return;
		edges[in[u].second].c++;
		dfs_path(in[u].first, forward);
		return;
	}
	
	if(u == T) return;
	edges[out[u].second ^ 1].c++;
	dfs_path(out[u].first, forward);
}

void solve() {
	cin >> n;
	S = 1, T = n;
	for(int u = 1; u < n; u++) {
		int k; cin >> k;
		m += k;
		for(int j = 1; j <= k; j++) {
			int v; cin >> v;
			add(u, v, LLINF);
			in[v] = {u, tot}, out[u] = {v, tot - 1};
		}
	}
	
	for(int u = 1; u < n; u++) {
		for(int i = head[u]; i; i = edges[i].nxt) {
			if(edges[i ^ 1].c >= 0) continue;
			int v = edges[i].v;
			edges[i ^ 1].c++;
			dfs_path(v, 0);
			dfs_path(u, 1);
			FLOW++;
		}
	}
	
	swap(S, T);
	cout << FLOW - dinic() << endl;
}

int main() {
	ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
	solve();
	return 0;
}
```

&emsp;&emsp;事实上，对于一般的最小路径点覆盖，也可以通过拆点用上下界最小流模型解决。将每个点 $v$ 拆成 $v_\text{in},v_\text{out}$，那么路径经过顶点 $v$ 就等价于流经过这条拆点边。

&emsp;&emsp;对于不允许路径之间重复顶点，要求每个顶点恰好被一条路径覆盖，因此设置
$$\begin{aligned}1\le f(v_\text{in},v_\text{out})\end{aligned}\le 1.$$
对于原图边 $u\to v$，连边 $u_\text{out}\to v_\text{in},0\le f\le 1$，再增加源汇 $S\to v_\text{in},v_\text{out}\to T$，容量都设为 $[0,1]$。最后求最小 $S-T$ 可行流即可。

&emsp;&emsp;如果允许不同路径重复经过顶点，这时只要求每个点至少被覆盖一次，于是拆点边改为 $[1,+\infty)$。原边 $u_\text{out}\to v_\text{in},S\to v_\text{in},u_\text{out}->T$ 也同样改为 $[0,+\infty)$，然后仍然求最小 $S-T$ 可行流。

&emsp;&emsp;但上述的基础都建立在 DAG 上，即不存在有向环，所以一个正数可行流一定可以被分解成若干 $S\to T$ 路径。如果原图存在环，那么下界可能被一个纯环流满足。基于该思路可以更通用的解决多次点覆盖问题，即求出最小可重复路径数，要求对于每个点 $v$，至少覆盖其 $r_v$ 次。若使用二分图，则要做顶点复制（复杂度差）或二分图 $b$-匹配（通常还是转化为网络流求解）。

#### 偏序集

&emsp;&emsp;原题实际上给出的图相当于一个偏序结构，原图也可以看作一个哈斯图。对于任意两点 $u,v$，定义偏序 $\preceq$ 关系为 DAG 上可达 $\leadsto$：
- 自反性：任意节点可达自身；
- 反对称性：若 $u\preceq v\land v\preceq u$，那么 $u,v$ 两点必定是同一点（DAG 不存在有向环）；
- 传递性：若 $a\preceq b,b\preceq c$，那么 $a\preceq c$，显然可以通过拼接路径得到。

&emsp;&emsp;但由于原题要求的是边覆盖，于是将偏序集中的对象变成每一条有向边，同样可以定义偏序关系为 DAG 上可达，即对于任意两边
$$\begin{aligned}\langle a,b\rangle,\langle c,d\rangle\mid b\leadsto c\end{aligned}.$$
那么即满足 $\langle a,b\rangle\preceq\langle c,d\rangle$（$b,c$ 可为同一点），此时三条性质依然成立。

&emsp;&emsp;考虑原题意中的可重复路径边覆盖，对于每一条合法路径，由于上面的每一条边都互相满足偏序关系，那么该合法路径上的所有边构成了 **链**（即上面的任意两个元素都是可比的），哪怕原题并未要求路径一定从 $S$ 到 $T$，根据可重复原则，也是可以扩展为 $S\leadsto T$。<br>
&emsp;&emsp;现在原题意即可转换为，求出最小的链的数量，覆盖边偏序集上的所有元素，即覆盖所有的边。根据 Dilworth 定理，该问题又可以等价于求出最长的 **反链**，反链中的任意两个元素都是不可比的，即求出一个最大的边集合大小，使得集合中不存在两条边，其中的一条通过 DAG 可达另一条。

&emsp;&emsp;故现在问题转换成了求解最长反链的长度，观察原示例图中的最长反链：

![[最长反链示意图.png|560]]

如果将左侧的空白视为 $F_L$，右侧的空白视为 $F_R$，可以发现：**最长反链长度对应该 DAG 对偶图上的最长路**。

>[!proof]+ Proof
>&emsp;&emsp;将原图的外部面沿 $S,T$ 拆成左侧外部面 $F_L$ 和右侧外部面 $F_R$，对于每条原图有向边 $e:u\to v$，沿 $u\to v$ 方向观察，记其左侧面、右侧面为 $L(e),R(e)$。在对偶图 $G^*$ 中建立有向边 $e^*:L(e)\to R(e)$，并赋权 $w(e^*)=1$。定向平面 $st$ 图有一个标准性质——$G^*$ 仍是 DAG，源点为 $F_L$，汇点为 $F_R$。因此可以定义
>$$\begin{aligned}L=\text{dist}_{max}^{G^*}(F_L,F_R)\end{aligned},$$
>也就是对偶图从左外部面到右外部面的最长路径长度。定义
>$$\begin{aligned}w=\max\{|A|:A\subseteq E\land A 是反链\}\end{aligned},$$
>需要证明 $w=L$。
>---
>- 引理 $1$：任意原图 $s\to t$ 路径与任意 $F_L\to F_R$ 路径恰好相交一次。
>
>&emsp;&emsp;设 $P$ 是原图一条有向 $s\to t$ 路径，由于 $P$ 是平面中的一条简单曲线，它把从 $s$ 到 $t$ 的局部平面分成 $P$ 的左侧和右侧。现在考虑一条对偶路径 $Q:F_L\leadsto F_R$，它必然至少穿过 $P$ 一次；若穿过 $P$ 两次，则代表 $G^*$ 存在一条边由 $P$ 的右侧面指向左侧面，与定义矛盾。故任意 $s\to t$ 路径只会与任意对偶图路径相交于原图的唯一一条边，即
>$$\begin{aligned}|P\cap Q|=1\end{aligned}.$$
>---
>- 引理 $2$：任意对偶图路径上的原边构成反链。
>  
>&emsp;&emsp;设对偶路径
>$$\begin{aligned}Q:F_L\xrightarrow{e_1^*}F_1\xrightarrow{e_2^*}\dots\xrightarrow{e_k^*}F_R\end{aligned}.$$
>取对应的原图边集合
>$$\begin{aligned}A_Q=\{e_1,e_2,\dots,e_k\}.\end{aligned}$$ 证明 $A_Q$ 是反链，反设其中存在 $e_i\prec e_j$，根据偏序定义，走完 $e_i$ 后可达 $e_j$ 的起点，所以可以评出一条原图 $s\to t$ 路径 $P$，同时经过 $e_i,e_j$，那么对偶路径 $Q$ 与 $P$ 至少相交两次——$e_i^*,e_j^*$，与引理 $1$ 矛盾。故 $A_Q$ 是反链，从而任何对偶路径长度都不超过最大反链：
>$$\begin{aligned}|Q|\le w.\end{aligned}$$
>取最长路径长度 $L\le w$，引理 $2$ 得证。
>---
>&emsp;&emsp;现在考虑证明 $w\le L$，在对偶 DAG 上定义最长路势函数，令
>$$\begin{aligned}d(F)=F_L\leadsto F\end{aligned}$$
>表示到 $F$ 的最长路径长度，显然有 $d(F_L)=0,d(F_R)=L$。对于每条原图边 $e$，对应对偶边
>$$\begin{aligned}e^*:L(e)\to R(e)\end{aligned}.$$
>由于该对偶边权值为 $1$，有
>$$\begin{aligned}d(R(e))\ge d(L(e))+1\end{aligned}.$$
>定义原图边上的整数为：
>$$\begin{aligned}f(e)=d(R(e))-d(L(e))\end{aligned}.$$
>显然有 $f(e)\ge1$，代表每条原图边至少有一个单位流，这与模型要求是一致的，但这只是定义在边上的整数函数，接下来考虑证明 $f$ 是一个合法 $s-t$ 流。<br>
>---
>&emsp;&emsp;取任意内部顶点 $v$，按照顺时针顺序列出与 $v$ 相邻的边：
>$$\begin{aligned}e_1,e_2,\dots,e_k.\end{aligned}$$
>记相邻两条边之间的面为
>$$\begin{aligned}F_0,F_1,\dots,F_{k-1}\end{aligned}.$$
>指标模 $k$。对每条关联边 $e_i$，分两种情况：
>1. 如果 $e_i$ 是出边，则沿边方向观察有
>   $$\begin{aligned}L(e_i)=F_{i-1},R(e_i)=F_{i}\end{aligned}.$$
>   因此
>   $$\begin{aligned}f(e_i)=d(F_i)-d(F_{i-1})\end{aligned}.$$
>2. 如果 $e_i$ 是入边，则沿边方向观察有
>   $$\begin{aligned}L(e_i)=F_{i},R(e_i)=F_{i-1}\end{aligned}.$$
>   因此
>   $$\begin{aligned}f(e_i)=d(F_{i-1})-d(F_i)\end{aligned}$$
>
>于是有：
>$$\begin{aligned}\sum\limits_{e\in\delta^+(v)}f(e)-\sum\limits_{e\in\delta^-(v)}f(e)=\sum\limits_{i=1}^k[d(F_i)-d(F_{i-1})]=0\end{aligned}.$$
>故：
>$$\begin{aligned}\sum\limits_{e\in\delta^+(v)}f(e)=\sum\limits_{e\in\delta^-(v)}f(e)\end{aligned}.$$
>所以所有内部顶点满足流量守恒。
>---
>&emsp;&emsp;考虑源点 $s$，所有关联边都从 $s$ 向外，按从左到右排列源点的出边：
>$$\begin{aligned}e_1,e_2,\dots,e_k.\end{aligned}$$
>相邻面依次为
>$$\begin{aligned}F_L=F_0,F_1,\dots,F_k=F_R\end{aligned}.$$
>于是源点总流出量：
>$$\begin{aligned} |f|=\sum\limits_{i=1}^kf(e_i)=\sum\limits_{i=1}^k[d(F_i)-d(F_{i-1})]=d(F_R)-d(F_L)=L \end{aligned}.$$
>因此从对偶最长路距离函数构造出了一个原图整数流。由于图中没有有向环，根据流分解定理，可以不断从 $s$ 找到一条正流量路径到 $t$，并沿路径减去 $1$，最终会得到
>$$\begin{aligned} P_1,P_2,\dots,P_L \end{aligned}$$
>共恰好 $L$ 条 $s-t$ 路径，使得
>$$\begin{aligned} f=\chi_{P_1}+\dots+\chi_{P_L} \end{aligned}.$$
>而因为对所有边 $f(e)\ge1$，所以每一条原图边都至少属于其中一条 $P_i$。
>
>&emsp;&emsp;取任意反链 $A\subseteq E$，每条 $P_i$ 都是一条有向路径，同一条有向路径中的任意两条边显然可比较，所以反链 $A$ 在每条路径 $P_i$ 中至多出现一条边。另一方面，每个 $e\in A$ 都有 $f(e)\ge 1$，所以至少有一个 $P_i$ 包含 $e$。因此，可以把每个反链元素分配给一条包含它的 $P_i$。由于一条 $P_i$ 至多容纳一个反链元素，这个分配是单射：
>$$\begin{aligned} A\hookrightarrow\{P_1,\dots,P_L\} \end{aligned}.$$
>因此：
>$$\begin{aligned}|A|\le L\end{aligned}.$$
>取最大反链有 $w\le L$，结合此前 $L\le w$，最终得到：
>$$\begin{aligned}w=L\end{aligned}.$$
>即最长反链大小等于定向对偶图 $F_L\to F_R$ 最长路长度。

&emsp;&emsp;得到该结论后，原问题就转化为了求对偶图上的最长路，但考虑原图的给出形式，建立对偶图比较复杂，因此考虑将对偶图上节点对应的路径长度捆绑到对应路径所在的各个边上，直接 $DFS$ 求解：

1. 定义 $pre(v)$ 表示 $v$ 当前的前驱节点，$f(v)$ 表示经过 $pre(v)\to v$ 这条有向边后的对偶图最长路长度，$vis(v)$  有 $0,1,2$ 三种状态，$0$ 表示该点未被访问过，$1,2$ 表示该点已被访问，但前者表示该节点还在递归栈中，后者表示已出栈。
2. 当前遍历到节点 $v$：
    - 若 $vis(v)=0$，则直接更新 $vis(v)=1$，再遍历后续节点；
    - 由于不存在有向环，不存在 $vis(v)=1$ 的情况；
    - 若 $vis(v)=2$，则说明存在节点 $u$ 于 $s\leadsto v$ 这条路径上，使得 $u\leadsto v$ 存在至少两条不同的路径，且当前正在遍历的这条 $u\leadsto v$ 与原本 $pre(v)\to v$ 对应的那条路径恰好闭合成一个面，其中 $u\leadsto pre(v)\to v$ 对应该平面的左侧边界 $P_L$，当前遍历的路径 $u\leadsto v$ 对应该平面的右侧边界 $P_R$。根据对偶图最长路，可以得出
      $$\begin{aligned}f(P_R)=\max(f(P_L))+1\end{aligned}.$$
      并更新 $pre(v)$ 为当前路径上对应节点，使得该路径，为下一个闭合面的左侧边界做准备。

复杂度为 $O(n)$。

```cpp
#include<bits/stdc++.h>
#define endl '\n'
#define pb push_back

using namespace std;
using vi = vector<int>;
using vvi = vector<vector<int>>;

const int N = 5e3 + 10;
vvi g(N);
vi pre(N), f(N), vis(N);

void dfs(int u) {
	vis[u] = 1;
	for(int v : g[u]) {
		if(vis[v] == 2) {
			int res = 0, stop;
			for(int k = v;; k = pre[k]) {
				if(vis[k] == 1) {
					stop = k;
					break;
				}
				res = max(res, f[k]);
			}
			pre[v] = u;
			for(int k = v; k != stop; k = pre[k]) {
				f[k] = res + 1;
			}
			continue;
		}
		pre[v] = u;
		dfs(v);
	}
	vis[u] = 2;
}

void solve() {
	int n; cin >> n;
	for(int i = 1; i < n; i++) {
		int k; cin >> k;
		for(int j = 1; j <= k; j++) {
			int v; cin >> v;
			g[i].pb(v);
		}
	}
	dfs(1);
	cout << *max_element(f.begin() + 1, f.begin() + 1 + n) + 1 << endl;
}

int main() {
	ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
	solve();
	return 0;
}
```
