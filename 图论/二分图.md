# 二分图

二分图的节点由两个不相交的集合 $X，Y$ 组成，且两个集合内部没有边。 

-   **二分图的判定**：由于 **二分图中不存在长度为奇数的环** ，对于一个给定的无向图，从任意一个点开始进行 $dfs$ 染色，相邻两个节点的颜色相异，如果两个顶点处于一个集合内但颜色不同，则该图不是二分图。

## 一、二分图初步

### 基础概念

1.   **匹配（独立边集）**：一张图中不具有公共端点的边的集合 $M$ ，在二分图中求匹配等价于网络流问题，匹配的大小定义为其中边的数量 $|M|$ 。匹配中的边称为 **匹配边**，反之称为 **未匹配边**。一个点属于 $M$ 中一条且至多一条边的端点，称为 **匹配点**，反之称为 **未匹配边** ，另有其它类型匹配：
>[!note] 匹配的分类
>- **极大匹配**：无法再增加匹配边的匹配，不一定是最大匹配，类比于极大值与最大值的关系。
>- **最大匹配**：匹配边数 $|M|$ 最大的匹配，记为 $\alpha'(G)$ 。最大匹配可能不止一个，但 $|M|$ 的大小的确定的，并且满足 **小于等于图中顶点数的一半** 。
>- **最大权匹配**：加权图中，权值和最大的匹配。
>- **最大权最大匹配**：匹配数最多的前提下，边权和最大的匹配。即最大匹配中边权和最大的匹配。
>- **完美匹配**：所有点都属于匹配的情况，同时也是最大匹配。**顶点数为偶数的完全图必然存在完美匹配** 。当二分图的两个集合的点数相等时，其完美匹配又称为 **完备匹配** 。
>- **近完美匹配**：图的点数为奇数且恰好只有一个点不在匹配中。
2.   **增广路（交错路）**：始于非匹配边且路径由匹配边与非匹配边交错而成的，称为 **交错路** 。如果交错路的两端连接两个非匹配点，称为 **增广路** 。

增广路有以下两点性质：

1.   其长度 $len$ ，即路径所含边数为 **奇数** 。
2.   路径上第 $1,3,5,\dots,len$ 条边为非匹配边，第 $2,4,6,\dots,len-1$ 条边是匹配边。

如果将一条增广路上的所有边的状态取反，那么得到的新的边集 $M'$ 仍然是一组匹配，且 $|M'|=|M|+1$ ，那么可以得到结论：**二分图的一组匹配 $M$ 是最大匹配，当且仅当图中不存在 $M$ 的增广路**。故求最大匹配的过程本质就是不断进行增广的过程。

### 二分图与矩阵行列式

对于均衡二分图 $G=(U,V,E)$（左右集合元素个数相等），定义 $n\times n$ 的 $01$ 矩阵 $A$ 为其邻接矩阵：$A_{i,j}=1$ 若存在边 $(u_i,v_j)$，否则 $A_{i,j}=0$。容易发现，二分图完美匹配对应了其邻接矩阵中行列各不相同的位置且元素为 $1$ 的情况，此时，二分图的完美匹配表现为，存在一组边 $\{(u_{i_1},v_{j_1}),(u_{i_2},v_{j_2}),\dots,(u_{i_n},v_{j_n})\}$，使得 $i_1,\dots,i_n$ 和 $j_1,\dots,j_n$ 都为 $1\sim n$ 的排列。

回顾行列式的代数定义：
$$
\begin{aligned}
\det(A)=\sum\limits_{\sigma\in{S_n}}sign(\sigma)\cdot\prod_{i=1}^{n}A_{i,\sigma(i)}
\end{aligned}
$$
其中：
- $S_n$ 是 $1\sim n$ 的所有排列构成的集合（共 $n!$ 个排列）。
- $\sigma$ 是一个排列，即将 $U$ 中的第 $i$ 个顶点匹配到 $V$ 中第 $\sigma(i)$ 个顶点。
- $sign(\sigma)$ 是排列的符号，偶排列为 $1$（排列存在偶数个逆序对），奇排列为 $-1$（排列存在奇数个逆序对）。
- $\prod_{i=1}^{n}A_{i,\sigma(i)}$ 是排列 $\sigma$ 对应的 **边乘积**：若所有 $A_{i,\sigma(i)}=1$（即排列 $\sigma$ 对应一组边 $(u_1,v_{\sigma(1)}),\dots,(u_n,v_{\sigma(n)})$），则乘积为 $1$；否则为 $0$（只要有一个 $A_{i,\sigma(i)}=0$，即 $i$ 没有对应的匹配，乘积为 $0$）。

对每个排列 $\sigma\in S_n$：
- 若 $\prod_{i=1}^{n}A_{i,\sigma(i)}=1$，则排列 $\sigma$ 恰好对应二分图的一个完美匹配（每个 $u_i$ 匹配到唯一的 $v_{\sigma(i)}$，且所有 $v$ 不重复）。
- 若 $\prod_{i=1}^{n}A_{i,\sigma(i)}=0$，则排列 $\sigma$ 不对应任何完美匹配（存在某个 $u_i$ 与 $v_{\sigma(i)}$ 无边）。
因此，行列式的定义重新解读为：$\det(A)=\sum_{完美匹配M}sign(\sigma_M)$，其中 $\sigma_M$ 是完美匹配 $M$ 对应的排列，求和仅遍历所有完美匹配。

在整数域 $\mathbb{Z}$ 中，单个完美匹配对应的排列的边乘积可能为 $1$ 或 $-1$，所以只能用于判断该二分图是否存在完美匹配。当矩阵行列式不为 $0$ 时，一定存在完美匹配，即邻接矩阵行列式为 $0$ 是二分图存在完美匹配的充分条件。但在模 $2$ 域 $\mathbb{F}_2$ 中，$-1\equiv1\mod{2}$，此时行列式的符号失去意义，简化为 $\det_{\mathbb{F}_2}(A)=\sum_{\text{完美匹配}M}1\mod2$，即 **行列式的值为完美匹配数量的奇偶性**：
- 若 $\det_{\mathbb{F}_2}(A)=1$，完美匹配数量为奇数。
- 若 $\det_{\mathbb{F}_2}(A)=0$，完美匹配数量为偶数（或 $0$)。
故可用高斯消元在 $O(n^3)$ 时间内解决二分图匹配的 parity 问题（判定完美匹配的奇偶性）。但在 $\mathbb{F}_2$ 域下，如果二分图的边以一种特殊形式给出，即对于每一个 $u_i$，其都与一组对应的 $[v_{l_i},v_{r_i}]$ 连边，那么邻接矩阵 $A_{i,l_{i}}\sim A_{i,r_i}$ 上都为 $1$，倘若另有 $j,k$ 分别满足 $A_{j,l_{j}}\sim A_{j,r_j}$ 和 $A_{k,l_{k}}\sim A_{k,r_k}$，且 $l_i=l_j\le{r_j},r_j+1=l_k,l_k\le{r_k}=r_i$，则 $(i,j,k)$ 对应的行向量是线性相关的（当存在两个行向量完全相等时，可以退化为二元组），即 $A_i=A_j+A_k$，得到的行列式也就一定为 $0$ 了，倘若并查集来维护，对于每个关系将 $l_i-1$ 与 $r_i$ 合并，如果两者合并之前已经在同一集合里，代表邻接矩阵中存在线性相关的行向量，复杂度为 $O(n)$。

## 二、二分图最大匹配（边独立集）

### 匈牙利算法（增广路算法）

该算法一开始将所有边设为非匹配边，然后不断重复寻找增广路，直到图中不存在增广路为止，其复杂度为 $O(VE)$。匈牙利算法依次尝试给每一个左部的节点 $x$ 找到一个匹配的右部的节点 $y$，该节点 $y$ 能与 $x$ 匹配需要满足：

1.   $y$ 本身为非匹配点，则无向边 $(x,y)$ 为一条非匹配边，自身构成一条长度为 $1$ 的增广路。
2.   $y$ 已经与一个左部点 $x'$ 匹配，但从 $x'$ 出发能够找到另外一个右部点 $y'$ 与之匹配，按照贪心策略，$x'$ 撤销与 $y$ 的匹配转而与 $y'$ 匹配，使得 $x$ 能够与 $y$ 匹配。此时路径 $P(x,y)$ 与 $P(x',y')$ 相连为新的一条增广路。

**Dfs 版**

```cpp
bool vis[N]; int match[N];
vector<vector<int>> g(N);

bool dfs(int u) {
    for(int v : g[u]) {
        if(vis[v]) continue;
        vis[v] = true; // 避免重复访问
        if(match[v] == -1 || dfs(match[v])) {
            match[v] = u;
            return true; // 找到增广路
        }
    }
    return false; // 未找到增广路
}

int hungarian(int n) {
    memset(match, -1, sizeof(match));
    int res = 0;
    for(int u = 0; u < n; u++) {
        memset(vis, false, sizeof(vis));
        if(dfs(u)) res++; // 找到增广路则最大匹配值增加
    }
    return res;
}
```

**Bfs 版**

```cpp
int px[N], py[N], pre[N], n, m;
bool g[N][N], vx[N], vy[N];

bool bfs(int s) {
    memset(pre, 0, sizeof(pre));
    memset(vx, false, sizeof(vx));
    memset(vy, false, sizeof(vy));
    queue<int> q;
    q.push(s);
    while(q.size()) {
        int u = q.front(); q.pop();
        vx[u] = true;
        for(int v = 1; v <= m; v++) {
            if(g[u][v] && !vy[v]) {
                vy[v] = true;
                pre[v] = u; // 记录路径
                if(py[v] == -1) {
                    while(v != -1) {
                        int t = px[pre[v]];
                        px[pre[v]] = v;
                        py[v] = pre[v];
                        v = t;
                    }
                    return true;
               } else q.push(py[v]);
            }
        }
    }
    return false;
}

int hungarian() {
    int res = 0;
    memset(px, -1, sizeof(px));
    memset(py, -1, sizeof(py));
    for(int i = 1; i <= n; i++) {
        if(bfs(i)) res++;
    }
    return res;
}
```

### Dinic 算法

将二分图转化为网络流模型：添加一个源点 $s$，连接上左边集合所有的点，每条边的容量设为 $1$；再添加一个汇点 $t$，连接上右边集合所有的点，容量同样设为 $1$；最后将原图中所有边改为从左到右的有向边，容量也设为 $1$。最后使用 **Dinic** 算法求网络最大流即可。算法复杂度为 $O(VE^2)$。

## 三、二分图完美匹配与 Hall 定理

Hall 定理给出了二分图 $G=(U\cup Y,E)$ 存在一个 $U-$ 完美匹配（即 $U$ 部的所有点都被匹配）的充要条件。
- **Hall 定理**：考虑一个二分图 $G=(U\cup V,E)$，$G$ 存在从 $U$ 到 $V$ 的匹配，当且仅当对于 $U$ 的任意子集 $A\subseteq U$，都有：$$|N(A)|\ge|A|$$其中 $N(A)$ 是 $A$ 中所有顶点的邻居集合（即与 $A$ 中顶点相连的 $V$ 中顶点的集合）。

倘若最多允许存在 $x(x\lt|U|)$ 个左部点得不到匹配，得到加强后的 Hall 定理。

- **亏缺 Hall 定理**：考虑一个二分图 $G=(U\cup V,E)$，$G$ 存在一个大小至少为 $|U|-x$ 的匹配（即 $U$ 部中最多有 $x$ 个点未被匹配），当且仅当对于 $U$ 的任意子集 $A\subseteq U$，都有：
  $$|N(A)|\ge|A|-x
$$
倘若左部 $U$ 中的第 $i$ 个点希望匹配 $r(i)$ 个右部 $V$ 中的点，即匹配带有容量约束，则被称为多重匹配，该匹配下有 Hall 定理的推广版本（在图论中称为因子理论或 $(r_1,r_2,\dots,r_n)-$ 因子的存在性条件）。

- **带容量的 Hall 定理推广**：考虑一个二分图 $G=(U\cup V,E)$，其中 $U=\{u_1,u_2,\dots,u_n\}$。若对于每位 $u_i\in U$ 都需要与 $r(u_i)$ 个不同且未被匹配过的右部点匹配，当且仅当对于 $U$ 的任意子集 $A\subseteq U$，都有：$$|N(A)|\ge\sum\limits_{u_i\in A}r(u_i)$$

## 四、二分图最大权完美匹配

### KM（Kuhn–Munkres）算法——匈牙利算法变种

1.   **可行顶标**
给每个节点 $i$ 分配一个权值 $l(i)$，对于所有边 $\langle u,v\rangle$ 满足 $w\langle u,v\rangle\le l(u)+l(v)$ 。
2. **相等子图**
在一组可行顶标下原图的生成子图，包含所有点但只包含满足 $w\langle u,v\rangle=l(u)+l(v)$ 的边 $\langle u,v\rangle$。

 **对于某组可行顶标，如果其相等子图存在完美匹配，那么该匹配就是原图的最大全完美匹配** 。
- 证明：

**Dfs 版**：对于随机数据，复杂度为 $O(n^3)$ ，但实际复杂度为 $O(n^4)$

```cpp
using ll = long long;

const ll INF = 0x3f3f3f3f3f3f3f3fll;
int match[N];
bool va[N], vb[N]; // 标记是否在交替路中
ll w[N][N], d[N], la[N], lb[N];
int n;

bool dfs(int x) {
    va[x] = 1;
    for(int y = 1; y <= n; y++) {
        if(vb[y] || la[x] + lb[y] != w[x][y]) continue; // 不在交替路中或不可行
        vb[y] = 1;
        if(!match[y] || dfs(match[y])) {
            match[y] = x;
            return true;
        } else {
            d[y] = min(d[y], la[x] + lb[y] - w[x][y]);
        }
    }
    return false;
}

ll KM() {
    memset(lb, 0, sizeof(lb));
    for(int i = 1; i <= n; i++) {
        la[i] = -INF;
        for(int j = 1; j <= n; j++) {
            // 初始化左部顶标为最大权值
            la[i] = max(la[i], w[i][j]);
        }
    }
    for(int i = 1; i <= n; i++) {
        // 直到找到一组匹配
        while(true) {
            fill(va + 1, va + 1 + n, 0);
            fill(vb + 1, vb + 1 + n, 0);
            fill(d + 1, d + 1 + n, INF);
            if(dfs(i)) break; // 找到增广路
            // 否则修改顶标
            ll delta = INF;
            for(int j = 1; j <= n; j++)
                if(!vb[j]) delta = min(delta, d[j]);
            for(int j = 1; j <= n; j++) {
                if(va[j]) la[j] -= delta;
                if(vb[j]) lb[j] += delta;
            }
        }
    }
    ll res = 0;
    for(int i = 1; i <= n; i++) {
        res += w[match[i]][i];
    }
    return res;
}
```

**Bfs 版**：复杂度为 $O(n^3)$

```cpp
using ll = long long;
const ll INF = 0x3f3f3f3f3f3f3f3fll;

ll px[N], py[N], slack[N];
bool vx[N], vy[N]; // 标记是否在交替路中
ll w[N][N], pre[N], lx[N], ly[N];
int n, m;

// 需要保证 n >= m
void augment(int v) {
    while(v != -1) {
        int t = px[pre[v]];
        px[pre[v]] = v;
        py[v] = pre[v];
        v = t;
    }
}

void bfs(int s) {
	memset(slack, 0x3f, sizeof(slack));
    memset(pre, -1, sizeof(pre));
    memset(vx, false, sizeof(vx));
    memset(vy, false, sizeof(vy));
    queue<int> q; q.push(s);
    while(true) {
        while(q.size()) {
            int u = q.front(); q.pop();
            vx[u] = true;
            for(int v = 1; v <= m; v++) {
                if(vy[v] || lx[u] + ly[v] - w[u][v] >= slack[v]) continue; // 不在交替路中或不可行
                slack[v] = lx[u] + ly[v] - w[u][v]; // 更新slack
                pre[v] = u; // 记录前驱
                if(!slack[v]) {
                    vy[v] = true; // 找到增广路
                    if(py[v] == -1) {
                        augment(v);
                        return;
                    } else q.push(py[v]);
                }
            }
        }
        ll delta = INF;
        for(int i = 1; i <= m; i++) {
            if(!vy[i]) delta = min(delta, slack[i]); // 找到最小的 slack
        }
        if(delta == INF) return; // 找不到增广路
        // 更新顶标
        for(int i = 1; i <= n; i++) if(vx[i]) lx[i] -= delta;
        for(int i = 1; i <= m; i++) {
            if(vy[i]) ly[i] += delta;
            else slack[i] -= delta;
        }
        for(int i = 1; i <= m; i++) {
            if(!vy[i] && !slack[i]) {
                vy[i] = true;
                if(py[i] == -1) {
                    augment(i);
                    return;
                } else q.push(py[i]);
            }
        }
    };
}

ll km() {
    memset(px, -1, sizeof(px));
    memset(py, -1, sizeof(py));
    for(int u = 1; u <= n; u++) {
    	lx[u] = -INF;
        for(int v = 1; v <= m; v++) lx[u] = max(lx[u], w[u][v]);
    }
    for(int i = 1; i <= n; i++) bfs(i);
    ll ans = 0;
    for(int i = 1; i <= n; i++) {
    	if(px[i] != -1) ans += w[i][px[i]];
    }
    return ans;
}

int main() {
	ll k;
	cin >> n >> m >> k;
	for(int i = 1; i <= n; i++) {
		for(int j = 1; j <= m; j++) w[i][j] = -INF;
	}
	while(k--) {
		ll x, y, wit; cin >> x >> y >> wit;
		w[x][y] = wit;
	}
	cout << km() << endl;
    // 输出匹配
	for(int i = 1; i <= n; i++) {
		cout << i << " " << px[i] << " \n"[i == n];
	}
    return 0;
}
```

### Dinic 算法

在图中新增一个源点一个汇点，从源点向二分图的每个左部点连一条流量为 $1$ ，费用为 $0$ 的边；从二分图的每个右部点向汇点连一条流量为 $1$，费用为 $0$ 的边；对于原图中每一条边 $\langle u,v\rangle$，边权为 $w$，连接一条从 $u$ 到 $v$，流量为 $1$，费用为 $w$ 的边；另外在最大权匹配下，匹配边的数量不一定与最大匹配的匹配边数量相等，因此对于每个左部点，还需向汇点连一条流量为 $1$，费用为 $0$ 的边。
此时转化为了网络流模型，即等价于求解 **最大费用最大流** ，将边权置为相反数，再跑一遍最小费用最大流即可。

## 五、二分图最小点覆盖

- **点覆盖**：点覆盖是顶点集 $V$ 的一个子集 $V'\subseteq{V}$，使得图中每一条边都至少有一个端点在 $V'$ 中。也就是说，点覆盖中的顶点能够 **覆盖** 住所有的边。在图 $G$ 的所有点覆盖中，顶点个数 $|V'|$ 最少点覆盖称为 **最小点覆盖** ，最小点覆盖的顶点个数被称为 **点覆盖数** ，记为 $\beta(G)$ 。 

### König 定理

**$\text{K\"onig}$ 定理**：在二分图中，**最大匹配的边数等于最小点覆盖的点数** ，这个定理揭示了二分图中覆盖与匹配的对偶性。

- **证明**：对于一个二分图 $G=(V,E)$，最大匹配 $M$ 的边数为 $m$，最小点覆盖 $C$ 的点数为 $n$ ，且 $m\neq{n}$ 。由于最大匹配是原二分图图集的一个子集，该集合中所有边都不相交，那么每一条匹配边都至少需要一个点覆盖，则最大匹配的边数一定小于等于最小点覆盖的点数。
  
  设 $M=\{e_1,e_2,\dots,e_m\}$ 为图 $G$ 的一个最大匹配，因为 $C$ 是点覆盖，所以 $C$ 要覆盖 $M$ 中的所有边，即 $M$ 中的每一条边 $e_i$ 的两个端点至少有一个在 $C$ 中。
  
  现在从 $C$ 中去掉一个点 $v$ ，由于 $C$ 是最小点覆盖，去掉 $v$ 后，必然存在一条匹配边 $e_j$ ，其两个端点都不在 $C-\{v\}$ 中，这意味着 $C-\{v\}$ 不能覆盖所有的匹配边，进而不能覆盖图 $G$ 的所有边，所以 $C-\{v\}$ 不是点覆盖。
  
  此时考虑边集 $M$ ，其有 $m$ 条边，而 $C-\{v\}$ 有 $n-1$ 个点，且 $m\lt{n}$ ，那么 $m\le{n}-1$ 。这就意味着存在一种方式可以用 $n-1$ 个点来覆盖 $m$ 条匹配边，即存在一个比 $C$ 更小的点集可以覆盖所有匹配边，与 $C$ 为最小点覆盖矛盾。
  
  所以假设 $m\lt{n}$ 不成立，只能 $m=n$，即最大匹配的边数等于最小覆盖的点数。

### 二分图最小点权覆盖集

给定一个带点权二分图 $G=(V,E)$ ，其中 $V=X\cup{Y}$ ，即 $Y=\overline{X}$ ，另有 $\forall{v}\in{V}$ ，都被分配了一个非负点权 $w(v)$ 。记该图的一个覆盖集的点权为 $w(V')=\sum_{v\in{V'}}w(v)$ ，其中，
$w(V')$ 最小的即为最小点权覆盖集。

根据 $\text{K\"onig}$ 定理的带权推广 ，考虑到最大边权独立集（匹配）和最小点权覆盖集之间的对偶性，二分图的最小点权覆盖集可以通过构造流网络的最小割求解。其核心逻辑如下：
- 将点覆盖的 **选点** 决策转化为流网络中 **割边** 的选择。
- 利用流网络中割的性质（源汇不流通）对应点覆盖的约束（每条边至少选择一个端点）。

构造流网络 $N=(V_N,E_N)$ ，其中 $V_n=X\cup{Y}\cup\{s,t\}$ 。对于边集 $E_N$ ，，从源点 $s$ 向 $X$ 中每个顶点 $u$ 连边 $\langle s,u\rangle$ ，容量大小为 $w(u)$（表示选择 $u$ 的代价）；从 $Y$ 中每个顶点 $v$ 向汇点 $t$ 连边，容量大小为 $w(v)$（表示选择 $v$ 的代价）；对于原图中每条边 $\langle u,v\rangle\in{E}$ ，从 $u$ 向 $v$ 连一条容量为 $+\infty$ 的边。

- **无穷大容量的边确保其不会被包含在最小割中，从而将割的选择限制在与源汇相连的边上，即简单割**。

此时求解最小割，对于网络中的一条路径 $s\rightarrow{u}\rightarrow{v}\rightarrow{t}$ ，不可能为 $u\rightarrow{v}$ （容量无穷大），只能是 $s\rightarrow{u}$ 和 $v\rightarrow{t}$ 二选一，对应最小点覆盖集的约束中每条边只能二选一一个端点。那么 **最小割的容量即为最小点权覆盖集的权值** 。

## 六、Gallai 定理

### 概念与定义

- **独立集**：对于一个图 $G=(V,E)$ ，如果有一个顶点子集 $S\subseteq{V}$ ，使得 $S$ 中任意两个顶点之间都没有边相连，那么称 $S$ 是图 $G$ 的一个独立集。在所有独立集中，包含顶点数量最多的独立集被称为 **最大独立集** ，$|S|$ 表示独立集 $S$ 中的顶点个数。最大独立集的顶点个数称为图 $G$ 的 **独立数** ，记为 $\alpha(G)$ 。
- **边覆盖集**：对于一个图 $G=(V,E)$ ，如果有一个边子集 $E'\subseteq E$ ，使得 $V$ 中的每个顶点至少与 $E'$ 中的一条边关联。即，$\forall v\in V$ ，都 $\exists e\in E'$ ，使得 $e$ 包含顶点 $v$ ，称 $E'$ 为一个边覆盖集。在所有边覆盖集中，边数 $|E'|$ 最少的边覆盖集被称为 **最小边覆盖集** 。最小边覆盖集的边数被称为图 $G$ 的 **边覆盖数** ，记为 $\beta'(G)$ 。

**$Gallai$ 定理**：
- 对于任意图 $G$，有 $\alpha(G)+\beta(G)=n$。
- 对于无孤立点的图 $G$，有 $\alpha'(G)+\beta'(G)=n$
即：**独立数=点数-点覆盖数** ，**边独立数=点数-边覆盖数** ，两对集合之间两两互为补集。
在二分图中：由 $\text{K\"onig}$ 定理可知 $\alpha'(G)=\beta(G)$ ，结合 $Gallai$ 定理可得 $\alpha(G)=\beta'(G)$ 。

- **证明** ：
	  1. $\alpha(G)\le n-\beta(G)$ ：设 $K$ 为 $G$ 的一个最小点覆盖，即 $|K|=\beta(G)$ 。考虑 $V-K$ 这个顶点集合，假设 $\exists u,v\in V-K$ ，使得 $(u,v)\in E$ ，那么 $K$ 就不是点覆盖，因为存在一条边，其两个端点都不在 $K$ 中，与假设矛盾。则 $\forall u,v\in V-K$ ，都满足 $(u,v)\notin E$ ，那么 $V-K$ 是一个独立集。由于 $|V-K|=n-|K|=n-\beta(G)$ ，那么可得 $\alpha(G)\le|V-K|=n-\beta(G)$ 。
	  2. $\alpha(G)\ge n-\beta(G)$ ：设 $I$ 为 $G$ 的一个最大独立集，即 $|I|=\alpha(G)$ 。考虑 $V-I$ 这个顶点集合，$\forall u,v\in V$ ，不可能使得 $\exists u,v\in I$ ，因为 $I$ 是独立集，任意两个顶点不相邻，所以两个顶点至少有一个在 $V-I$ 中。这说明 $V-I$ 是一个点覆盖。由于 $|V-I|=n-|I|=n-\alpha(G)$ ，那么可得 $\beta(G)\le|V-I|=n-\alpha(G)$ ，即 $\alpha(G)\ge n-\beta(G)$ 。
	  3. 由上述两点得证，对于一般图 $G$ ，有 $\alpha(G)=n-\beta(G)$ 。
	  4. 同理可用反证法证得 $\alpha'(G)=n-\beta'(G)$ 。

同样的，对于带权扩展有：
 $$
\begin{aligned}
最大点权独立集权值和+最小点权覆盖集权值和=\sum_{v\in{V}}w(v)
\end{aligned}
$$
而最大边权匹配与最小边权覆盖没有类似的结论。

### 二分图最小权边覆盖

对于原图，新建源点 $s$ 和汇点 $t$ ，从源点 $s$ 向左部 $X$ 中所有顶点连边，容量 $c\langle s,u\rangle=1$ ，费用 $w\langle s,u\rangle=0$（确保每个 $u\in{X}$ 最多被匹配一次）；从右部 $Y$ 中所有顶点向汇点 $t$ 连边，容量与费用与前者相同（确保每个 $v\in{V}$ 只被匹配一次）；最后保留原二分图的所有边 $\langle u,v\rangle\in{E}$，容量无穷大且权重不变。

现在在该网络上跑一遍最小费用最大流，在确保尽可能多的顶点被覆盖（最大流）的同时，保证总费用最小（优先选权值更小的边）。

## 七、二分图与最小路径覆盖

### 最小路径覆盖

**路径覆盖**：在有向无环图 $G=(V,E)$ 中路径覆盖是指一个路径集合 $P$ ，使得图中每个顶点恰好属于 $P$ 中的一条路径。这里的路径可以是单个顶点，也可以是多条连续的边连接的多个顶点序列。在所有可能的路径覆盖中，路径数量最少 $|P|$ 的路径覆盖，被称为 **最小路径覆盖** 。

**DAG 最小路径覆盖定理**：对于任意有向无环图（DAG）$G=(V,E)$ ，定义 $G'=(V_{l}\cup V_{r},E')$ 为原图 $G$ 的 **拆点二分图** （也称二分图模型），其构造方法如下：
1. 将原图 $G$ 的每个顶点拷贝出两个副本 $V_{l},V_{r}$ 。
2. 对于原图中每一条有向边 $\langle u,v\rangle$ ，在 $G'$ 中建立对应的有向边 $\langle u_l,v_r\rangle$ 。 
在二分图 $G'$ 中，每次找到一条匹配边 $\langle u_l,v_r\rangle$ ，相当于在原图 $G$ 中合并两条路径（如：对于一条匹配边 $\langle u_l,k_r\rangle$ ，如果另有一条匹配边 $\langle k_l,v_r\rangle$ ，则可以合并路径为 $u\rightarrow v$ ），从而减少一条路径。那么有：
$$
\begin{aligned}
|P|_{\min}=n-\alpha'(G')
\end{aligned}
$$
即：**最小路径覆盖数=原图节点数-拆点二分图的边独立数** 。结合 $Gallai$ 定理及其推论可知 **原图的最小路径覆盖数等于其拆点二分图的边覆盖数，等于拆点二分图的独立数** 。

### 最小可相交路径覆盖（可重复点路径覆盖）

在可重复点最小路径覆盖中，若有两条路径 $\dots\rightarrow{u}\rightarrow{p}\rightarrow{v}\rightarrow\dots$ 和 $\dots\rightarrow{x}\rightarrow{p}\rightarrow{y}\rightarrow\dots$ 在 $p$ 点相交，可以直接在原图中添加边 $\langle x,y\rangle$ ，让第二条路线变换为 $x\rightarrow{y}$ ，避免了重复覆盖点 $p$ 。因此，如果将原图中所有间接连通点对 $u, v$ 连上有向边 $\langle u,v\rangle$ ，那么**可重复点路径覆盖就转化为了无重复点路径覆盖** 。

故先对有向图做传递闭包（即 Floyd 算法），得到有向无环图 $G'$ 后，再在 $G'$ 上求一般最小路径点覆盖。

### 最多不相交路径问题

这个是在固定起点和终点情况下最大化路径数量问题，通常是寻找在满足特定约束下（如节点/边限制）和长度限制（如最短路）的最大路径集合，一般采用最大流解决，建模方法如下：
- 拆点：将每个节点 $u$ 拆分为 $u_{in}$ 和 $u_{out}$，并在两者之间连边，容量设为该节点最多可经过次数（即路径条数）。
- 连边：图中边的容量设为该边最多可经过的次数。
