## 定义

将一个大小为 $m$ 的序列排序为

$$
x_1\le x_2\le\cdots\le x_m.
$$

中位数在偶数个元素时有三种常见定义：

| 名称 | 定义 | $m=4$ 时 |
|---|---|---|
| 下中位数 | 第 $\left\lceil\frac m2\right\rceil$ 小，即 $x_{\lceil m/2\rceil}$ | $x_2$ |
| 上中位数 | 第 $\left\lfloor\frac m2\right\rfloor+1$ 小，即 $x_{\lfloor m/2\rfloor+1}$ | $x_3$ |
| 数学中位数 | 两个中间元素的平均值 | $\frac{x_2+x_3}{2}$ |

当 $m$ 为奇数时，三者相同。不同题面可能混用“上中位数”和“下中位数”的名称，因此实现时应以“第几小”的定义为准。

除非另有说明，本文后续的序统计量推导均采用下中位数：

$$
\operatorname{med}(S)=\text{第 }\left\lceil\frac{|S|}{2}\right\rceil\text{ 小元素}.
$$

## 基本求法

### 静态序列

排序后可以直接取得中位数，时间复杂度为 $O(n\log n)$。如果只需要某一个序统计量，可以使用 `std::nth_element`，平均时间复杂度为 $O(n)$：

```cpp
// 返回下中位数；nth_element 会改变局部副本中元素的相对顺序。
long long LowerMedian(vector<long long> a) {
    int k = (static_cast<int>(a.size()) - 1) / 2;
    nth_element(a.begin(), a.begin() + k, a.end());
    return a[k];
}

// 返回上中位数；nth_element 会改变局部副本中元素的相对顺序。
long long UpperMedian(vector<long long> a) {
    int k = static_cast<int>(a.size()) / 2;
    nth_element(a.begin(), a.begin() + k, a.end());
    return a[k];
}
```

序统计量意义下的中位数一定是原序列中的元素；偶数长度时取平均值的数学中位数则不一定属于原序列。

### 只插入的动态序列

不断插入元素并查询中位数时，可以维护一对对顶堆：

- `lower` 是大根堆，保存较小的一半；
- `upper` 是小根堆，保存较大的一半；
- 任意时刻都满足 `lower` 中的元素不大于 `upper` 中的元素；
- `upper.size()` 等于 `lower.size()`，或者比它多 $1$。

```cpp
priority_queue<long long> lower;
priority_queue<long long, vector<long long>, greater<long long>> upper;

long long x;
while (cin >> x) {
    if (upper.empty() || x >= upper.top()) {
        upper.push(x);
    } else {
        lower.push(x);
    }

    if (upper.size() < lower.size()) {
        upper.push(lower.top());
        lower.pop();
    } else if (upper.size() > lower.size() + 1) {
        lower.push(upper.top());
        upper.pop();
    }

    long long lowerMedian = upper.size() == lower.size()
                              ? lower.top()
                              : upper.top();
    long long upperMedian = upper.top();

    cout << lowerMedian << ' ' << upperMedian << '\n';
}
```

单次插入的时间复杂度为 $O(\log n)$，查询堆顶为 $O(1)$。如果还需要删除任意元素，例如维护滑动窗口中位数，可以使用两个 `multiset`，或者为双堆增加延迟删除机制。

## 序统计量的阈值判定

中位数题的重要转换不是直接求出中位数，而是判断

$$
\operatorname{med}(S)\ge x.
$$

设 $|S|=m$，并记

$$
G(x)=\#\{s_i\in S\mid s_i\ge x\}.
$$

对于下中位数，至少要有严格超过一半的元素不小于 $x$：

$$
\operatorname{med}_{\mathrm{low}}(S)\ge x
\iff 2G(x)>m.
$$

对于上中位数，恰好一半也可以：

$$
\operatorname{med}_{\mathrm{up}}(S)\ge x
\iff 2G(x)\ge m.
$$

将每个元素按阈值 $x$ 转换为

$$
d_i=
\begin{cases}
+1,&s_i\ge x,\\
-1,&s_i<x,
\end{cases}
$$

则

$$
\sum_i d_i=2G(x)-m.
$$

因此有：

| 中位数定义 | $\operatorname{med}(S)\ge x$ 的条件 |
|---|---|
| 下中位数 | $\sum_i d_i>0$ |
| 上中位数 | $\sum_i d_i\ge0$ |

使用 `2 * count > size` 或 `2 * count >= size` 表达多数关系，可以避免先除以 $2$ 带来的奇偶边界问题。

### 第 $k$ 小的统一形式

中位数只是第 $k$ 小问题的特殊情形。设 $\operatorname{kth}_k(S)$ 表示第 $k$ 小元素，则

$$
\operatorname{kth}_k(S)\ge x
\iff \#\{s_i<x\}\le k-1
\iff G(x)\ge m-k+1.
$$

这说明所谓“中位数的 $\pm1$ 转换”，本质是把序统计量的排名条件转换为阈值计数。

## 二分答案

定义判定函数

$$
P(x)=[\operatorname{med}(S)\ge x].
$$

如果 $P(x)$ 为真，那么对于任意 $y<x$，$P(y)$ 也为真。可行性随 $x$ 增大呈现

```text
x:       小 -------------------------- 大
P(x):    true true true | false false false
                       ↑
                   最大可行值
```

因此可以二分查找

$$
\max\{x\mid P(x)=\mathrm{true}\}.
$$

如果每一层中位数都采用序统计量定义，那么答案一定来自最初的输入值。对输入值排序去重后进行离散二分，通常比在整个数值范围上二分更快，也不会遇到 `maxValue + 1` 溢出。

### 长度至少为 $k$ 的子数组最大下中位数

固定候选值 $x$，令

$$
d_i=
\begin{cases}
1,&a_i\ge x,\\
-1,&a_i<x,
\end{cases}
\qquad
P_i=\sum_{j=1}^{i}d_j.
$$

区间 $[l,r]$ 的下中位数不小于 $x$，等价于

$$
P_r-P_{l-1}>0.
$$

在 $r-l+1\ge k$ 的限制下，只需维护 $P_0,\dots,P_{r-k}$ 的最小值：

```cpp
bool ExistsMedianAtLeast(const vector<int>& a, int k, int x) {
    int n = static_cast<int>(a.size());
    vector<int> prefix(n + 1, 0);

    for (int i = 1; i <= n; ++i) {
        prefix[i] = prefix[i - 1] + (a[i - 1] >= x ? 1 : -1);
    }

    int minPrefix = prefix[0];
    for (int r = k; r <= n; ++r) {
        minPrefix = min(minPrefix, prefix[r - k]);
        if (prefix[r] > minPrefix) {
            return true;
        }
    }
    return false;
}
```

一次判定为 $O(n)$，对离散值二分后的总时间复杂度为 $O(n\log n)$。如果题目采用上中位数，应将最后的严格大于改为大于等于。

### 统计中位数满足条件的子数组

固定 $x$ 后，下中位数不小于 $x$ 的子数组数量等于前缀和中满足

$$
l-1<r,\qquad P_{l-1}<P_r
$$

的点对数量。按 $r$ 从左到右扫描，用树状数组维护此前前缀和的频数，即可在 $O(n\log n)$ 内统计。

对于整数数组，中位数恰好等于 $x$ 的子数组数量可以写成

$$
\#(\operatorname{med}=x)
=\#(\operatorname{med}\ge x)-\#(\operatorname{med}\ge x+1).
$$

如果值域不是连续整数，应减去“中位数大于 $x$”或“中位数至少为下一个离散值”的数量。

## 中位数的 $L_1$ 最优性质

对于

$$
f(x)=\sum_{i=1}^{n}|a_i-x|,
$$

当 $x$ 从左向右移动时，位于 $x$ 左侧的项推动函数增大，右侧的项推动函数减小。只有当两侧元素数量达到平衡时，函数才取得最小值。

将序列排序后，最优解集合为

$$
x\in
\left[
a_{\lceil n/2\rceil},
a_{\lfloor n/2\rfloor+1}
\right].
$$

奇数长度时最优点唯一，即中位数；偶数长度时，两个中间元素之间的任意位置都最优。如果 $x$ 必须取原序列中的元素，可以选择下中位数或上中位数。

这一性质常用于：

- 选择一个位置，使所有点移动到该位置的距离和最小；
- 一维设施选址；
- 曼哈顿距离问题，将横坐标和纵坐标分别取中位数；
- 带权距离和，其中普通中位数推广为带权中位数。

## 例题：The Median of the Median of the Median

>[!question] [The Median of the Median of the Median](https://vjudge.net/problem/QOJ-9314)
> 给定数组 $a$，定义
> $$
> b_{l,r}=\operatorname{med}\{a_l,\dots,a_r\},
> $$
> 再定义
> $$
> c_{l,r}=\operatorname{med}\{b_{i,j}\mid l\le i\le j\le r\}.
> $$
> 求所有 $c_{l,r}$ 的中位数。数组长度 $n\le2000$，每一层中位数均定义为第 $\left\lceil\frac m2\right\rceil$ 小元素，即下中位数。

### 阈值穿过嵌套中位数

二分候选值 $x$。对原数组进行 $\pm1$ 转换：

$$
d_i=
\begin{cases}
1,&a_i\ge x,\\
-1,&a_i<x,
\end{cases}
\qquad
P_i=\sum_{k=1}^{i}d_k.
$$

第一层中位数满足

$$
b_{l,r}\ge x
\iff P_r-P_{l-1}>0.
$$

因此只需记录布尔矩阵

$$
B_{l,r}=[b_{l,r}\ge x].
$$

这里不需要求出任意 $b_{l,r}$ 的具体值，只需要保留它是否达到阈值 $x$。

### 用二维前缀和统计第二层多数

固定区间 $[l,r]$，参与计算 $c_{l,r}$ 的 $b_{i,j}$ 数量为

$$
N_{l,r}=\frac{(r-l+1)(r-l+2)}{2}.
$$

由于使用下中位数，故

$$
c_{l,r}\ge x
\iff
2\sum_{l\le i\le j\le r}B_{i,j}>N_{l,r}.
$$

矩阵 $B$ 只有 $i\le j$ 的上三角区域有效。将 $i>j$ 的位置设为 $0$ 后，正方形 $[l,r]\times[l,r]$ 中的元素和正好等于上述三角区域的元素和。

设 `squarePrefix` 为整个矩阵的二维前缀和，则

$$
\sum_{l\le i\le j\le r}B_{i,j}
=S_{r,r}-S_{l-1,r}-S_{r,l-1}+S_{l-1,l-1}.
$$

每个 $c_{l,r}$ 是否达到阈值可以在 $O(1)$ 内判断，全部判断共需 $O(n^2)$。

### 最后一层多数

所有 $c_{l,r}$ 一共有

$$
M=\frac{n(n+1)}{2}
$$

个。设其中有 $K$ 个满足 $c_{l,r}\ge x$，则最终答案满足

$$
\operatorname{answer}\ge x
\iff 2K>M.
$$

一次 `Check(x)` 的流程为：

```text
a_i
 └─ 与 x 比较并转为 ±1
     └─ 一维前缀和判断 b[l][r] >= x
         └─ 二维前缀和判断 c[l][r] >= x
             └─ 统计满足条件的 c 是否严格过半
```

阈值比较可以逐层穿过中位数，将每一层中位数转换为对下一层布尔值的多数判定。由于最终答案来自原数组，只需对不同的 $a_i$ 离散二分。总时间复杂度为 $O(n^2\log n)$，空间复杂度为 $O(n^2)$。

### 完整实现

```cpp
#include <algorithm>
#include <cstddef>
#include <iostream>
#include <vector>

using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<ll> a(n + 1);
    vector<ll> values;
    values.reserve(n);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        values.push_back(a[i]);
    }

    sort(values.begin(), values.end());
    values.erase(unique(values.begin(), values.end()), values.end());

    vector<int> prefix(n + 1, 0);
    const int width = n + 1;
    vector<int> squarePrefix(static_cast<size_t>(width) * width, 0);

    auto Value = [&](int i, int j) {
        return squarePrefix[static_cast<size_t>(i) * width + j];
    };

    auto Check = [&](ll x) {
        for (int i = 1; i <= n; ++i) {
            prefix[i] = prefix[i - 1] + (a[i] >= x ? 1 : -1);
        }

        for (int i = 1; i <= n; ++i) {
            size_t row = static_cast<size_t>(i) * width;
            size_t previousRow = static_cast<size_t>(i - 1) * width;

            for (int j = 1; j <= n; ++j) {
                int good = i <= j && prefix[j] - prefix[i - 1] > 0;
                squarePrefix[row + j]
                    = squarePrefix[previousRow + j]
                    + squarePrefix[row + j - 1]
                    - squarePrefix[previousRow + j - 1]
                    + good;
            }
        }

        ll goodC = 0;
        for (int l = 1; l <= n; ++l) {
            for (int r = l; r <= n; ++r) {
                int goodB = Value(r, r)
                          - Value(l - 1, r)
                          - Value(r, l - 1)
                          + Value(l - 1, l - 1);

                ll length = r - l + 1;
                ll countB = length * (length + 1) / 2;
                if (2LL * goodB > countB) {
                    ++goodC;
                }
            }
        }

        ll countC = 1LL * n * (n + 1) / 2;
        return 2LL * goodC > countC;
    };

    int left = 0;
    int right = static_cast<int>(values.size()) - 1;
    int answer = 0;

    while (left <= right) {
        int middle = left + (right - left) / 2;
        if (Check(values[middle])) {
            answer = middle;
            left = middle + 1;
        } else {
            right = middle - 1;
        }
    }

    cout << values[answer] << '\n';
    return 0;
}
```
