# 乘法逆元

对于线性同余方程 $ax\equiv1(\bmod{b})$ ，称 $x$ 为 $a\bmod{b}$ 的逆元，记作 $a^{-1}$ ，或者是 $inv(a)$。
而另有 $\lfloor\frac{x}{k}\rfloor\bmod{p} =\ (x\bmod{p}-x\bmod{k})\bmod{p}\times inv(k)$ 。

## 扩展欧几里得法

根据贝祖定理，若 $\gcd(a, b)\ =\ d$ ,则存在整数 $x,\ y$ 使得 $ax+by=d$ 。
对于线性同余方程 $ax\equiv1(\bmod{b})$ ，已知 $\gcd(a,b)\ =\ 1$ ，则有等式 $ax+by=1$ ，其中 $x$ 为 $a$ 的逆元。

```cpp
void exgcd(int a, int b, int &x, int &y) {
    if(b == 0) {
        x = 1, y = 0;
        return;
    }
    exgcd(b, a % b, y, x);
    y -= a / b * x;
}
```

## 快速幂法

根据费马小定理，当 $b$ 为一个素数时，有 $ax\equiv a^{(b-1)}\bmod{b}$ ，则 $x\equiv a^{b-2}\bmod{b}$ 。

```cpp
int qpow(long long a, int b) {
    int ans = 1;
    a = (a % p + p) % p;
    while(b) {
        if(b & 1) ans = (ans * a) % p;
        a = (a * a) % p;
        b >>= 1;
    }
    return ans;
}
```

## 线性求逆元

求出 $1,\ 2,\dots,\ n$ 中每个数关于质数 $p$ 的逆元。设 $k\ =\ \lfloor\frac{p}{i}\rfloor,\ j\ =\ p\bmod{i}$ ，有 $p\ =\ ki+j$ ，即 $ki+j\equiv0\bmod p$ ，在等式两边同时乘上 $i^{-1}\times j^{-1}$ 有 $i^{-1}\equiv -k j^{-1}(\bmod{p})$ ，再将原式代入得：
$$
i^{-1}\equiv-\lfloor\frac{p}{i}\rfloor(p\bmod i)^{-1}(\bmod{p})
$$
取 $inv[i]$ 表示 $i$ 在模 $p$ 下得逆元，那么可以得到：
$$
inv[i]\ =\ (p-\frac{p}{i})\times inv[p\ \%\ i]\  \% \ p
$$

# 卢卡斯定理

## 基本内容

卢卡斯定理用于计算组合数模质数 $p$ 的值，尤其适用于当 $n$ 和 $k$ 较大时的高效计算。其核心思想是将 $n$ 和 $k$ 分解为 $p$ 进制数，逐位计算组合数的乘积并取模。
$$
\binom{n}{k}\ =\ \binom{\frac{n}{p}}{\frac{k}{p}}\ \binom{n\bmod{p}}{k\bmod{p}}
$$
其中 $\binom{\frac{n}{p}}{\frac{k}{p}}$ 可以继续用 Lucas 定理求解，设 $p$ 为质数，将 $n$ 和 $k$ 表示为 $p$ 进制数：
$$
n\ =\ n_mp^m + n_{m-1}p^{m-1}+\dots+n_0\\
k\ =\ k_mp^m + k_{m-1}p^{m-1}+\dots+k_0
$$
则组合数模 $p$ 的结果为：$\binom{n}{k}\ \equiv\ \prod_{i=0}^m \binom{n_i}{k_i}\pmod{p}$

```cpp
int n, k, p;
long long A[N], invA[N];

void Init() {
    A[0] = A[1] = invA[0] = invA[1] = 1;
    for(int i = 2; i <= n + k; i++) A[i] = A[i - 1] * i % p;
    for(int i = 2; i <= n + k; i++) {
        invA[i] = (p - p / i) * A[p % i] % p; // 计算 i 的逆元
        invA[i] = invA[i] * invA[i - 1] % p; // 计算 i! 的逆元
    }
}

long long Lucas(int x, int y) {
    if(x < y) return 0;
    else if(x < p) return A[x] * invA[y] % p * invA[x - y] % p;
    else return Lucas(x / p, y / p) * Lucas(x % p, y % p) % p;
}
```


## 推论

1.   $k_i \gt n_i$ 时，$\binom{n_i}{k_i}\ \equiv\ 0\pmod{p}$，即 $\binom{n}{k}\ \equiv\ 0\pmod{p}$

2.   当 $p=2$​ 时，将 $n$ 和 $m$ 分解为二进制位：$\binom{n}{m} \equiv \prod_{i=0}^k \binom{n_i}{m_i} \pmod{2}$ ，其中 $\binom{n_i}{m_i} \pmod{2}$ 的值为：
   
   - 当 $m_i \leq n_i$ 时，$\binom{n_i}{m_i} \equiv 1 \pmod{2}$ 
   - 当 $m_i > n_i$ 时，$\binom{n_i}{m_i} \equiv 0 \pmod{2}$

因此，**当且仅当 m 的二进制每一位都不超过 $n$ 的对应位（即 $n\ \&\ m\ =\ m)$** 时 ，组合数 $\binom{n}{m}\ \equiv\ 1\pmod{2}$

3.   $(1+x)^p\equiv1+x^p(\bmod{p})$

# 约数

## 约数个数

**约数个数定理**：若 $n\ =\ \prod_{i=1}^{s}p_i^{a_i}$ ，则 $d(n)\ =\ \prod_{i=1}^{s}(a_i+1)$ 

另有性质：
1. $d(n\cdot m)=\sum\limits_{x|n}\sum\limits_{y|n}\big[\gcd(x,y)=1\big]$
2. $\sum\limits_{i=1}^n\lfloor\frac{n}{i}\rfloor=\sum\limits_{i=1}^nd(i)$

**筛法求约数个数：**
用 $a[i]$ 记录 $i$ 的最小质因子次数，$d[i]$ 记录 $i$ 的约数。
若 $i$ 为质数，$a[i]\ =\ 1,\ d[i]\ =\ 2$ 。在线性筛中，每个合数 $m$ 都被 **最小的质因子** 筛去。设 $p_j$ 为 $m$ 的最小质因子，则 $m$ 通过 $m\ =\ p_j\times i$ 筛掉。那么有两种情况：

-   若 $i$ 能被 $p_j$ 整除，则 $p_j$ 为 $i$ 的最小质因子。此时，$a[m]\ =\ a[i]+1,\ d[m]\ =\ d[i]\ /\ a[m]\times(a[m]+1)$ 。
-   若 $i$ 不能，则 $i$ 不包含质因子 $p_j$ 。此时，$a[m]\ =\ 1,\ d[m]\ =\ d[i]\times2$ 。

```cpp
int a[N], d[N];
bool not_prime[N];
vector<int> prime;

void get_d(int n) {
    d[1] = 1;
    for(int i = 2; i <= n; i++) {
        if(!not_prime[i]) {
            prime.push_back(i);
            a[i] = 1, d[i] = 2;
        }
        for(int pri : prime) {
            int m = i * pri;
            if(m > n) break;
            not_prime[m] = true;
            if(i % pri == 0) {
                a[m] = a[i] + 1;
                d[m] = d[i] / a[m] * (a[m] + 1);
                break;
            } else {
                a[m] = 1, d[m] = d[i] * 2;
            }
        }
    }
}
```

## 约数和

**约数和定理**：若 $n\ =\ \prod_{i=1}^{s}p_i^{a_i}$ ，则 $f(n)\ =\ \prod_{i=1}^{s}\sum_{j=0}^{a_i}p_i^j$ 

-   **证明：**$pi^{a_i}$ 的约数有 $p_i^0,p_i^1,\dots,p_i^{a_i}$ 共 $(a_i+1)$ 个，其约数和为 $\sum_{j=0}^{a_i}p_i^{j}\ =\frac{1 - p_i^{a_i + 1}}{1 - p_i}$ 。根据乘法原理，$f(n)\ =\ \prod_{i=1}^{s}\sum_{j=0}^{a_i}p_i^j$ 。

**筛法求约数和：**
用 $g[i]$ 表示 $i$ 的最小质因子 $p_i$ 的 $\sum_{j=0}^{a_i}p_i^{j}$ ，$f[i]$ 表示 $i$ 的约数和。
若 $i$ 为质数，$g[i]\ =\ f[i]\ =\ i+1$ 。在线性筛中，每个合数 $m$ 都被 **最小的质因子** 筛去。设 $p_j$ 为 $m$ 的最小质因子，则 $m$ 通过 $m\ =\ p_j\times i$ 筛掉。那么有两种情况：

-   若 $i$ 能被 $p_j$ 整除，则 $p_j$ 为 $i$ 的最小质因子。此时有：

$$
\begin{aligned}
    g[i]&=p_j^0+p_j^1+\dots+p_j^{a_j}=\sum_{i=0}^{a_j}p_j^{i}\\
    g[m]&=p_j^0+p_j^1+\dots+p_j^{a_j+1}=g[i]\times p_i+1\\
    f[m]&=f[i]/\ g[i]\times g[m]
\end{aligned}
$$
-   若 $i$ 不能，则 $i$ 不包含质因子 $p_j$ 。此时有：

$$
\begin{aligned}
    g[m]&=p_{j+1}\\
    f[m]&=g[m]\times f[i]
\end{aligned}
$$

```cpp
bool not_prime[N];
vector<int> prime;
int g[N], f[N];

void get_f(int n) {
    g[1] = f[1] = not_prime[1] = true;
    for(int i = 2; i <= n; i++) {
        if(!not_prime[i]) {
            prime.push_back(i);
            f[i] = g[i] = i + 1;
        }
        for(int pri : prime) {
            int m = i * pri;
            if(m > n) break;
            not_prime[m] = true;
            if(i % pri == 0) {
                g[m] = g[i] * pri + 1;
                f[m] = f[i] / g[i] * g[m];
                break;
            } else {
                g[m] = pri + 1;
                f[m] = f[i] * g[m];
            }
        }
    }
}
```

# 数论分块

在 $O(\sqrt{n})$ 时间复杂度下计算有除法下取整的和式。

**性质**：

1.   分块的块数 $\le2\lfloor\sqrt{n}\rfloor$ 。
2.   $\forall a,b,c\in Z,\lfloor\frac{a}{bc}\rfloor=\lfloor\frac{\lfloor\frac{a}{b}\rfloor}{c}\rfloor$ 。
3.   $i$ 所在的块的值 $k=\lfloor\frac{n}{i}\rfloor$ ，所在块的右端点为 $\lfloor\frac{n}{\lfloor\frac{n}{i}\rfloor}\rfloor$ 。

**求解如下问题：**
$$
\sum_{i=1}^{n}f(i)\lfloor\frac{n}{i}\rfloor
$$
先预处理 $f(i)$ 的前缀和 $s(i)=\sum_{j=1}^{i}f(j)$ ，枚举每一块 $[l, r]$ ，有 $r=\lfloor\frac{n}{\lfloor\frac{n}{l}\rfloor}\rfloor$ ，该块的总和为 $(s(r)-s(l-1))\times\lfloor\frac{n}{l}\rfloor$ ，下一块的左端点为 $r+1$ 。

# 欧拉函数

**定义：**$1$ ~ $n$ 中与 $n$ 互质的个数为 $n$ 的欧拉函数的值，记为 $\varphi(n)$ 。

**性质：**
-   若 $p$ 为质数，$\varphi(p) = p-1$ ，$\varphi(p^{k}) = (p-1) p^{k}$；
-   $\sum_{d\mid n}\ \varphi(d)\ =\ n$ ；
-   积性函数：若 $\gcd(m,n) = 1$ ，则 $\varphi(m n) = \varphi(m) \varphi(n)$；

**计算公式：**
由 **唯一分解定理：**$n=\prod_{i=1}^{s} p_{i}^{a_i}$ ，那么有:
$$
\begin{aligned}
\varphi(n)=&\prod_{i=1}^{s}\ \varphi(p_{i}^{a_i})
=\prod_{i=1}^{s}\ (p_i - 1)\ p_{i}^{a_i-1}\\
=&\prod_{i=1}^{s}\ (1-\frac{1}{p_i})\ p_{i}^{a_i}
=n\ \times\ \prod_{i=1}^{s}\ \frac{p_i-1}{p_i}
\end{aligned}
$$
由此可见，欧拉函数只与 $n$ 和质因子决定，与次数无关。

## 求解欧拉函数

1.   **质因数分解：**

```cpp
int phi(int n) {
    int res = n;
    for(int i = 2; i * i <= n; i++) {
        if(n % i == 0) {
            res = res / i * (i - 1);
            while(n % i == 0) n /= i;
        }
    }
    if(n > 1) res = res / n * (n - 1);
    return res;
}
```

2.   **线性筛法：**
在线性筛中，每个合数 $m$ 都被 **最小质因子** $pri$ 筛掉，则 $m = pri\ \times\ i$ 。

-   若 $i$ 被 $pri$ 整除，则 $i$ 包含了 $m$ 的所有质因子。那么有：
$$
\varphi(m) = m\ \times\ \prod_{i=1}^{s}\ \frac{p_i-1}{p_i} = p_j\ \times\ i\ \times\ \frac{p_i-1}{p_i} = p_j\ \times\ \varphi(i)
$$
-   若 $i$ 不被 $pri$ 整除，则 $i$ 与 $pri$ 互质。那么有：
 $$\varphi(m) = \varphi(pri\times{i}) = \varphi(pri)\times\varphi(i) = (pri - 1)\times\varphi(i)$$

```cpp
vector<int> prime, phi[N];
bool not_prime(N);
 
void get_phi(int n) {
    phi[1] = 1;
    for(int i = 2; i <= n; i++) {
        if(!not_prime[i]) {
            prime.push_back(i);
            phi[i] = i - 1; // 质数的情况
        }
        for(int pri : prime) {
            int m = pri * i;
            if(m > n) break;
            not_prime[m] = true;
            if(i % pri == 0) {
                phi[m] = pri * phi[i];
                break;
            }
            phi[m] = (pri - 1) * phi[i];
        }
    }
}
```

## 欧拉降幂（扩展欧拉定理）

- **欧拉降幂**：对于任意互质正整数对 $\gcd(a,m)=1$，则 $a^{\varphi(m)}\equiv1\mod m$；
- **推广欧拉降幂**：$\forall a,m,n\in Z_+$，当 $n\ge\varphi(m)$ 时，$a^n=a^{n\%\varphi(m)+\varphi(m)}\mod m$；

定义幂塔为形如 $a^{{(a+1)^{\dots}}^{n}}\pmod{m}$ 这样的复合指数运算，取 $a$ 为底数，$n$ 为幂塔最高层，$m$ 为当前模数。计算该幂塔显然需要递归计算，递归会产生一个模数链 $m,\varphi(m),\varphi(\varphi(m)),\dots$，由于当 $m$ 为偶数时 $\varphi(m)\le \frac{m}{2}$，否则有 $\varphi(m)\lt m$，故其递归深度大约为 $O(\log m)$ 就会收敛到 $1$，故总的时间复杂度约为 $O(\sqrt{m})$。

```cpp
using ll = long long;
ll a, n;
ll qpow(ll x, ll n, ll k = mod){ll y=1;while(n){if(n&1)y=y*x%k;x=x*x%k;n>>=1;}return y;}

ll solve(ll a, ll m, bool &greater) {
	if(m == 1) {
		greater = true;
		return 0;
	}
	if(a > n) {
		greater = false;
		return 1;
	}
	ll phim = phi(m);
	bool judge = false;
	ll exp = solve(a + 1, phim, judge);
	if(judge) exp += phim;
	return qpow(a, exp, m);
}
```

# 积性函数与和性函数

## 积性函数

**定义：**

1.   若函数 $f(n)$ 满足 $f(1)=1$ ，且 $f(xy)=f(x)f(y)$ 对任意 $\gcd(x,y)=1$ 成立，则 $f(n)$ 为积性函数。
2.   若函数 $f(n)$ 满足 $f(1)=1$ ，且 $f(xy)=f(x)f(y)$ 对任意 $x,y\in N^*$ 成立，则 $f(n)$ 为完全积性函数。

---

## 和性函数

**定义：**

1.   若函数 $f(n)$ 满足 $f(1)=0$ ，且 $f(xy)=f(x)+f(y)$ 对任意 $gcd(x,y)=1$ 成立，则 $f(n)$ 为和性函数。
2.   若函数 $f(n)$ 满足 $f(1)=0$ ，且 $f(xy)=f(x)+f(y)$ 对任意 $x,y\in N^*$ 成立，则 $f(n)$ 为完全和性函数。

# 狄利克雷卷积

### 定义

对于两个积性函数 $f(n),g(n)$ ，其狄利克雷卷积形式为:
$$
(f*g)(n)=\sum\limits_{d|n}f(d)g(\frac{n}{d})=\sum\limits_{d|n}f(\frac{n}{d})g(d)
$$

或者表示为：
$$
h(n)=\sum\limits_{d|x}f(d)g(\frac{n}{d})=\sum\limits_{ab=n}f(a)g(b)
$$


1.   常用函数

-   元函数：$\epsilon(n)=[n=1]$ （卷积运算中的 **单位元** ，对于任意数论函数 $f$ 都有 $(f*\epsilon)(n)=f(n)$ ）
-   常数函数：$I(n)=1$
-   恒等函数：$id(n)=n$
-   约数和函数：$\sigma(n)=\sum_{d|n}d$
-   约数个数和函数：$d(n)=\sum_{d|n}1$

2.   常用卷积关系

-   $\sum\limits_{d|n}\mu(d)=[n=1]\Leftrightarrow (\mu*I)(n)=\epsilon(n)=[n=1]$
-   $\sum\limits_{d|n}\varphi(d)=n\Leftrightarrow (\varphi*I)(n)=id(n)=n$
-   $\sum\limits_{d|n}\mu(d)\frac{n}{d}=\varphi(n)\Leftrightarrow (\mu*id)=\varphi(n)$
-   $\sum\limits_{d|n}\varphi(d)\frac{n}{d}=\sum\limits_{k=1}^{n}\gcd(k,n)\Leftrightarrow (\varphi*id)=\sum\limits_{k=1}^{n}\gcd(k,n)$
-   $(f*I)(n)=\sum\limits_{d|n}f(d)$

### 和式变换

1.   整除与区间转换
$$
\sum_{d|n}d=\sum_{d=1}^nd[d|n]
$$

2.   交换求和顺序
将内外层求和变量调换，利用莫比乌斯函数性质化简计算。例如：

$$
\sum_{i=1}^{n}\sum_{d|i}\mu(d)f(\frac{i}{d})=\sum_{d=1}^{n}\mu(d)\sum_{k=1}^{\lfloor\frac{n}{d}\rfloor}f(k)
$$

3.   数论分块

4.   变量替换与参数分离
 通过设 $t=k\cdot d$ 等变量替换，将双重求和转为单变量求和。例如：

$$
\sum_{d=1}^{n}\sum_{k=1}^{\lfloor\frac{n}{d}\rfloor}f(d,k)=\sum_{t=1}^n\sum_{d|t}f(d,\frac{t}{d})
$$


5.   积性函数分解
对积性函数的和式，分解为质因子幂次处的乘积。例如：

-   对于 $n=p_1^{k_1}p_2^{k_2}\dots p_m^{k_m}$ ，计算和式：$\sum_{d|n}\mu(d)\varphi(d)$ ，和式可分解为各个质因子幂对应和式的乘积：

$$
\sum_{d|n}\mu(d)\varphi(d)=\prod_{p|n}\sum_{d|p^k}\mu(d)\mu(d)\\
$$

-   对每个质因子 $p^k$ ，计算其对应和式 $\sum_{d|p^k}\mu(d)\mu(d)$ ，当 $d=p^a(a\le k)$ 时有：
$$
\mu(p^a)=\begin{cases}
1, & a = 0\\
-1, & a = 1\\
0, & a\ge2
\end{cases}\\
\varphi(p^a)=p^a-p^{a-1}
$$
代入和式可得：
$$
\begin{aligned}
\sum_{a=0}^k\mu(p^a)\cdot\varphi(p^a)=&\mu(1)\varphi(1)+\mu(p)\varphi(p)+\sum_{a=2}^k\mu(p^a)\varphi(p^a)\\
=&1\times1+(-1)\times(p-1)=2-p
\end{aligned}
$$

-   合并所有质因子贡献可得：
$$
\sum_{d|n}\mu(d)\varphi(d)=\prod_{p|n}(2-p)
$$

6.   容斥定理
将问题转化为多重集合的容斥，莫比乌斯函数作为容斥系数。例如：

$$
\sum_{k=1}^m[gcd(k,n)=1]=\sum_{d|n}\mu(d)\cdot\lfloor\frac{m}{d}\rfloor
$$

# 莫比乌斯反演

## 莫比乌斯函数

**定义：** 由唯一分解定理有 $n\ =\ \prod_{i=1}^{s}p_i^{a_i}$ 。
$$
\mu(n)=\begin{cases}
1, & n = 1\\
(-1)^s, & n = \prod_{i=1}^{s}p_i\\
0, &others
\end{cases}
$$

### 求解莫比乌斯函数

若 $i$ 为质数，$\mu(i)=-1$。
取 $p_j$ 为 $m$ 的最小质因子，则 $m$ 通过 $m=i\times p_j$ 筛掉。

-   若 $i$ 能被 $p_j$ 整除，则 $i$ 也包含质因子 $p_j$ 。此时，$\mu(m)=0$ 。
-   若 $i$ 不能被 $p_j$ 整除，则 $m$ 比 $i$ 多一个不同的质因子 $p_j$ 。此时，$\mu(m)=\mu(p_j\times i)=-\mu(i)$ 。

```cpp
bool not_prime[N];
vector<int> prime;
int mu[N];

void get_mu(int n) {
    mu[1] = 1;
    for(int i = 2; i <= n; i++) {
        if(!not_prime[i]) {
            prime.push_back(i);
            mu[i] = -1;
        }
        for(int pri : prime) {
            int m = pri * i;
            if(m > n) break;
            not_prime[m] = true;
            if(i % pri == 0) {
                mu[m] = 0;
                break;
            }
            mu[m] = -mu[i];
        }
    }
}
```

# 常见求和化简

1. ${\sum\limits_{d|n}\varphi(d)=n}$

取 $n$ 的正因数为 $d_1,\ d_2,\ \dots,\ d_k$ ，对于每个 $d_i$ ，考虑集合 $A_{d_i}\ =\ \{1,\ 2,\ \dots,\ n\ |\ gcd(x, n)\ =\ d_i \}$，对于 $gcd(x, n)\ =\ d$ ，有 $gcd(\frac{x}{d},\frac{n}{d})\ =\ 1$ 。那么集合 $A_d$ 中的元素个数为小于等于 $\frac{n}{d}$ 且与 $\frac{n}{d}$ 互质的正整数个数，即 $|A_d|\ =\ \varphi(\frac{n}{d})$ 。
而由于对于每个数字 $x\in\{1,\ 2,\ \dots,\ n\}$，都有 $gcd(x, n) \in \{d_1,\ d_2,\ \dots,\ d_k\}$ ，那么 $\{1,\ 2,\ \dots,\ n\}$ 可以被划分为互不相交的子集 $A_{d_1}, A_{d_2}, A_{d_k}$ ，所以有：
$$
n=\sum_{i=1}^{k}|A_{d_i}|=\sum\nolimits_{d|n}\varphi(\frac{n}{d})=\sum\nolimits_{d|n}\varphi(d)
$$

2. ${\sum\limits_{k=1}^{n}\gcd(k,n)=\sum_{d|n}d\ \varphi(\frac{n}{d})}$

对于固定的 $d$ ，$d$ 是 $n$ 的正因数，考虑满足 $gcd(k,n)\ =\ d$ 的 $k$ 集合。
取 $k\ =\ ld$ ，那么有  $gcd(l,\frac{n}{d})\ =\ 1$ ，且有 $1\le l\le\frac{n}{d}$ 。满足 $gcd(l,\frac{n}{d})\ =\ 1$ 的 $l$ 的个数为 $\varphi(\frac{n}{d})$ ，此时 $k\ =\ ld$ ，所以满足 $gcd(k,n)\ =\ d$ 的所有 $k$ 的和 为：
$$
d\sum\nolimits_{l:gcd(l,\frac{n}{d})=1,\ 1\le l\le \frac{n}{d}} l\ =\ d\ \varphi(\frac{n}{d})\\
$$
即
$$
\begin{aligned}
\sum_{k=1}^{n}\gcd(k,n)=\sum\nolimits_{d|n}d\ \varphi(\frac{n}{d})
\end{aligned}
$$


3. ${\sum\limits_{d|n}\mu(d)=[n=1]}$

当 $n=1$ 时显然成立；当 $n\gt1$ 时，取 $n=p_1^{a_1}p_2^{a_2}\dots p_k^{a_k}(a_i\ge1,i=1,2,\dots,k)$ 为 $n$ 的素因数分解式，$n$ 的一个正因子 $d=p_1^{b_1}p_2^{b_2}\dots p_k^{b_k}(0\le b_i\le a_i,i=1,2,\dots,k)$ 。由莫比乌斯函数定义，当且仅当 $\forall i\in[1,k],b_i=0/1$ 时，$\mu(d)\neq0$ ，仅考虑非 $0$ 的 $\mu(d)$ 即可。
现在考虑 $\sum_{d|n}\mu(d)$ ，根据二项式定理，从 $k$ 个素因子 $p_1,p_2,\dots,p_k$ 中选取 $r$ 个素因子的组合数为 $C_k^r$ ，当 $d$ 由这 $r$ 个因子组成时，有 $\mu(d)=(-1)^r$ ，那么 $\sum_{d|n}\mu(d)=\sum_{r=0}^kC_k^r(-1)^r$ 。由二项式定理有 $(a+b)^k=\sum_{r=0}^{k}C_k^ra^rb^{k-r}$ ，取 $a=-1,b=1$ ，那么可以得到 $\sum_{r=0}^kC_k^r(-1)^r=(-1+1)^k=0$ ，结论得证。

4. ${\sum\limits_{d|n}\mu(d)\frac{n}{d}=\varphi(n)}$

当 $n=1$ 时显然成立；当 $n\gt1$ 时，取 $n=p_1^{a_1}p_2^{a_2}\dots p_k^{a_k}(a_i\ge1,i=1,2,\dots,k)$ ，$n'=p_1p_2\dots p_k$ ，变形得到 $\sum\limits_{d|n}\mu(d)\frac{n}{d}=n\sum\limits_{d|n'}\frac{\mu(d)}{d}$ ，由于约数由质因子或其乘积组成，根据 $n'$ 每个约数的质因子个数分组，根据容斥原理可得： 
$$
\begin{aligned}
n\sum\limits_{d|n'}\frac{\mu(d)}{d}&=n(1-(\frac{1}{p_1}+\dots+\frac{1}{p_k})+(\frac{1}{p_1p_2+\dots+p_{k-1}p_k})-\dots) \\
&=n(1-\frac{1}{p_1})(1-\frac{1}{p_2})\dots(1-\frac{1}{p_k}) \\
&=\varphi(n)
\end{aligned}
$$

5. $\sum\limits_{i\le n}\sum\limits_{d|i}\mu(d)=\sum\limits_{d\le n}\lfloor{\frac{n}{d}}\rfloor\mu(d)$ 

6. $\sum\limits_{i\le n}\sum\limits_{j\le m}[\gcd(i,j)=1]=\sum\limits_{d\le\min(n,m)}\mu(d)\lfloor{\frac{n}{d}}\rfloor\lfloor{\frac{m}{d}\rfloor}$
$$
\begin{aligned}
\sum\limits_{i=1}^n\sum\limits_{j=1}^m[\gcd(i,j)=1]=&\sum\limits_{i=1}^n\sum\limits_{j=1}^m\sum\limits_{d|\gcd(i,j)}\mu(d)\\
=&\sum\limits_{d=1}^{\min(n,m)}\mu(d)\sum\limits_{i=1,d|i}^n\sum\limits_{j=1,d|j}^m\\
=&\sum\limits_{d\le\min(n,m)}\mu(d)\sum\limits_{i=1}^{\lfloor\frac{n}{d}\rfloor}\sum\limits_{j=1}^{\lfloor\frac{m}{d}\rfloor}\\
=&\sum\limits_{d\le\min(n,m)}\mu(d)\lfloor {\frac{n}{d}} \rfloor\lfloor{\frac{m}{d}}\rfloor
\end{aligned}
$$

7. $\sum\limits_{i\le n}\sum\limits_{j\le m}\gcd(i,j)=\sum\limits_{d\le min(n,m)}\varphi(d)\lfloor{\frac{n}{d}}\rfloor\lfloor{\frac{m}{d}\rfloor}$
$$
\begin{aligned}
\sum\limits_{i\le n}\sum\limits_{j\le m}\gcd(i,j)=&\sum\limits_{i=1}^n\sum\limits_{j=1}^m\sum\limits_{d|\gcd(i,j)}\varphi(d)\\
=&\sum\limits_{d=1}^{\min(n,m)}\varphi(d)\sum\limits_{i=1}^n\big[d|i\big]\sum\limits_{j=1}^m\big[d|j\big]\\
=&\sum\limits_{d\le min(n,m)}\varphi(d)\lfloor{\frac{n}{d}}\rfloor\lfloor{\frac{m}{d}\rfloor}
\end{aligned}
$$
