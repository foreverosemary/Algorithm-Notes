# 辛普森公式

对二次函数 $f(x)=ax^2+bx+c$ 在区间 $\big[l,r\big]$ 上求定积分（即图像与 $x$ 轴围成的面积），原函数 $F(x)=\frac{a}{3}x^3+\frac{b}{2}x^2+cx+d$。
$$
\begin{aligned}
\int_{l}^{r}f(x)\,dx=&\frac{a}{3}(r^3-l^3)+\frac{b}{2}(r^2-l^2)+c(r-l)\\
=&\frac{r-l}{6}(2al^2+2ar^2+2alr+3bl+3br+6c)\\
=&\frac{r-l}{6}\big[(al^2+bl+c)+(ar^2+br+c)+4(a(\frac{l+r}{2})^2+b(\frac{l+r}{2})+c)\big]\\
=&\frac{r-l}{6}\big(f(l)+f(r)+4f(\frac{l+r}{2})\big)
\end{aligned}
$$
# 自适应辛普森法

对积分区间不断二分，每次判断当前段和二次函数的相似程度（比较当前段直接代入计算的值，和从中点分割成两端的积分之和的差距大小），如果足够相似就可以直接代入辛普森公式计算，否则将当前段分割成左右两端递归求解。

```cpp
double simpson(double l, double r) {
    return (r - l) * (f(l) + f(r) + 4 * f((l + r) / 2)) / 6;
}

double asr(double l, double r, double eps, double ans, int step) {
    double mid = (r + l) / 2;
    double fl = simpson(l, mid), fr = simpson(mid, r);
    if(fabs(fl + fr - ans) <= 15 * eps && step < 0)
        return fl + fr + (fl + fr - ans) / 15;
    return asr(l, mid, eps / 2, fl, step - 1) + asr(mid, r, eps / 2, fr, step - 1);
}
```
