# 组合数学基础

## 四个基本的计数原理

1. 加法原理：设集合 $S$ 被划分为两两不相交的部分 $S_1,S_2,\dots,S_m$。则 $S$ 中满足某个要求的对象的数目可以通过确定它的每一个部分中满足某个要求的对象数目并如此相加得到：$$\begin{aligned}|S|=|S_1|+|S_2|+\dots+|S_m|\end{aligned}$$如果允许集合 $S_1,S_2,\dots,S_m$ 相交，那么需要用到容斥定理对公式修正。
2. 乘法原理：令 $S$ 是对象的有序对 $(a,b)$ 的集合，其中第一个对象 $a$ 来自大小为 $p$ 的一个集合，而对于对象 $a$ 的每个选择，对象 $b$ 有 $q$ 种选择。于是 $S$ 的大小为：$$\begin{aligned}|S|=p\times q\end{aligned}$$另一种理解是，对于两项独立事件，第一个事件有 $p$ 种结果，而不论第一个事件结果如何，第二个事件都有 $q$ 种结果，那么这两个事件连续执行或发生就有 $p\times q$ 种结果
3. 减法原理：令 $A$ 是一个集合，$U$ 是包含 $A$ 的更大集合（多数情况下为全集）。取$$\begin{aligned}\overline{A}=U-A=\{x\in U:x\notin A\}\end{aligned}$$ 是 $A$ 在 $U$ 中的补，那么 $A$ 的对象数目为：$$|A|=|U|-|\overline{A}|$$
4. 除法原理：令 $S$ 为一个有限集合，把它划分成 $k$ 个部分使得每一个部分包含的对象数目相同，于是，此划分中的部分的数目为：$$k=\frac{|S|}{\text{在一个部分中的对象数目}}$$

## 排列与组合

### 排列与组合基础

1. 排列数：从 $n$ 个不同的元素中，任取 $m$ 个元素按一定顺序排成一列的所有排列个数，称为排列数，用 $A_n^m$ 表示：$$A_n^m=n(n-1)(n-2)\dots(n-m+1)=\frac{n!}{(n-m)!}$$
2. 组合数：从 $n$ 个不同元素中，任取 $m$ 个元素组成一个集合的所有不同集合个数，称为组合数，用 $\binom{n}{m}$ 表示：$$\binom{n}{m}=\frac{A_n^m}{m!}=\frac{n!}{m!(n-m)!}$$
3. 多重集合：除其成员不必不同以外与集合一样，可以表示为：$$M=\{a_{1}\cdot x_1,a_{2}\cdot x_2,\dots,a_{n}\cdot x_n\}$$
4. 循环排列（圆排列）：排列数考虑的是线性排列，如果将对象排列成一个圆环，可以通过旋转使得两个看似不同的圆环相同，如 $123456$ 与 $234561$。考虑到含有 $r$ 元素的线性排列有 $r$ 种循环排列方案，因此 $n$ 个元素的循环 $r$ 排列的数目为：$$\frac{A_n^r}{r}=\frac{n!}{r\cdot(n-r)!}$$当 $r=n$ 时，公式变为 $(n-1)!$。

### 插板法

插板法（星条法、挡板法）：用于求解将相同元素分组的方案数。

1. 将 $n$ 个完全相同的元素分为 $k$ 组，且每组至少有一个元素，一共有多少种划分方案？问题等价于求 $x_1+x_2+\dots+x_k=n$ 的正整数解的组数。

将 $k-1$ 块板子插入到 $n$ 个元素（在这里视作 $n$ 个 $1$ 排成一排）两两之间形成的 $n-1$ 个空里面，形成了 $k$ 个部分，由于元素相同，每个部分内部无需排序，那么方案数为 $\binom{n-1}{k-1}$。

2. 将 $n$ 个完全相同的元素分为 $k$ 组，且每组允许为空，一共有多少种划分方案？问题等价于求 $x_1+x_2+\dots+x_k=n$ 的非负整数解的组数。

取 $t_1=x_1+1,t_2=x_2+1,\dots,t_k=x_k+1$，那么问题转化为 $t_1+t_2+\dots+t_k=n+k$ 的正整数解的组数，方案数为 $\binom{n+k-1}{k-1}=\binom{n+k-1}{n}$。 

3. 将 $n$ 个完全相同的元素分为 $k$ 组，第 $i$ 组需要满足至少有 $a_i$，且最多有 $b_i$ 个元素，一共有多少种划分方案？问题等价于求 $x_1+x_2+\dots+x_k=n$ 且满足 $a_1\le x_1\le b_1,a_2\le x_2\le b_2,\dots,a_k\le x_k\le b_k$ 的解的组数。

同样先只考虑下界引入新变量 $$t_1=x_1-a_1,t_2=x_2-a_2,\dots t_k=x_k-a_k$$那么原不等式转化为$$0\le t_1\le b_1-a_1,0\le t_2\le b_2-a_2,\dots,0\le t_k\le b_k-a_k$$且方程转化为$$t_1+t_2+\dots+t_k=n-a_1-a_2-\dots-a_k$$取 $n'=n-a_1-\dots-a_k$，$S$ 是满足上述方程的所有非负整数解集合，其大小为$$|S|=\binom{n'+k-1}{n'}$$设 $P_i$ 是 $t_i\ge b_i-a_i+1$ 的性质，$A_i$ 表示  中满足性质 $P_i$ 的解组成的子集，我们需要计算 $\overline{A_1}\cap\overline{A_2}\cap\dots\cap\overline{A_k}$ 的大小，根据容斥原理，集合 $A_i$ 由  中满足 $t_i\ge b_i-a_i+1$ 的解组成，做变量代换（仅 $z_i=t_i-b_i+a_i-1$，其余 $z_j=t_j(j\neq i)$），则 $A_i$ 的大小为$$|A_i|=\binom{(n'-b_i+a_i-1)+k-1}{n'-b_i+a_i-1}=\binom{(n'-b_i+a_i-1)+k-1}{k-1}$$故最终计算结果如下
$$
\begin{aligned}
|\overline{A_1}\cap\overline{A_2}\cap\dots\cap\overline{A_k}|=&S-\sum\limits|A_i|+\sum\limits|A_i\cap A_j|-\sum\limits|A_i\cap A_j\cap A_k|\\&+\dots+(-1)^k|A_1\cap\dots\cap A_k|
\end{aligned}
$$

### 多重集合的排列

1. 设 $S$ 为多重集合，它有 $k$ 种不同类型的对象，每一种类型的有限重复数是 $n_1,n_2,\dots,n_k$。设 $S$ 的大小为 $n=n_1+n_2+\dots+n_k$。则 $S$ 的排列数目为：$$\frac{n!}{n_1!n_{2}!\dots n_k!}=\frac{n!}{\prod_{i=1}^kn_i!}$$其中分子为 $n$ 个元素的排列数，对分母的解释是，考虑到不同类型的元素是可以区分的，但同一类型的元素是不可区分的。对于每种类型 $i$，由于其 $n_i$ 个元素不可区分，在全排列中会将这 $n_i$ 个元素的 $n_i!$ 种内部排列都计为不同排列，但实际上这些排列都是完全相同的。那么根据乘法原理，有 $\prod_{i=1}^kn_i!$ 个排列是重复的，分母除以该结果即可消序。

2. 另一种解释是等价于将一个含有 $n$ 个不同元素的集合划分为指定大小的各个部分，每个部分是被 **标号** 的、相互不同的。但倘若各个部分仍被指定大小，但取消标号，即互不区分，就还需要对各个部分组成的排列进行消序，其划分方法数变为：$$\frac{n!}{k!n_1!n_{2}!\dots n_k!}=\frac{n!}{k!\prod_{i=1}^kn_i!}$$
### 多重集合的组合

设 $S$ 为多重集合，它有 $k$ 种不同类型的对象，且每一种类型均有无限的重复数，又或者每个对象的重复数 $n_{i}\ge r$（$r$ 是 $S$ 取出来进行组合的元素个数），因为 $S$ 的任意 $r$ 组合都呈 $\{x_{1}\cdot a_1,x_{2}\cdot a_2,\dots,x_{k}\cdot a_k\}$ 的形式，其中 $x_1,x_2,\dots,x_k$ 都为非负整数，且 $x_1+x_2+\dots+x_k=r$。因此 $S$ 的 $r$ 组合个数等于方程 $x_1+x_2+\dots+x_k=r$ 的非负整数解的个数，考虑隔板法其个数为：$$\binom{r+k-1}{r}=\binom{r+k-1}{k-1}$$

## 鸽巢原理

>**鸽巢原理：将 $n$ 个物体放进 $a$ 个盒子，那么至少有一个盒子内的物品数量不多于 $\lfloor\frac{n}{a}\rfloor$，且至少有一个盒子内的物品数量不少于 $\lceil\frac{n}{a}\rceil$。**

- 将 $n+1$ 个物体放进 $n$ 个盒子，那么至少有一个盒子包含两个或更多的物体。
- 将 $n(r-1)+1$ 个物体放进 $n$ 个盒子，那么至少有一个盒子含有不少于 $r$ 个的物体（每个盒子都先放 $r-1$ 个物体，最后剩余一个物体放入任何一个盒子即可，是平均原理的一种体现）。
- 将 $q_1+q_2+\dots+q_n-n+1$ 个物体放入 $n$ 个盒子，至少存在一个 $i$ 满足第 $i$ 个盒子里至少有 $q_i$ 个物体。

### 鸽巢原理的运用

- 给定 $m$ 个整数 $a_1,a_2,\dots,a_m$，存在满足 $0\le l\lt r\le m$ 的整数 $l$ 和 $r$，使得 $a_{l+1}+a_{l+2}+\dots+a_r$ 能够被 $m$ 整除。或者说，在序列 $a_1,a_2,\dots,a_m$ 中存在连续的 $a$，这些 $a$ 的和能够被 $m$ 整除。

证明：考虑 $m$ 个和 $a_1,a_1+a_2,\dots,a_1+a_2+\dots+a_m$，将每个和对 $m$ 取模，得到 $0,1,2,\dots,m-1$ 中的一个数。倘若存在一个和取模后为 $0$，显然得证；若不存在和取模后为 $0$，由于共有 $m$ 个和，而只有 $m-1$ 个数字与之对应，那么必然存在两个和对 $m$ 取模后结果相等。因此，存在整数 $l,r\ (l\lt r)$，使得$$a_1+a_2+\dots+a_{l}\equiv a_1+a_{2}+\dots+a_{r}\mod{m}$$将左右两式相减即可得到$$a_{l+1}+\dots+a_{r}\equiv0\mod{m}$$从而 $a_{l+1}+\dots+a_r$ 能够被 $m$ 整除。

- 每个由 $n^2+1$ 个实数构成的序列 $a_1,a_2,\dots,a_{n^2+1}$ 要么含有长度为 $n+1$ 的非降子序列，要么含有长度为 $n+1$ 的非增子序列。

证明：假设不存在长度为 $n+1$ 的非降子序列，证明必然存在长度为 $n+1$ 的非升子序列。对于每一个 $k=1,2,\dots,n^2+1$，设 $m_k$ 为从 $a_k$ 开始的最长的非降子序列的长度。假设对于每一个 $k=1,2,\dots,n^2+1$，有 $1\le m_k\le n$，使得不存在长度为 $n+1$ 的非降子序列，所以 $m_1,m_2,\dots,m_{n^2+1}$ 是 $1$ 和 $n$ 之间的 $n^2+1$ 个整数。由鸽巢原理可知，$m_1,m_2,\dots,m_{n^2+1}$ 中有 $n+1$ 个是相等的。令$$m_{k_1}=m_{k_2}=\dots=m_{k_{n+1}}$$其中 $1\le k_1\lt k_2\lt\dots\lt k_{n+1}\le n^2+1$，假设对于某个 $i=1,2,\dots,n$，有 $a_{k_i}\lt a_{k_{i+1}}$。那么，由于 $k_i\lt k_{i+1}$，对于从 $a_{k_{i+1}}$ 开始的最长的非降子序列，将 $a_{k_i}$ 放在前面得到一个从 $a_{k_i}$ 开始的长度为 $m_{k_i}=m_{k_{i+1}}+1$ 非降子序列，与 $m_{k_i}=m_{k_{i+1}}$ 矛盾。因此 $a_{k_i}\ge a_{k_{i+1}}$。由于这对于 $i=1,2,\dots,n$ 均成立，因此有：$$a_{k_1}\ge a_{k_2}\ge\dots\ge a_{k_{n+1}}$$从而得出存在一个长度为 $n+1$ 的非升子序列。

### 补集策略

**补集策略** 即一种 **基于鸽巢原理的划分**，此类题目通常限制操作次数为 $\lfloor\frac{Total}{k}\rfloor$，通用解法是构造 $k$ 个互斥且并集为全集的方案。

假设所有可能的修改操作集合为全集 $U$，那么需要构造 $k$ 种修改策略 $U_1,U_2,\dots,U_k$，分别对应修改后的状态 $S_1,S_2,\dots,S_k$。如果这 $k$ 种策略满足以下两个条件：
1. 覆盖性：对于每个单独的操作方式，其仅在一个策略中出现，即（用 $|U_i|$ 表示策略 $i$ 所需操作次数）
$$|U_1|+|U_2|+\dots+|U_k|=|U|$$
也就是说这 $k$ 个修改策略是对全集 $U$ 的一个划分。
2. 有效性：要求 $k$ 个结果状态 $S_1,S_2,\dots,S_k$ 都符合题目最终要求。

那么根据鸽巢原理，$U_1,U_2,\dots,U_k$ 中必然存在一个策略，其修改次数满足：
$$\min(|U_1|,|U_2|,\dots,|U_k|)\le\lfloor\frac{|U|}{k}\rfloor$$

### 习题

- **题目链接**：[P9820 [ICPC 2020 Shanghai R] Mine Sweeper II](https://www.luogu.com.cn/problem/P9820)

**题目大意**：给定两个 $n\times m$ 大小的扫雷图 $A,B$，网格中的每个单元格要么是地雷单元格，要么是非地雷单元格。地雷单元格上没有数字，而每个非地雷单元格有一个数字，表示其周围 $8$ 个格子中地雷单元格的数量。每次修改可以将地雷单元格修改为非地雷单元格，或者将非地雷单元格修改为地雷单元格，问是否存在某种修改方法，将 $B$ 修改最多 $\lfloor\frac{nm}{2}\rfloor$，使得 $B$ 的非地雷单元格的数字之和与 $A$ 的非地雷单元格的数字之和相等。

**题目分析**

- 从限制入手，其修改次数上限为 $\lfloor\frac{nm}{2}\rfloor$ 次，那么需要找到两种修改方案。考虑两种不存在交集的修改方案 $S$ 和 $S'$ 使得 $B$ 的数字之和与 $A$ 相等，且修改方案的操作次数满足 $|S|+|S'|=n\cdot m$，这样根据鸽巢原理有：
$$\min(|S|,|S'|)\le\lfloor\frac{nm}{2}\rfloor$$
- 定义地雷图 $A$ 的反图 $\overline{A}$ 为原图中地雷单元格变为非地雷单元格、非地雷单元格变为地雷单元格的生成图。将地雷单元格视作黑色，非地雷单元格视作白色，那么数字之和即为所有的黑白交界线的数量（每一对相邻的黑白格子，都会为白色格子上的数字贡献 $1$）。将地图取反时，原来的黑白相连对变成了白黑相邻对，但依然是不同颜色相邻，因此交界线的总数量不变，故数字之和自然不变。
- 因此有对于 $B$ 来说有方案 $S$ 变换到 $A$，以及不存在交集的修改方案 $S'$ 变换到 $\overline{A}$。对于任意坐标 $(i, j)$，如果 $B_{i,j} = A_{i,j}$，则 $B_{i,j} \neq \overline{A}_{i,j}$。这意味着每个格子要么在 $S$ 中被修改，要么在 $S'$ 中被修改，绝无重叠。
- 由于 $|S|+|S'|=n\cdot m$ 且不存在交集，输出两种方案中修改次数更小的方案所对应的图即可。

```cpp
#include<bits/stdc++.h>
#define endl '\n'

using namespace std;
using ll = long long;
using vstr = vector<string>;

void solve() {
	int n, m; cin >> n >> m;
	vstr a(n), b(n);
	for(int i = 0; i < n; i++) {
		cin >> a[i];
	}
	for(int i = 0; i < n; i++) {
		cin >> b[i];
	}
	ll lim = n * m / 2, ans = 0;
	for(int i = 0; i < n; i++) {
		for(int j = 0; j < m; j++) {
			if(b[i][j] == a[i][j]) {
				ans++, b[i][j] = (b[i][j] == '.' ?  'X' : '.');
			}
		}
	}
	if(ans <= lim) {
		for(int i = 0; i < n; i++) cout << b[i] << endl;
	} else {
		for(int i = 0; i < n; i++) cout << a[i] << endl;
	}
}

int main() {
	ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
	solve();
	return 0;
}

```
- **题目链接**：[C2. Errich-Tac-Toe (Hard Version)](https://codeforces.com/contest/1450/problem/C2)

**题目大意**：给定 $n\times n$ 棋盘，部分格子有 $X$ 或 $O$。操作是将 $X$ 变 $O$ 或 $O$ 变 $X$。求一种不超过 $\lfloor\frac{k}{3}\rfloor$ 次操作的方案（$k$ 为棋子总数），使得棋盘上不存在横向或纵向连续 3 个相同的棋子。

**题目分析**

- 从限制入手，其修改操作次数上限为 $\lfloor\frac{k}{3}\rfloor$，那么需要找到 $3$ 种并列不相交的操作方案 $S_1,S_2,S_3$ 使得 $|S_1|+|S_2|+|S_3|=k$，这样根据鸽巢原理有：
$$\min(|S_1|,|S_2|,|S_3|)\le\lfloor\frac{k}{3}\rfloor$$
- 取棋子为第 $i$ 类表示对于第 $r$ 行第 $c$ 列的棋子 $(r,c)$ 满足 $r+c\equiv i\pmod{3}$，若 $3$ 个棋子连续出现在同一行或者同一列的情况，那么这三个棋子两两互不同类。故存在以下三种修改策略：
1. $S1$：若第 $0$ 类棋子中出现 $X$，则将其修改成 $O$；若第 $1$ 类棋子中出现 $O$，将其修改成 $X$。
2. $S_2$：若第 $1$ 类棋子中出现 $X$，则将其修改成 $O$；若第 $2$ 类棋子中出现 $O$，将其修改成 $X$。
3. $S_3$：若第 $2$ 类棋子中出现 $X$，则将其修改成 $O$；若第 $0$ 类棋子中出现 $O$，将其修改成 $X$。

- 由于 $|S_1|+|S_2|+|S_3|=k$ 且这三种方案中不存在一样的操作，故输出三种方案中修改次数更小的方案所对应的图即可。

```cpp
#include<bits/stdc++.h>
#define endl '\n'

using namespace std;
using ll = long long;
using vstr = vector<string>;

void solve() {
	int n; cin >> n;
	int sum = 0;
	vstr g(n);
	for(int i = 0; i < n; i++) {
		cin >> g[i];
		for(int j = 0; j < n; j++) sum += (g[i][j] != '.');
	}
	for(int k = 0, ans = 0; k < 3; k++) {
		vector<string> res(g);
		for(int i = 0; i < n; i++) {
			for(int j = 0; j < n; j++) {
				int flag = (i + j) % 3;
				if(flag == k && g[i][j] == 'X') {
					g[i][j] = 'O';
					ans++;
				} else if(flag == (k + 1) % 3 && g[i][j] == 'O') {
					g[i][j] = 'X';
					ans++;
				}
			}
		}
		if(ans <= sum / 3) {
			break;	
		} else {
			ans = 0;
			swap(res, g);
		}
	}
	for(int i = 0; i < n; i++) cout << g[i] << endl;
}

int main() {
	ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
	int t = 1; cin >> t;
	while(t--) {
		solve();
	}
	return 0;
}
```
