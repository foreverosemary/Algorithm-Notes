# 01 背包

- 有 $N$ 件物品和一个容量为 $V$ 的背包。第 $i$ 件物品的体积是 $v_i$，价值是 $w_i$，求解将物品放入背包后能够达到的最大价值和。

定义 $\text{dp}[i][j]$ 表示考虑前 $i$ 件物品放入一个容量为 $j$ 的背包获得的最大价值，转移方程为：
$$\text{dp}[i][j]=\max(\text{dp}[i-1][j],\text{dp}[i-1][j-v_i]+w_i)$$
若题目所给容量过大，如 $V\le10^{18}$，但 $n\cdot w_i$ 较小时，要改变枚举顺序。此时 $\text{dp}[i][j]$ 表示考虑前 $i$  件物品时获得最大价值 $j$ 所需的最小背包容量（可行性 DP）。转移方程变为：
$$\text{dp}[i][j]=\min(\text{dp}[i-1][j],\text{dp}[i-1][j-w_i]+v_i)$$

## 空间复杂度优化

原方法中的空间复杂度为 $O(NV)$，但注意到每次转移都只跟上一行数据有关，故可以通过滑动数组优化到 $O(V)$。再观察方程可发现该列的值只跟上一行的同一列或者往前的列有关，而跟上一行的往后的列无关。因此如果直接在第 $i-1$ 行从后往前遍历，如果当前遍历到第 $j$ 列，那么 $1\sim j$ 的值都还是第 $i-1$ 行的值，而 $j+1\sim V$ 的值已经更新成了第 $i$ 行的值。那么根据这个原理可以直接将空间压缩成一维，即优化到 $O(V)$，其遍历过程更改为：

```plaintext
for(int i = 1; i <= N; i++) {
	for(int j = V; j >= v[i]; j--) {
		dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
	}
}
```

同时，如果修改内层循环下界为 $\max(V-\sum_{k=i+1}^Nv_k,v_i)$，那么可以得到一个在时间复杂度上的常数级别优化。该优化为一个剪枝操作，如果当前容量 $j$ 加上后面所有物品的总费用小于 $V$，即 $j\lt V-\sum_{k=i+1}^Nv_k$，那么后面无论怎么选，都无法到达总容量 $V$，故不用更新。**但在使用该优化后，$\text{dp}$ 数组中的其它值可能是错误的，即不是当前容量下的最大价值**。

## 初始化问题

倘若有的题目求解的是 **恰好装满背包时的最优解**，而非背包任意状态下的最优解，那么仅需要不同的初始化即可实现题目要求。
- 恰好装满背包：初始化 $\text{dp}[0]=0$，对于其它 $\text{dp}[1\sim V]$ 均设为 $-\infty$，这样可以保证最终得到的 $\text{dp}[V]$ 一定是一种恰好装满背包的最优解，如果不存在，则为 $-\infty$。
- 任意状态下最优：初始化 $\text{dp}[0\sim V]=0$，因为初始无物品时任意容量下不装物品即为最优解。

# 完全背包

- 有 $N$ 件物品和一个容量为 $V$ 的背包。第 $i$ 件物品的体积是 $v_i$，价值是 $w_i$，**每个物品都有无限件可用**，求解将物品放入背包后能够达到的最大权值和。

每个物品都有取 $0$ 件、$1$ 件、......、$\lfloor \frac{V}{v_i}\rfloor$，这些选择，根据 01 背包思路将每个选择看作一个新的单独的物体，对于物品 $i$ 可得到状态转移方程为：
$$\text{dp}[i][j]=\max\{\text{dp}[i-1][j-k\cdot v_i]+k\cdot w_i\mid0\le k\cdot v_i\le V\}$$

## 时间复杂度优化

展开 $\text{dp}[i][j]$：
$$\text{dp}[i][j]=\max(\text{dp}[i-1][j],\text{dp}[i-1][j-v_i]+w_i,\text{dp}[i-1][j-2v_i]+2w_i,\dots)$$
展开 $\text{dp}[i][j-v_i]$：
$$\text{dp}[i][j-v_i]=\max(\text{dp}[i-1][j-v_i],\text{dp}[i-1][j-2v_i]+w_i,\text{dp}[i-1][j-3v_i]+2w_i,\dots)$$
可以发现 $\text{dp}[i][j]$ 的状态转移方程可以写成：
$$\text{dp}[i][j]=\max(\text{dp}[i-1][j],dp[i][j-v]+w)$$
同样考虑 01 背包中的降维思路，由于 $\text{dp}[j]$ 需要由当前行状态 $\text{dp}[i][j-v_i]$ 推导而来，而 $\text{dp}[i][j-v_i]$ 需要已经被更新过，故采用顺序遍历方式进行递推，时间复杂度变为 $O(NV)$，同时空间复杂度变为 $O(V)$。

```plaintext
for(int i = 1; i <= N; i++) {
	for(int j = v[i]; j <= V; j++) {
		dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
	}
}
```

# 多重背包

- 有 $N$ 件物品和一个容量为 $V$ 的背包。第 $i$ 件物品的体积是 $v_i$，价值是 $w_i$，**每个物品都有 $c_i$ 件可用**，求解将物品放入背包后能够达到的最大价值和。

与完全背包类似，只不过是物品可选次数上限发生了变化：
$$\text{dp}[i][j]=\max\{\text{dp}[i-1][j-k\cdot v_i]+k\cdot w_i\mid0\le k\le c_i\}$$
倘若这样拆解物品个数并遍历，时间复杂度为 $O(NV\sum c_i)$。考虑二进制思想，将 $c_i$ 分解为 $1,2,2^2,\dots,2^{k-1},2^k,c_i-2^k$，其中 $k$ 为满足 $c_i\gt 2^k$ 的最大整数，而 $1\sim c_i$ 中的每个数字都可以由分解出的若干整数表示。这样就将第 $i$ 种物品分成了 $O(\log{c_i})$ 种物品，时间复杂度变为 $O(NV\sum\log{c_i})$。

```plaintext
for(int i = 1; i <= N; i++) {
	if(c[i] * v[i] >= V) 采用完全背包过程
	else {
		int k = 1;
		while(c[i] > 0) {
			int take = min(c[i], k);
			for(int j = V; j >= take * v[i]; j--) 
				dp[j] = max(dp[j], dp[j - take * v[i]] + take * w[i]);
			c[i] -= take;
			k <<= 1;
		}
	}
}
```

## 可行性问题

若只考虑填满背包的可行性，不考虑每件物品的价值时，多重背包有 $O(NV)$ 复杂度的解法。取 $\text{dp}[i][j]$ 表示使用了前 $i$ 种物品填满容量为 $j$ 的背包后，第 $i$ 种物品最多还剩下几个可用。若 $\text{dp}[i][j]=-1$，则代表该状态不可达，如果 $\text{dp}[i][j]\ge0$，则代表可行，且其数值代表第 $i$ 种物品的剩余数量。

```
// 正序遍历降维
// 初始化 dp[1~N] = -1, dp[0] = 0;
for(int i = 1; i <= N; i++) {
	for(int j = 0; j <= V; j++) {
		if(dp[i - 1][j] >= 0) dp[j] = c[i];
		else if(j >= v[i] && dp[j - v[i]] > 0) dp[j] = dp[j - v[i]] - 1;
		else dp[j] = -1;
	}
}
```

# 二维费用的背包问题

- 对于每件物品，有两种不同的体积 $v_i,u_i$ 和不同的容量 $V,U$，价值为 $w_i$。

设 $\text{dp}[i][j][k]$ 表示考虑前 $i$ 个物品且两种容量分别为 $j,k$ 时的最大价值，状态转移方程为：
$$\text{dp}[i][j][k]=\max(\text{dp}[i-1][j][k],\text{dp}[i-1][j-v_i][k-u_i]+w_i)$$
如若对背包内总物品数量有限制，就可以看作一个隐藏的第二维上限 $U$，那么每一件物品的在该维度下体积就为 $1$（即件数）。

## 复整数域上的背包问题

一维背包可视为自然数域上的问题，那么二维背包就可以被视作 **复整数域/向量空间** 上的问题，如果将一个物品 $i$ 的两个体积 $v_i,u_i$ 看作一个复数 $z_i=v_i+u_ii$（或看作一个二维向量 $(v,u)$），那么二维背包问题就等价于：**给定一堆复数 $z_1,z_2,\dots$ 从中选中若干个，使得它们的实部之和不超过 $V$，虚部之和不超过 $U$，且价值最大**。

# 分组背包

- 有 $N$ 件物品和一个容量为 $V$ 的背包。第 $i$ 件物品的体积是 $v_i$，价值是 $w_i$。这些物品被划分为 $K$ 组，每组中的物品互相冲突，最多选一件。求解将物品放入背包后能够达到的最大价值和。

对每一组单独考虑，在第二层循环中遍历体积而非物品，且考虑降维采用逆序遍历，这样在第三层循环中遍历物品，就可以保证同一组内的物品是被互斥选择。

```plaintext
for(int k = 1; k <= K; k++) {
	for(int i = V; i >= 0; i--) {
		for j in group k {
			dp[i] = max(dp[i], dp[i - v[j]] + w[j]);
		}
	}
}
```

# 泛化物品与有依赖的背包问题

- **泛化物品**：物品体积不确定，若取定其体积为 $0\le v_i\le V$，其对应的价值为 $w_i(v_i)$。

## 泛化物品的合并

考虑如何求解多个泛化物品在定容量 $V$ 下的最大价值，先思考最简单的只有两个泛化物品的情况。此时，只需要枚举体积分配给其中一个物品，那么另一个物品的体积也就决定好了，这里定义 $w'_i(v)$ 为体积不超过 $v$ 时物品 $i$ 所能提供的最大价值，即
$$w_i'(v_i)=\max\{w_i(v)\mid 0\le v\le v_i\}$$
定义 $f(v)$ 表示：
$$f(v)=\max\{w_1'(k)+w_2'(v-k)\mid0\le k\le v\}$$
可以看到，$f(v)$ 的实际含义是总体积不超过 $v$ 时两个物品能提供的最大价值。倘若此时又引入一个新的泛化物品，并将其合并，那么定义 $g(v)$ 表示：
$$g(v)=\max\{f(k)+w_3'(v-k)\mid0\le k\le v\}$$
由此可见，倘若拓展到多个泛化物品合并求最大价值，那么取 $f(v)$ 为已经考虑的泛化物品集合在容量限制 $v$ 下的最大价值，$g(v)$ 表示一个新的泛化物品在容量限制 $v$ 下的最大价值，那么在合并该新的泛化物品后可以得到一个新的泛化物品集合在容量限制 $v$ 下的最大价值：
$$h(v)=\max\{f(k)+g(v-k)\mid0\le k\le v\}$$
事实上，泛化物品合并的本质是 $(\max,+)$ 卷积，也就是说，每次合并都是 $O(V^2)$ 的复杂度，那么多个泛化物品合并的最大价值就是 $O(NV^2)$ 的复杂度。

## 有依赖的背包问题

- 这种背包问题中物品间存在某种依赖关系，如果物品 $i$ 依赖于物品 $j$，那么当且仅当物品 $j$ 被选择，物品 $i$ 才有被选择的可能。

根据依赖关系，若物品 $i$ 依赖于物品 $j$，从标号 $i$ 的节点向标号 $j$ 的节点连一条有向边，那么显然这些依赖关系在图表示法中构成了森林（保证不会出现循环依赖情况，在某种意义上这就是树上背包问题）。在该森林中，以 $u$ 为根节点的子树可被视作一个泛化物品 $u$。取 $\text{dp}[u][k]$ 表示给泛化物品 $u$ 分配 $k$ 体积得到的最大价值，那么就可以套用前文的卷积原理进行合并。

```plaintext
void dfs(int x) {
	for v in x -> y {
		dfs(y); // 先遍历子节点初始化子泛化物品 y
	}
	for y in x -> y {
		for(int v = V; v > 0; v--) {
			for(int k = 0; k <= v; k++) {
				// 卷积合并
				dp[x][v] = max(dp[x][v], dp[x][k] + dp[y][v - k]);
			}
		}
	}
}
```

## 时间复杂度优化

### DFS 序 DP

将树进行 DFS（先序遍历），得到一个序列，在这个序列中，任何一个节点 $u$ 的的子树，都是连续的一段。假设节点 $u$ 在序列中的位置为 $i$，用 $size[u]$ 记录 $u$ 的子树大小，那么 $u$ 的子树在序列中覆盖的范围是 $[i,i+size[u]-1]$，$u$ 的下一个兄弟节点在序列中的位置就是 $i+size[u]$。重新定义 $\text{dp}[i][j]$：
- $i$：表示当前决策到了 DFS 序中的第 $i$ 个节点；
- $j$：表示当前还剩 $j$ 的容量可供分配；
- $\text{dp}[i][j]$：在考虑 DFS 序中第 $i$ 个节点到第 $N$ 个节点这些物品，剩余容量为 $j$ 时，能获得的最大价值。
对于 DFS 序中的第 $i$ 个节点（对应原树中的节点 $u$），有两种选择：
- 选择节点 $i$：接下来考虑它的左孩子，即 DFS 序中的 $i+1$，如果给定容量 $j\ge v_u$，转移到 $\text{dp}[i+1][j-v_u]$；
- 不选择节点 $i$：那么 $u$ 的整棵子树都不选，这意味着可以直接跳过 $i$ 后面的 $size[u]-1$ 个节点，直接跳到 $i+size[u]$ 处做出决策。

```plaintext
void dfs(int u) {
	sz[u] = 1, dfn[++tot] = u;
	for v in u -> v {
		dfs(v);
	}
}

void solve() {
	for(int i = tot; i >= 1; i--) {
		int u = dfn[i];
		for(int j = 0; j <= V; j++) {
			int take = -INF;
			if(j >= v[u]) 
				// dp[i][v[u]] = w[u]
				take = dp[i + 1][j - v[u]] + w[u];
			int skip = dp[i + sz[u]][j];
			dp[i][j] = max(take, skip);
		}
	}
}
```

那么 $\text{dp}[\text{root}][V]$ 即为所求答案，该算法时间复杂度为 $O(NV)$。

### 闵可夫斯基和优化

在几何上，两个点集 $A$ 和 $B$ 的闵可夫斯基和定义为：
$$A+B=\{\vec a+\vec b\mid\vec a\in A,\vec b\in B\}$$
简单来说，就是把图形 $A$ 和 $B$ 的所有点向量相加，形成一个新的图形。在背包语境下，下将泛化物品 $f(v)$ 看作二维平面上的一系列点 $(v,f(v))$，所谓泛化物品合并 
$$h(v)=\max\{f(k)+g(v-k)\}$$
在几何上等价于求这两个函数图像的闵可夫斯基和的外轮廓。

**闵可夫斯基和不能用于所有泛化物品，它只能用于 “上凸” 的泛化物品**。通常只有在物品是完全背包或同类多重背包，或者特殊的分段线性收益题目中，泛化物品的函数图像才会呈现上凸性质。如果泛化物品的权值函数 $w_v(v)$ 是上凸的，即边际收益递减，等价于
$$w_v(v)-w_v(v-1)\ge w_v(v+1)-w_v(v)$$
直观理解为每多投入一单位体积，获得的额外价值越来越少，不能突然暴增。如果两个函数 $f,g$ 都是上凸的（斜率单调递减），那么合并两个函数时，可以根据斜率（边际收益）进行贪心：
- 取物品 $A$ 的收益增量序列（差分数组） $d_A=[w_A'(1),w_A(2)'\dots]$，其中 $$w'_A(1)=w_A(1),w_A'(2)=w_A(2)-w_A(1),w_A'(3)=w_A(3)-w_A(2),\dots$$取物品 $B$ 的为 $d_B$，定义同理。
- 由于两个序列都是单调递减序列，将 $d_A$ 和 $d_B$ 按照归并排序逻辑，从大到小合并，再对新的差分数组做前缀和即可得到两个物品合并后的泛化物品函数。
这样合并复杂度变为了 $O(NV)$。

# 背包问题其它问法

## 最优方案

在动态规划过程中，记录下每个状态的最优值是由哪个状态转移过来的。以 01 背包为例，对于方程 $\text{dp}[i][j]=\max(\text{dp}[i-1][j],\text{dp}[i-1][j-v_i]+w_i)$，如果 $\text{dp}[i][j]=\text{dp}[i-1][j]$，代表从前一项转移过来，即不选该物品；若 $\text{dp}[i][j]=\text{dp}[i-1][j-v_i]+w_i$ 代表从后一项转移过来，即选择该物品；若同时等于两者，则选与不选都是最优解的一种。

```plaintext
for(int i = N, curv = V; i >= 1; i--) {
	if(Pre[i][curv] == 0) //未选物品 i 则向上平移
	else if(Pre[i][curv] == 1) {
		// 选择了物品 i 则向左上方移动
		curv -= v[i];
	}
}
```

倘若需要输出字典序最小的最优方案，那么优先向后一项转移，即选择该物品的情况。如果需要给出最优方案的数量，用 $S[i][j]$ 表示这个子问题的最优方案总数，在求解 $\text{dp}[i][j]$ 的同时可以求解 $S[i][j]$。

```plaintext
S[0][0] = 1;
for(int i = 1; i <= N; i++) {
	for(int j = 0; j <= V; j++) {
		dp[i][j] = dp[i - 1][j];
		if(j >= v[i]) dp[i][j] = max(dp[i][j], dp[i - 1][j - v[i]] + w[i];
		if(dp[i][j] == dp[i - 1][j]) S[i][j] += S[i - 1][j];
		if(dp[i][j] == dp[i - 1][j - v[i]] + w[i]) s[i][j] += S[i - 1][j - v[i]];
	}
}
```

## 第 K 优解

同样以 01 背包为例，如果要求解第 K 优解，那么状态 $\text{dp}[i][j]$ 应该是一个大小为 K 的优先队列。故 $\text{dp}[i][j][k]$ 表示前 $i$ 个物品中，背包容量大小为 $v$ 时，第 $k$ 优解的值。显然这 K 个数是从大到小排列的，所以它可以看作一个有序队列。那么原方程就可以理解为：$\text{dp}[i][j]$ 这个队列是由 $\text{dp}[i-1][j]$ 和 $\text{dp}[i-1][j-v[i]]+w[i]$ 两个队列合并得到的。合并后再将结果的前 $K$ 项存储到当前状态中的复杂度为 $O(K)$，那么第 $K$ 优解的答案为 $\text{dp}[N][V][K]$，总的时间复杂度为 $O(NVK)$。
